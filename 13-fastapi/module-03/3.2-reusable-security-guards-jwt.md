# 3.2 Reusable Security Guards (JWT)

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
Securing APIs often leads to massive duplication. In every single protected route, you have to read the `Authorization` header, strip the "Bearer " prefix, decode the JWT, check for expiration, query the database for the user, and handle 401 errors. If you have 50 protected routes, you have 50 places where a security bug could hide.

### 2. Plain English Metaphor (The What)
Manual security is like having a separate bouncer standing directly in front of every single person's table inside a restaurant checking IDs before they can take a bite.
FastAPI Dependency Security is like a bouncer at the front door. You just mark certain tables as "VIP Only" (the dependency), and the framework guarantees that nobody can even approach that table without having already passed the front door bouncer.

### 3. Complete Runnable Code
```python
from fastapi import FastAPI, Depends, HTTPException, Security
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials

app = FastAPI()

# FastAPI's built-in Bearer token extractor
security = HTTPBearer()

def get_current_user(credentials: HTTPAuthorizationCredentials = Security(security)):
    token = credentials.credentials
    # In a real app, you would decode the JWT here
    if token != "super-secret-jwt":
        raise HTTPException(
            status_code=401,
            detail="Invalid authentication credentials",
            headers={"WWW-Authenticate": "Bearer"},
        )
    # Return the user object
    return {"username": "ai_researcher", "role": "admin"}

@app.get("/public")
async def public_data():
    return {"data": "Anyone can see this"}

@app.get("/private")
async def private_data(user: dict = Depends(get_current_user)):
    # By the time this runs, we are 100% sure the user is authenticated
    return {"secret_data": "Model weights", "accessed_by": user["username"]}
```

### 4. Progressive Step-by-Step Breakdown

**Step 1: The Extractor**
```python
security = HTTPBearer()
```
`HTTPBearer` is a built-in FastAPI class. It automatically looks for the `Authorization: Bearer <token>` header. If it's missing, it automatically returns a 403 Forbidden without you writing any code.

**Step 2: The Validator Dependency**
```python
def get_current_user(credentials: HTTPAuthorizationCredentials = Security(security)):
    token = credentials.credentials
    if token != "super-secret-jwt":
        raise HTTPException(status_code=401, ...)
    return {"username": "ai_researcher"}
```
We use `Security()` (which is just an alias for `Depends()` that adds security metadata to OpenAPI). We validate the token and return the user object. If validation fails, we raise a 401.

**Step 3: The Guarded Endpoint**
```python
@app.get("/private")
async def private_data(user: dict = Depends(get_current_user)):
```
The endpoint just asks for `user`. It contains zero security logic. FastAPI handles the entire pipeline before the endpoint logic executes.

### 5. ASCII Data Flow
```text
GET /private (No Header) -> [HTTPBearer] -> Returns 403 instantly
                                |
GET /private (Bad Token) -> [HTTPBearer] -> [get_current_user] -> Raises 401
                                |
GET /private (Good Token)-> [HTTPBearer] -> [get_current_user] -> Returns User Dict
                                                                      |
                         [Endpoint logic runs safely] <---------------+
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Re-implementing header extraction manually: `token = request.headers.get("Authorization")`. You lose automatic OpenAPI documentation (Swagger UI won't show the "Authorize" padlock button).
**Pro Tip:** Create a stricter dependency `get_admin_user` that depends on `get_current_user`, checks if `user['role'] == 'admin'`, and raises a 403 if not.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
**Challenge:** Create a simple dependency `verify_api_key` that checks a custom header `X-API-KEY`. If the key is not "12345", raise a 401 HTTPException. Protect a `GET /secure` endpoint with it.
<details>
<summary><b>Hint</b></summary>
Use <code>from fastapi import Header</code>. Write <code>def verify_api_key(x_api_key: str = Header(...)):</code>
</details>
<details>
<summary><b>Solution</b></summary>

```python
from fastapi import FastAPI, Depends, Header, HTTPException

app = FastAPI()

def verify_api_key(x_api_key: str = Header(...)):
    if x_api_key != "12345":
        raise HTTPException(status_code=401, detail="Invalid API Key")
    return True

@app.get("/secure")
async def secure_endpoint(is_valid: bool = Depends(verify_api_key)):
    return {"msg": "You are authorized"}
```
</details>

### Level 2: Real-World
**Challenge:** Role-Based Access Control (RBAC).
1. Create `get_current_user` that just returns `{"name": "Bob", "role": "user"}`.
2. Create `require_admin` that depends on `get_current_user`. It checks the role. If not "admin", raise a 403 HTTPException.
3. Apply `require_admin` to a `DELETE /users/1` endpoint.
<details>
<summary><b>Hint</b></summary>
<code>def require_admin(user: dict = Depends(get_current_user)):</code>
</details>
<details>
<summary><b>Solution</b></summary>

```python
from fastapi import FastAPI, Depends, HTTPException

app = FastAPI()

def get_current_user():
    # Simulated token decode
    return {"name": "Bob", "role": "user"}

def require_admin(user: dict = Depends(get_current_user)):
    if user.get("role") != "admin":
        raise HTTPException(status_code=403, detail="Not enough privileges")
    return user

@app.delete("/users/{id}")
async def delete_user(id: int, admin_user: dict = Depends(require_admin)):
    return {"status": "deleted"}
```
</details>

### Level 3: Boss Level
**Challenge:** Global Security.
Protect the *entire application* using dependencies in the FastAPI initialization, rather than per-route.
Create an app with two endpoints (`/a` and `/b`). Require a mock dependency `global_guard` for the entire `app`.
<details>
<summary><b>Hint</b></summary>
You can pass dependencies to the FastAPI constructor: <code>app = FastAPI(dependencies=[Depends(global_guard)])</code>.
</details>
<details>
<summary><b>Solution Walkthrough</b></summary>

```python
from fastapi import FastAPI, Depends, HTTPException, Header

def global_guard(x_token: str = Header(...)):
    if x_token != "global-secret":
        raise HTTPException(status_code=400, detail="Invalid token")

# Apply the dependency to all routes automatically!
app = FastAPI(dependencies=[Depends(global_guard)])

@app.get("/a")
async def route_a():
    return {"msg": "A"}

@app.get("/b")
async def route_b():
    return {"msg": "B"}
```
*Walkthrough:* If your microservice is strictly private (like an internal AI worker node), applying security globally prevents accidental data leaks. If a new developer adds a route `/c` tomorrow and forgets to add `Depends(...)`, they are still protected because the global dependency enforces the guard at the routing layer.
</details>
