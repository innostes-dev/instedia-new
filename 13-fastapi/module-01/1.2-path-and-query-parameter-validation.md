# 1.2 Path and Query Parameter Validation

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
In classic frameworks, you extract data from request objects manually: `user_id = request.args.get('id')`. Then you have to check if it's there, try to cast it to an integer, and if it fails, manually return a 400 Bad Request. For 10 parameters, you have 30 lines of boilerplate validation code before your actual business logic begins.

### 2. Plain English Metaphor (The What)
Manual validation is like being a bouncer who has to strip-search every guest, check their ID under a microscope, and ask them 20 questions before letting them into the club.
FastAPI validation is like an automated VIP scanner gate. You just declare "Guests must be 18+ and have a ticket", and the gate automatically rejects anyone who doesn't fit, handing you perfect guests every time.

### 3. Complete Runnable Code
```python
from fastapi import FastAPI, Query, Path

app = FastAPI()

@app.get("/products/{product_id}")
async def get_product(
    product_id: int = Path(..., title="The ID of the product", ge=1),
    min_price: float = Query(0.0, description="Minimum price filter"),
    max_price: float = Query(None, description="Maximum price filter", le=10000.0)
):
    return {
        "product_id": product_id,
        "filters": {"min_price": min_price, "max_price": max_price}
    }
```

### 4. Progressive Step-by-Step Breakdown

**Step 1: The Path Parameter**
```python
@app.get("/products/{product_id}")
async def get_product(
    product_id: int = Path(..., title="The ID of the product", ge=1),
```
By placing `{product_id}` in the URL and adding it to the function signature with type `int`, FastAPI automatically casts the string URL into an integer. `Path(...)` (where `...` means required) lets us add metadata and constraints like `ge=1` (greater than or equal to 1).

**Step 2: The Query Parameters**
```python
    min_price: float = Query(0.0, description="Minimum price filter"),
    max_price: float = Query(None, description="Maximum price filter", le=10000.0)
):
```
Variables not in the URL path default to Query parameters. We assign default values (`0.0` and `None`) and enforce constraints like `le=10000.0` (less than or equal).

**Step 3: The Business Logic**
```python
    return {
        "product_id": product_id,
        "filters": {"min_price": min_price, "max_price": max_price}
    }
```
By the time this code runs, we are 100% guaranteed that `product_id` is a valid integer >= 1, and the prices are valid floats within bounds. If not, FastAPI automatically returns a structured 422 Unprocessable Entity error.

### 5. ASCII Data Flow
```text
GET /products/abc?min_price=-5
      |
[FastAPI Validator]
      |-- (product_id='abc' -> Fail: Not int) ---> [422 Error Response]
      |-- (min_price='-5' -> Fail: ge=0)      ---> [422 Error Response]
      |
    (Valid Data)
      |
[Endpoint Logic] -> Returns 200 OK
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Using `Optional[str] = None` without explicitly using `Query(None)`. While it works, explicitly using `Query` is better when you need to add limits (like `max_length=50`) or regex validation.
**Pro Tip:** Use Enum for query parameters if there are strictly defined choices. FastAPI will auto-generate dropdown menus in the Swagger UI and validate against the Enum.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
**Challenge:** Create an endpoint `GET /users/{user_id}/posts` that requires an integer `user_id` greater than 0, and accepts an optional query parameter `limit` (integer, max 100, default 10).
<details>
<summary><b>Hint</b></summary>
Use <code>Path(..., gt=0)</code> and <code>Query(10, le=100)</code>.
</details>
<details>
<summary><b>Solution</b></summary>

```python
from fastapi import FastAPI, Path, Query

app = FastAPI()

@app.get("/users/{user_id}/posts")
async def get_user_posts(
    user_id: int = Path(..., gt=0),
    limit: int = Query(10, le=100)
):
    return {"user_id": user_id, "limit": limit}
```
</details>

### Level 2: Real-World
**Challenge:** Build an AI model version selector. Create `GET /models/{model_name}` where `model_name` is validated via an Enum containing "gpt-3.5", "gpt-4", and "claude-3". Also accept a query param `temperature` between 0.0 and 2.0 (default 0.7).
<details>
<summary><b>Hint</b></summary>
Import <code>Enum</code> from Python's <code>enum</code> module. Create a class <code>class ModelName(str, Enum): ...</code>. Use it as the type hint for the path param.
</details>
<details>
<summary><b>Solution</b></summary>

```python
from enum import Enum
from fastapi import FastAPI, Query, Path

app = FastAPI()

class ModelName(str, Enum):
    gpt3 = "gpt-3.5"
    gpt4 = "gpt-4"
    claude = "claude-3"

@app.get("/models/{model_name}")
async def select_model(
    model_name: ModelName,
    temperature: float = Query(0.7, ge=0.0, le=2.0)
):
    return {"model": model_name, "temp": temperature}
```
</details>

### Level 3: Boss Level
**Challenge:** Combine Module 1.1 and 1.2. Create an endpoint `GET /search/{query}`.
- `query` must be min 3 chars, max 50 chars.
- Query param `delay` (float, max 2.0 seconds).
- The endpoint must asynchronously sleep for `delay` seconds, and then return the query back.
<details>
<summary><b>Hint</b></summary>
Use <code>Path(..., min_length=3, max_length=50)</code>. Make the endpoint <code>async def</code> and <code>await asyncio.sleep(delay)</code>.
</details>
<details>
<summary><b>Solution Walkthrough</b></summary>

```python
import asyncio
from fastapi import FastAPI, Path, Query

app = FastAPI()

@app.get("/search/{query}")
async def async_search(
    query: str = Path(..., min_length=3, max_length=50),
    delay: float = Query(0.0, ge=0.0, le=2.0)
):
    # Asynchronously block without stopping the server
    await asyncio.sleep(delay)
    return {"search_query": query, "time_slept": delay}
```
*Walkthrough:* We define strict boundaries for the user's input. The string length constraints protect against massive payload abuse, and the max delay of 2.0 prevents users from holding server connections open indefinitely. The `await asyncio.sleep()` simulates a variable-length database or external API call, keeping the main thread free.
</details>
