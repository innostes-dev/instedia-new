# 2.4 Global Resilient Exception Filters

## Phase A: Concept & Implementation

### Real-World Pain Point (The Why)
In Node.js applications, unhandled errors often result in the server crashing or, worse, raw stack traces (including database connection strings or internal file paths) being sent directly to the client. Writing `try/catch` blocks in every single controller method is tedious, clutters business logic, and doesn't guarantee consistency. You need a centralized mechanism that acts as a safety net, catches all exceptions, logs them securely, and returns sanitized, standardized error formats to the client.

### Plain English Metaphor (The What)
Think of an **Exception Filter** as a safety net placed underneath a group of trapeze artists (your controllers and services). If an artist falls (an exception is thrown), they don't hit the ground (the app doesn't crash). Instead, the safety net catches them, examines why they fell (e.g., slipped, missed grab), quietly logs the exact reason for the circus manager, and then calmly announces to the audience over the loudspeaker, "Please excuse the interruption, we are resetting the act" (returning a sanitized error to the client).

### Complete Runnable Code
```typescript
import {
  ExceptionFilter, Catch, ArgumentsHost, HttpException,
  HttpStatus, Controller, Get, UseFilters
} from '@nestjs/common';
import { Request, Response } from 'express';

// 1. Create a Custom Exception
export class BusinessLogicException extends HttpException {
  constructor(message: string, code: string) {
    // We pass our custom structure into the base HttpException
    super({ message, code }, HttpStatus.UNPROCESSABLE_ENTITY);
  }
}

// 2. Define the Exception Filter using @Catch()
@Catch() // Empty @Catch() catches ALL exceptions (HttpExceptions and standard Errors)
export class GlobalResilientFilter implements ExceptionFilter {
  catch(exception: unknown, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();
    const request = ctx.getRequest<Request>();

    let status = HttpStatus.INTERNAL_SERVER_ERROR;
    let message = 'An unexpected error occurred';
    let errorCode = 'INTERNAL_ERROR';

    // 3. Determine the type of exception
    if (exception instanceof HttpException) {
      status = exception.getStatus();
      const exceptionResponse: any = exception.getResponse();

      // Handle custom BusinessLogicException or standard NestJS HttpExceptions
      message = exceptionResponse.message || exception.message;
      errorCode = exceptionResponse.code || 'HTTP_EXCEPTION';
    } else {
      // 4. Handle Uncaught System Errors (e.g., TypeErrors, DB Errors)
      // Log the actual stack trace to the console (or a service like Sentry)
      console.error('CRITICAL UNHANDLED ERROR:', exception);
      // But KEEP the response sanitized for the client!
    }

    // 5. Return standardized RFC 7807-style Problem Details format
    response
      .status(status)
      .json({
        type: `https://api.myapp.com/errors/${errorCode.toLowerCase()}`,
        title: errorCode,
        status: status,
        detail: message,
        instance: request.url,
        timestamp: new Date().toISOString(),
      });
  }
}

// 6. Controller
@Controller('payments')
@UseFilters(GlobalResilientFilter) // Can also be applied globally in main.ts
export class PaymentController {

  @Get('process')
  processPayment() {
    // Simulate a business rule violation
    throw new BusinessLogicException('Insufficient funds in wallet', 'INSUFFICIENT_FUNDS');
  }

  @Get('crash')
  causeCrash() {
    // Simulate an uncaught system error (e.g., trying to read a property of undefined)
    const obj: any = undefined;
    return obj.nonExistentProperty;
  }
}
```

### Progressive Step-by-Step Breakdown

**Step 1: The `@Catch()` Decorator**
```typescript
@Catch()
export class GlobalResilientFilter implements ExceptionFilter {
```
*Rationale:* `@Catch()` tells NestJS this class is an Exception Filter. If you pass an argument (e.g., `@Catch(HttpException)`), it only catches that specific type. Leaving it blank means it catches *everything*, acting as the ultimate safety net.

**Step 2: The `ArgumentsHost`**
```typescript
catch(exception: unknown, host: ArgumentsHost) {
  const ctx = host.switchToHttp();
  const response = ctx.getResponse<Response>();
```
*Rationale:* Because NestJS supports HTTP, Microservices, and WebSockets, it provides `ArgumentsHost` instead of raw `req/res` objects. We use `switchToHttp()` to access the underlying Express (or Fastify) Response object so we can manually send the JSON payload.

**Step 3: Sanitization and Standardization**
```typescript
let status = HttpStatus.INTERNAL_SERVER_ERROR;
if (exception instanceof HttpException) {
  status = exception.getStatus();
  // ... extract message
} else {
  console.error(exception); // Log real error internally
}
response.status(status).json({ detail: message /* sanitized */ });
```
*Rationale:* If it's a known `HttpException`, we trust the message and return it. If it's a raw JavaScript `Error` (e.g., a database connection failure), we log the raw trace securely on the server but return a generic 500 error to the client to prevent leaking sensitive information.

### ASCII / Architecture Data Flow
```text
[HTTP Request -> Controller]
       │
       ▼
[Controller Throws Exception]
       │ (Execution halts, bubbles up)
       ▼
┌──────────────┐
│  Exception   │ -> Is it an HttpException?
│    Filter    │ ────► YES: Use status and message
└──────┬───────┘ ────► NO: Log stack trace, return generic 500
       │
       ▼
[Response Sent to Client in Standard JSON Format]
```

### Noob Trap vs Pro Tip
* **Noob Trap:** Putting business logic `try/catch` blocks everywhere and manually using `res.status(400).send()`. This breaks the NestJS architecture. Always `throw` exceptions (like `new NotFoundException()`) and let NestJS (and your filters) handle the response formatting.
* **Pro Tip:** Register your ultimate safety net globally in `main.ts` using `app.useGlobalFilters(new GlobalResilientFilter())`. This guarantees that no unhandled exception will ever leak a stack trace to a client.

### Level 1 Warm-Up
**Task:** Create a custom exception called `ItemNotFoundException` that extends `NotFoundException`. Throw it in a controller when an item ID is 99.
<details>
<summary>Hint</summary>
Import `NotFoundException` from `@nestjs/common`. In the constructor, pass your custom string.
</details>
<details>
<summary>Solution</summary>

```typescript
import { Controller, Get, Param, NotFoundException } from '@nestjs/common';

export class ItemNotFoundException extends NotFoundException {
  constructor(itemId: string) {
    super(`Item with ID ${itemId} could not be located in our systems.`);
  }
}

@Controller('items')
export class ItemController {
  @Get(':id')
  getItem(@Param('id') id: string) {
    if (id === '99') {
      throw new ItemNotFoundException(id);
    }
    return { id, name: 'Standard Item' };
  }
}
```

### Level 2 Real-World
**Task:** Create a `PrismaExceptionFilter` that only catches a fictional `PrismaDatabaseError`. When caught, it should return a 409 Conflict status code and a message "Database constraint violated", regardless of what the original database error message was (to hide DB internals).
<details>
<summary>Hint</summary>
Use `@Catch(PrismaDatabaseError)`. In the `catch` method, use the `response` object to send a 409.
</details>
<details>
<summary>Solution</summary>

```typescript
import { ExceptionFilter, Catch, ArgumentsHost, HttpStatus, Controller, Post, UseFilters } from '@nestjs/common';
import { Response } from 'express';

// Mock DB Error
class PrismaDatabaseError extends Error {
  constructor(public meta: any) { super('Prisma Error'); }
}

@Catch(PrismaDatabaseError)
export class PrismaExceptionFilter implements ExceptionFilter {
  catch(exception: PrismaDatabaseError, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();

    // We completely hide the 'exception.meta' from the client
    response
      .status(HttpStatus.CONFLICT)
      .json({
        statusCode: HttpStatus.CONFLICT,
        message: 'Database constraint violated',
      });
  }
}

@Controller('users')
@UseFilters(PrismaExceptionFilter)
export class UserController {
  @Post()
  createUser() {
    throw new PrismaDatabaseError({ target: ['email'], code: 'P2002' });
  }
}
```
</details>

### Level 3 Boss Level
**Task:** Implement an Enterprise Global Resilient Exception Filter. It catches everything. If it's an `HttpException`, use its status. If it's a `TypeError`, return a 500. Additionally, the filter must log the error along with the HTTP Method, URL, and User IP Address using `console.error` before returning an RFC 7807 Problem Details object.
<details>
<summary>Hint</summary>
Use `@Catch()`. Extract the request and response from `ArgumentsHost`. Use `instanceof HttpException` to branch logic. Build the JSON structure required.
</details>
<details>
<summary>Solution</summary>

```typescript
import { ExceptionFilter, Catch, ArgumentsHost, HttpException, HttpStatus, Controller, Get } from '@nestjs/common';
import { Request, Response } from 'express';

@Catch()
export class EnterpriseFilter implements ExceptionFilter {
  catch(exception: unknown, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();
    const request = ctx.getRequest<Request>();

    const isHttp = exception instanceof HttpException;
    const status = isHttp ? exception.getStatus() : HttpStatus.INTERNAL_SERVER_ERROR;

    // Log for internal observability
    console.error({
      timestamp: new Date().toISOString(),
      method: request.method,
      url: request.url,
      ip: request.ip,
      error: exception instanceof Error ? exception.stack : exception
    });

    // Send sanitized response
    response.status(status).json({
      type: `https://example.com/probs/${status}`,
      title: isHttp ? 'Request Failed' : 'Internal System Error',
      status,
      detail: isHttp ? (exception as HttpException).message : 'Please contact support.',
      instance: request.url
    });
  }
}

@Controller('test')
// Imagine applied globally via app.useGlobalFilters()
export class TestController {
  @Get('error')
  trigger() {
    const a: any = null;
    return a.b; // Throws TypeError, caught globally, 500 returned safely
  }
}
```
</details>
