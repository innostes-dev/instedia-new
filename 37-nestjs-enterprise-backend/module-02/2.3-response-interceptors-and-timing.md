# 2.3 Response Interceptors and Timing

## Phase A: Concept & Implementation

### Real-World Pain Point (The Why)
In a growing enterprise API, different teams write different endpoints. Team A returns `{ user: { id: 1 } }`. Team B returns `{ data: { items: [] } }`. Team C just returns `[{ id: 1 }]`. Your frontend team is pulling their hair out trying to parse these inconsistent formats. Furthermore, you need to track how long requests take for performance monitoring, but manually adding `Date.now()` to the start and end of every single controller method is a nightmare.

### Plain English Metaphor (The What)
Think of an **Interceptor** as the shipping department of a factory. The factory workers (Controllers) produce raw goods (data). Instead of handing the raw goods directly to the customer, the workers hand them to the shipping department. The shipping department packages the goods in a standardized, branded box (wrapping the response in a consistent JSON envelope), stamps it with a timestamp (execution time), and then ships it out. Interceptors can wrap *both* the incoming request and the outgoing response.

### Complete Runnable Code
```typescript
import {
  Injectable, NestInterceptor, ExecutionContext, CallHandler,
  Controller, Get, UseInterceptors
} from '@nestjs/common';
import { Observable } from 'rxjs';
import { map, tap } from 'rxjs/operators';

// 1. A unified response interface
export interface Response<T> {
  data: T;
  meta: {
    timestamp: string;
    path: string;
  };
}

// 2. The Interceptor to standardize responses
@Injectable()
export class TransformInterceptor<T> implements NestInterceptor<T, Response<T>> {
  intercept(context: ExecutionContext, next: CallHandler): Observable<Response<T>> {
    const ctx = context.switchToHttp();
    const request = ctx.getRequest();

    // `next.handle()` triggers the controller method.
    // The `map` operator intercepts the data returned by the controller.
    return next.handle().pipe(
      map(data => ({
        data, // The raw data returned by the controller
        meta: {
          timestamp: new Date().toISOString(),
          path: request.url,
        },
      })),
    );
  }
}

// 3. The Interceptor to measure execution time
@Injectable()
export class LoggingInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const req = context.switchToHttp().getRequest();
    const method = req.method;
    const url = req.url;
    const now = Date.now();

    // `tap` allows us to perform side-effects (like logging) without
    // altering the actual response data stream.
    return next.handle().pipe(
      tap(() => console.log(`[${method}] ${url} executed in ${Date.now() - now}ms`)),
    );
  }
}

// 4. Using Interceptors
@Controller('users')
// They run bottom-to-top on the way IN, and top-to-bottom on the way OUT.
@UseInterceptors(LoggingInterceptor, TransformInterceptor)
export class UserController {
  @Get()
  getUsers() {
    // Controller just returns raw data. No need to worry about formatting.
    return [{ id: 1, name: 'Alice' }, { id: 2, name: 'Bob' }];
  }
}
```

### Progressive Step-by-Step Breakdown

**Step 1: Implementing `NestInterceptor`**
```typescript
export class TransformInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    return next.handle(); // Triggers the route handler
  }
}
```
*Rationale:* Interceptors implement the `intercept` method. Unlike Guards (which return booleans), Interceptors return an RxJS `Observable`. `next.handle()` represents the invocation of your controller method.

**Step 2: Mutating Responses with `map`**
```typescript
return next.handle().pipe(
  map(data => ({ data, meta: { timestamp: new Date() } }))
);
```
*Rationale:* Because `next.handle()` is an Observable, we use RxJS operators. The `map` operator intercepts the exact data the controller returned, and allows us to wrap it in a new structure before it is finally serialized to JSON and sent to the client.

**Step 3: Side-Effects with `tap`**
```typescript
const now = Date.now();
return next.handle().pipe(
  tap(() => console.log(`Execution time: ${Date.now() - now}ms`))
);
```
*Rationale:* If you want to do something *after* the controller finishes, but you *don't* want to change the data it returns, you use the RxJS `tap` operator. It's perfect for logging, auditing, or metrics collection.

### ASCII / Architecture Data Flow
```text
[Incoming HTTP GET]
       │
       ▼
┌──────────────┐
│ Interceptors │ -> Logs start time
│ (Way IN)     │ -> `next.handle()` is called
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  Controller  │ -> Returns raw array: `[{ id: 1 }]`
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ Interceptors │ -> `map`: Wraps array in `{ data: [...] }`
│ (Way OUT)    │ -> `tap`: Calculates Date.now() - startTime and logs it
└──────┬───────┘
       │
       ▼
[Response Sent to Client]
```

### Noob Trap vs Pro Tip
* **Noob Trap:** Using middleware for response formatting. Express middleware runs *before* the route handler, and it's extremely clunky to intercept the response stream in Express. NestJS Interceptors are deeply integrated with the request lifecycle, making post-controller logic trivial.
* **Pro Tip:** Use `app.useGlobalInterceptors()` in your `main.ts` file to apply your `TransformInterceptor` globally. This ensures 100% consistency across your entire API without having to remember to add `@UseInterceptors()` to every new controller.

## Phase B: Engineering Challenges

### Level 1 Warm-Up
**Task:** Create an `ExcludeNullInterceptor` that intercepts the response. If the controller returns a value, it strips out any keys that have a `null` value.
<details>
<summary>Hint</summary>
Use `map` from RxJS. Iterate over the keys of the returned object and delete them if they are strictly `null`.
</details>
<details>
<summary>Solution</summary>

```typescript
import { Injectable, NestInterceptor, ExecutionContext, CallHandler, Controller, Get, UseInterceptors } from '@nestjs/common';
import { Observable } from 'rxjs';
import { map } from 'rxjs/operators';

@Injectable()
export class ExcludeNullInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    return next.handle().pipe(
      map(value => {
        if (typeof value === 'object' && value !== null) {
          // Simplistic implementation for shallow objects
          return Object.fromEntries(Object.entries(value).filter(([_, v]) => v !== null));
        }
        return value;
      })
    );
  }
}

@Controller('data')
@UseInterceptors(ExcludeNullInterceptor)
export class DataController {
  @Get()
  getData() {
    return { name: 'Alice', age: null, status: 'Active' };
    // Will return { name: 'Alice', status: 'Active' }
  }
}
```
</details>

### Level 2 Real-World
**Task:** Create a `TimeoutInterceptor`. Sometimes, your database queries hang. If a controller method takes more than 3 seconds to complete, the interceptor should automatically cancel the request and throw a `RequestTimeoutException`.
<details>
<summary>Hint</summary>
Use the RxJS `timeout` operator, catch the resulting error using `catchError`, and throw the NestJS built-in `RequestTimeoutException`.
</details>
<details>
<summary>Solution</summary>

```typescript
import { Injectable, NestInterceptor, ExecutionContext, CallHandler, RequestTimeoutException, Controller, Get, UseInterceptors } from '@nestjs/common';
import { Observable, throwError, TimeoutError } from 'rxjs';
import { timeout, catchError } from 'rxjs/operators';

@Injectable()
export class TimeoutInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    return next.handle().pipe(
      timeout(3000), // Wait max 3 seconds
      catchError(err => {
        if (err instanceof TimeoutError) {
          return throwError(() => new RequestTimeoutException());
        }
        return throwError(() => err);
      })
    );
  }
}

@Controller('slow')
@UseInterceptors(TimeoutInterceptor)
export class SlowController {
  @Get()
  async getSlowData() {
    // Simulate a hung process
    await new Promise(resolve => setTimeout(resolve, 5000));
    return { data: 'This will never be reached' };
  }
}
```
</details>

### Level 3 Boss Level
**Task:** Build a Unified RFC-Compliant API Response Envelope & Audit Interceptor. It should track execution time. If the response is successful, wrap it in `{ data: X, success: true, timestamp, executionMs }`. This applies to all routes using a global interceptor.
<details>
<summary>Hint</summary>
Combine the logic of the `LoggingInterceptor` and `TransformInterceptor`. Track `startTime` before `next.handle()`, and use `map` to build the final JSON envelope.
</details>
<details>
<summary>Solution</summary>

```typescript
import { Injectable, NestInterceptor, ExecutionContext, CallHandler, Controller, Get } from '@nestjs/common';
import { Observable } from 'rxjs';
import { map } from 'rxjs/operators';

@Injectable()
export class UnifiedResponseInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    const startTime = Date.now();

    return next.handle().pipe(
      map(data => {
        const executionMs = Date.now() - startTime;
        return {
          success: true,
          data,
          meta: {
            timestamp: new Date().toISOString(),
            executionMs,
          }
        };
      })
    );
  }
}

@Controller('products')
// Assume this interceptor is registered globally in main.ts
export class ProductController {
  @Get()
  getProducts() {
    // Returns: { success: true, data: [{id:1}], meta: { timestamp: '...', executionMs: 2 } }
    return [{ id: 1, name: 'Laptop' }];
  }
}
```
</details>
