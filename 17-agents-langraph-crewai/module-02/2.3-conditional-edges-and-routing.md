# 2.3 Conditional Edges and Routing

## Phase A: Core Concept

### 1. Real-World Pain Point (The Why)
In a linear DAG graph (`add_edge("A", "B")`), the flow is hardcoded. But agents need to make decisions. If an LLM reads a customer support ticket and realizes it's a billing issue, it needs to send it to the `billing_department` node. If it's a tech issue, it needs to go to the `tech_support` node. We need a way to inspect the state at runtime and dynamically route the execution to different nodes.

### 2. Plain English Metaphor (The What)
Think of a standard Edge like a train track with no switches. The train goes exactly where the track goes.
Think of a **Conditional Edge** like a train switch operator. As the train approaches the switch, the operator looks at the train's cargo (the State). If it's coal, they pull the lever to send it to the furnace. If it's passengers, they pull the lever to send it to the station.

### 3. Complete Runnable Code

```python
import os
from typing import TypedDict, Literal
from langgraph.graph import StateGraph, END
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage

os.environ["OPENAI_API_KEY"] = "your-api-key"

# 1. Define State
class TicketState(TypedDict):
    ticket_text: str
    category: str
    response: str

# 2. Define Nodes
def triage_node(state: TicketState):
    """Uses LLM to categorize the ticket."""
    llm = ChatOpenAI(temperature=0)
    prompt = f"Categorize this ticket as exactly 'BILLING' or 'TECH': {state['ticket_text']}"
    category = llm.invoke([HumanMessage(content=prompt)]).content.strip()
    return {"category": category}

def billing_node(state: TicketState):
    return {"response": "Routing to finance team for refund."}

def tech_node(state: TicketState):
    return {"response": "Routing to IT team for password reset."}

# 3. Define the Router Function
def route_ticket(state: TicketState) -> Literal["billing_node", "tech_node"]:
    """Inspects the state and returns the name of the next node."""
    if state["category"] == "BILLING":
        return "billing_node"
    return "tech_node"

# 4. Build Graph
builder = StateGraph(TicketState)
builder.add_node("triage", triage_node)
builder.add_node("billing_node", billing_node)
builder.add_node("tech_node", tech_node)

builder.set_entry_point("triage")

# THIS IS THE CONDITIONAL EDGE
builder.add_conditional_edges(
    "triage",       # Starting Node
    route_ticket    # The Routing Function
)

builder.add_edge("billing_node", END)
builder.add_edge("tech_node", END)

app = builder.compile()

if __name__ == "__main__":
    state1 = app.invoke({"ticket_text": "I was overcharged $50!", "category": "", "response": ""})
    print(f"Ticket 1 routed to: {state1['category']} | Response: {state1['response']}")

    state2 = app.invoke({"ticket_text": "My screen is blank.", "category": "", "response": ""})
    print(f"Ticket 2 routed to: {state2['category']} | Response: {state2['response']}")
```

### 4. Progressive Step-by-Step Breakdown

**Step 1: The Triage Node**
The `triage_node` uses an LLM to classify the text. Crucially, it saves this classification into the state (`{"category": category}`).

**Step 2: The Routing Function**
`route_ticket` is just a normal Python function. It takes the current `state`. It looks at `state["category"]`. It must return a string that perfectly matches the name of the node you want to go to next. The type hint `Literal["billing_node", "tech_node"]` is optional but great for catching typos.

**Step 3: `add_conditional_edges`**
Instead of `add_edge("triage", "billing")`, we say "From the 'triage' node, run the `route_ticket` function to figure out where to go next."

### 5. ASCII Data Flow

```text
               [Initial State]
        "ticket": "I was overcharged"
                      │
                      ▼
            ┌───────────────────┐
            │ NODE: triage      │──► Updates state: category = "BILLING"
            └───────────────────┘
                      │
                      ▼
         [ ROUTER: route_ticket() ]
           if category == "BILLING":
              return "billing_node"
           else:
              return "tech_node"
                      │
            ┌─────────┴─────────┐
            ▼                   ▼
    ┌──────────────┐    ┌──────────────┐
    │ billing_node │    │  tech_node   │
    └──────────────┘    └──────────────┘
            │                   │
            └─────────┬─────────┘
                      ▼
                    (END)
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Hardcoding Node strings in the router and making a typo. If `route_ticket` returns `"biling_node"` (missing an 'L'), LangGraph will crash at runtime because that node doesn't exist.
**Pro Tip:** You can pass a dictionary to `add_conditional_edges` to map the router's output to node names.
`builder.add_conditional_edges("triage", route_ticket, {"bill": "billing_node", "tech": "tech_node"})`
This allows your router to just return "bill", which is safer if you are parsing raw LLM output.

## Phase B: Engineering Challenges

### Level 1 Warm-Up
**Task:** Build a graph with a number validator. State is `{"number": int, "valid": bool}`. Node 1 generates a random number 1-10. Route function: if number > 5, go to `SuccessNode`, else go to `END`.
<details>
<summary>Hint</summary>
Your route function can return `"SuccessNode"` or `END` (which is a special imported constant).
</details>

<details>
<summary>Solution</summary>
```python
import random
from typing import TypedDict
from langgraph.graph import StateGraph, END

class NumState(TypedDict): number: int

def generate(state): return {"number": random.randint(1, 10)}
def success(state): print("Success!"); return {}

def router(state):
    if state["number"] > 5: return "success"
    return END

b = StateGraph(NumState)
b.add_node("gen", generate)
b.add_node("success", success)

b.set_entry_point("gen")
b.add_conditional_edges("gen", router)
b.add_edge("success", END)

app = b.compile()
app.invoke({"number": 0})
```
</details>

### Level 2 Real-World
**Task:** Build an Agent termination loop. State is `{"messages": list, "is_done": bool}`. The LLM generates a response. If the LLM includes the word "GOODBYE" in its response, `is_done` is True. Route: if `is_done`, go to `END`, else loop back to the LLM node.
<details>
<summary>Hint</summary>
You don't need a separate node to check the text. The LLM node can update `is_done: True` if "GOODBYE" is in the text. The router just reads `state["is_done"]`.
</details>

<details>
<summary>Solution</summary>
```python
from typing import TypedDict
from langgraph.graph import StateGraph, END

class ChatState(TypedDict):
    text: str
    is_done: bool

def llm_node(state):
    # Mocking LLM
    new_text = state["text"] + " hello"
    done = len(new_text) > 20 # Mock condition
    return {"text": new_text, "is_done": done}

def router(state):
    if state["is_done"]: return END
    return "llm"

b = StateGraph(ChatState)
b.add_node("llm", llm_node)
b.set_entry_point("llm")
b.add_conditional_edges("llm", router)

app = b.compile()
print(app.invoke({"text": "", "is_done": False}))
```
</details>

### Level 3 Boss Level (Cumulative)
**Task:** Zendesk Ticket Triage Router (from prompt). Combine Reducers (for a message log) and Routing. State has `ticket: str`, `category: str`, and `log: Annotated[list, add]`.
1. `Triage` node categorizes as 'Refund', 'Tech', or 'Spam'. (Updates log).
2. Route: Spam -> END. Refund -> `RefundNode`. Tech -> `TechNode`.
3. `RefundNode` and `TechNode` update the log with their actions and point to END.
<details>
<summary>Hint</summary>
Use a mapping dictionary in `add_conditional_edges` to map the raw category string to the specific node names or END.
</details>

<details>
<summary>Solution</summary>
```python
import operator
from typing import TypedDict, Annotated
from langgraph.graph import StateGraph, END

class ZenState(TypedDict):
    ticket: str
    category: str
    log: Annotated[list[str], operator.add]

def triage(state):
    cat = "Spam" if "win" in state["ticket"] else "Tech"
    return {"category": cat, "log": [f"Triaged as {cat}"]}

def tech_node(state): return {"log": ["Sent to tech."]}

def router(state):
    if state["category"] == "Spam": return END
    return "tech"

b = StateGraph(ZenState)
b.add_node("triage", triage)
b.add_node("tech", tech_node)
b.set_entry_point("triage")
b.add_conditional_edges("triage", router)
b.add_edge("tech", END)

app = b.compile()
print(app.invoke({"ticket": "win a prize", "category": "", "log": []}))
print(app.invoke({"ticket": "broken monitor", "category": "", "log": []}))
```
</details>
