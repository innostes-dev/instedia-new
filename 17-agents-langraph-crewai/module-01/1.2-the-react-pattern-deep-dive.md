# 1.2 The ReAct Pattern Deep Dive

## Phase A: Core Concept

### 1. Real-World Pain Point (The Why)
When you build standard text-generating LLMs, they often confidently hallucinate answers when they don't know the truth. If you ask an LLM for the current stock price of Apple, it might invent a number. We need a way to force the LLM to realize it doesn't know, actively search for the information using an external tool, and *then* formulate an answer. This requires an internal monologue that connects Reasoning to Action.

### 2. Plain English Metaphor (The What)
Imagine you are asked to bake a cake you've never baked before.
- **Reasoning:** "I don't know the recipe for a Black Forest cake. I need to look it up."
- **Action:** Open a cookbook and read the recipe.
- **Observation:** "Okay, the recipe requires cherries and chocolate."
- **Reasoning:** "I need to check if I have those."
This internal monologue mapping thoughts to actions to observations is exactly how the **ReAct (Reason + Act)** pattern works in LLMs.

### 3. Complete Runnable Code

```python
import os
from langchain_openai import ChatOpenAI
from langchain.agents import initialize_agent, AgentType
from langchain.tools import tool

os.environ["OPENAI_API_KEY"] = "your-api-key"
llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)

# Mocking Wikipedia for demonstration
@tool
def search_wikipedia(query: str) -> str:
    """Searches Wikipedia for the given query and returns a summary."""
    database = {
        "LangChain": "LangChain is a framework designed to simplify the creation of applications using large language models.",
        "ReAct Pattern": "ReAct is a paradigm that interleaves reasoning traces and task-specific actions."
    }
    return database.get(query, "No Wikipedia article found.")

agent = initialize_agent(
    [search_wikipedia],
    llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,
    verbose=True # Verbose is crucial to see the ReAct trace
)

if __name__ == "__main__":
    # The prompt forces the agent to use the tool
    response = agent.run("What is the ReAct Pattern according to Wikipedia?")
    print(f"\nFinal Output: {response}")
```

### 4. Progressive Step-by-Step Breakdown

**Step 1: The Prompt Setup (Hidden in LangChain)**
Under the hood, LangChain gives the LLM a highly specific prompt template. It looks something like:
`Use the following format: Question -> Thought -> Action -> Action Input -> Observation -> (Repeat) -> Final Answer`. This forces the LLM into the ReAct loop.

**Step 2: Generating the Thought and Action**
The LLM receives the user's question. It outputs:
*Thought: I need to search Wikipedia for the ReAct pattern.*
*Action: search_wikipedia*
*Action Input: ReAct Pattern*

**Step 3: Execution and Observation**
The LangChain framework intercepts the LLM's output, parses the Action and Input, and actually executes your Python function `search_wikipedia("ReAct Pattern")`. The string returned by your function is fed back to the LLM as the *Observation*. The LLM then generates its next *Thought*.

### 5. ASCII Data Flow

```text
User: "What is ReAct?"
      │
      ▼
┌─────────────────────────[ LLM Core ]─────────────────────────┐
│ 1. THOUGHT: "I don't know, I should search Wikipedia."       │
│ 2. ACTION: search_wikipedia                                  │
│ 3. ACTION INPUT: "ReAct Pattern"                             │
└────────────────┬───────────────────────────▲─────────────────┘
                 │ (LangChain intercepts)    │
                 ▼                           │
┌────────────────────────────────┐           │
│ Tool: search_wikipedia(query)  │──(Returns Observation)
└────────────────────────────────┘
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Ignoring "Parsing Errors". Sometimes the LLM fails to output exactly `Action:` or `Action Input:`. The agent will crash with an `OutputParserException`.
**Pro Tip:** Always use robust models (like GPT-4) for ReAct agents, or implement `handle_parsing_errors=True` when initializing the agent in LangChain so it can tell the LLM, "You formatted that wrong, try again."

### Level 2 Real-World
**Task:** Build a "Math Tutor Agent" with two tools: `add_numbers(a, b)` and `multiply_numbers(a, b)`. Ask it to solve `(15 + 7) * 3`. Watch the ReAct trace execute multiple steps.
<details>
<summary>Hint</summary>
Because tools usually take a single string input, you might need a tool that evaluates string expressions, or write your tool docstrings to instruct the LLM to pass inputs as a comma-separated string: "15, 7".
</details>

<details>
<summary>Solution</summary>
```python
from langchain_openai import ChatOpenAI
from langchain.agents import initialize_agent, AgentType
from langchain.tools import tool

@tool
def add_numbers(input_str: str) -> int:
    """Adds two numbers. Input should be a comma separated string, e.g. '5, 3'"""
    a, b = map(int, input_str.split(','))
    return a + b

@tool
def multiply_numbers(input_str: str) -> int:
    """Multiplies two numbers. Input should be a comma separated string, e.g. '5, 3'"""
    a, b = map(int, input_str.split(','))
    return a * b

llm = ChatOpenAI(temperature=0)
agent = initialize_agent([add_numbers, multiply_numbers], llm, agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION, verbose=True)
agent.run("What is (15 + 7) * 3?")
```
</details>

### Level 3 Boss Level (Cumulative)
**Task:** Build a "Stock Research Agent". It needs two tools: `get_stock_ticker(company_name)` which returns a ticker symbol, and `get_stock_price(ticker)` which returns the price. Ask it: "What is the stock price of Apple?". The agent must use ReAct to first find the ticker, then find the price.
<details>
<summary>Hint</summary>
Create mock dictionaries inside the tools. Ensure the docstrings clearly state that `get_stock_price` REQUIRES a ticker symbol, forcing the LLM to use the `get_stock_ticker` tool first.
</details>

<details>
<summary>Solution</summary>
```python
from langchain_openai import ChatOpenAI
from langchain.agents import initialize_agent, AgentType
from langchain.tools import tool

@tool
def get_stock_ticker(company_name: str) -> str:
    """Given a company name, returns its stock ticker symbol."""
    db = {"Apple": "AAPL", "Google": "GOOGL"}
    return db.get(company_name, "Unknown")

@tool
def get_stock_price(ticker: str) -> str:
    """Given a stock ticker symbol (e.g., AAPL), returns the current price."""
    db = {"AAPL": "$150", "GOOGL": "$2800"}
    return db.get(ticker, "Price not found.")

llm = ChatOpenAI(temperature=0)
agent = initialize_agent([get_stock_ticker, get_stock_price], llm, agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION, verbose=True)
agent.run("What is the current stock price of Apple?")
```
</details>
