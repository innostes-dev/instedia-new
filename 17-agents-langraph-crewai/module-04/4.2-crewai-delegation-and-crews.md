# 4.2 CrewAI Delegation and Crews

## Phase A: Core Concept

### 1. Real-World Pain Point (The Why)
In LangGraph, we had to manually build `StateGraphs`, define `TypedDict` states, write custom python router functions, and manage the edges to create a multi-agent team. This is highly customizable, but it requires a lot of boilerplate code. If you just want a standard hierarchical team where agents can talk to each other and pass tasks around without writing 100 lines of graph logic, LangGraph can feel too low-level.

### 2. Plain English Metaphor (The What)
Think of **LangGraph** like buying lumber, nails, and a hammer to build a house from scratch. You can build any shape you want, but you have to do the engineering.
Think of **CrewAI** like a pre-fabricated modular home. You just define the "Roles" (Agents) and the "Chores" (Tasks), and say "Go." CrewAI automatically builds the underlying communication graph, handles the prompt engineering for delegation, and ensures the tasks are completed in order.

### 3. Complete Runnable Code

```python
import os
from crewai import Agent, Task, Crew, Process
from langchain_openai import ChatOpenAI

os.environ["OPENAI_API_KEY"] = "your-api-key"
llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)

# 1. Define the Agents (The Roles)
researcher = Agent(
    role='Senior Market Analyst',
    goal='Gather comprehensive data on the target market.',
    backstory='You are a seasoned analyst at a Fortune 500 company known for finding hidden trends.',
    verbose=True,
    allow_delegation=False, # We don't want this agent giving its work to others
    llm=llm
)

writer = Agent(
    role='Content Strategist',
    goal='Draft compelling marketing content based on market research.',
    backstory='You are an award-winning copywriter who turns dry data into engaging stories.',
    verbose=True,
    allow_delegation=True, # The writer can ask the researcher for more info!
    llm=llm
)

# 2. Define the Tasks (The Chores)
research_task = Task(
    description='Analyze the current market demand for electric skateboards in 2024.',
    expected_output='A 3-bullet point summary of market demand.',
    agent=researcher # Assigning the task to the specific agent
)

writing_task = Task(
    description='Using the research provided, write a 1-paragraph Instagram ad for a new electric skateboard.',
    expected_output='A catchy Instagram caption with emojis.',
    agent=writer
)

# 3. Assemble the Crew
crew = Crew(
    agents=[researcher, writer],
    tasks=[research_task, writing_task],
    process=Process.sequential, # Tasks run in the order they are listed
    verbose=True # Shows the internal dialogue
)

# 4. Execute
if __name__ == "__main__":
    print("--- Crew Starting ---")
    result = crew.kickoff()
    print("\n--- Final Result ---")
    print(result)
```

### 4. Progressive Step-by-Step Breakdown

**Step 1: Agents and Prompts**
In CrewAI, you don't write system prompts manually. You provide `role`, `goal`, and `backstory`. Under the hood, CrewAI compiles these three strings into a massive, highly-optimized system prompt that forces the LLM to act exactly as described.

**Step 2: Tasks and Expected Output**
A `Task` is explicitly tied to an `Agent`. The `expected_output` parameter is crucial—it acts as a validation check. The agent will keep trying until its output matches the format requested. Because we chose a sequential process, the output of `research_task` is automatically injected into the prompt for `writing_task`.

**Step 3: Delegation**
Notice `allow_delegation=True` on the writer. CrewAI automatically gives the writer a tool called `delegate_work`. If the writer feels the research isn't good enough, it can use this tool to pause its own task and force the researcher to go find more data!

### 5. ASCII Data Flow

```text
       crew.kickoff()
             │
             ▼
   ┌──────────────────────┐
   │ Task 1: Research     │
   │ Agent: Researcher    │
   └──────────────────────┘
             │ (Returns 3 bullet points)
             ▼
   ┌──────────────────────┐   (Delegation Tool available!)
   │ Task 2: Writing      │ ────► "Hey Researcher, I need more info!"
   │ Agent: Writer        │ ◄──── "Here is more info."
   └──────────────────────┘
             │
             ▼
      [Final Output]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Using CrewAI when you need strict, deterministic control over the exact execution flow (like pausing for human approval at a very specific sub-step). CrewAI abstracts the control flow away from you. If you need complex conditional loops, use LangGraph.
**Pro Tip:** You can change `Process.sequential` to `Process.hierarchical`. This automatically creates a "Manager" agent (powered by the LLM) that reads the tasks and dynamically decides which agent should do what, completely overriding your manual agent assignments!

## Phase B: Engineering Challenges

### Level 1 Warm-Up
**Task:** Create a one-agent Crew. The agent is a `Joke Translator`. The task is to take the joke "Why did the chicken cross the road?" and translate it into French.
<details>
<summary>Hint</summary>
You only need one `Agent` and one `Task`. Set `allow_delegation=False`.
</details>

<details>
<summary>Solution</summary>
```python
from crewai import Agent, Task, Crew
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(temperature=0)
translator = Agent(
    role="French Translator",
    goal="Accurately translate text to French.",
    backstory="You are a native French speaker.",
    allow_delegation=False, llm=llm
)
task = Task(
    description="Translate this joke: 'Why did the chicken cross the road?'",
    expected_output="A French string.",
    agent=translator
)
crew = Crew(agents=[translator], tasks=[task])
print(crew.kickoff())
```
</details>

### Level 2 Real-World
**Task:** Tool Integration in CrewAI. Create a `Stock Analyst` agent. In LangChain/LangGraph we use `@tool`. CrewAI supports LangChain tools natively! Create a `@tool def get_stock_price(ticker): return "$150"`. Pass it to the Agent using `tools=[get_stock_price]`.
<details>
<summary>Hint</summary>
The `Agent` constructor takes a `tools` parameter.
</details>

<details>
<summary>Solution</summary>
```python
from langchain.tools import tool
from crewai import Agent, Task, Crew

@tool
def get_stock_price(ticker: str) -> str:
    """Returns the mock stock price for a ticker."""
    return f"{ticker} is currently at $150."

analyst = Agent(
    role="Stock Analyst",
    goal="Find stock prices.",
    backstory="Expert trader.",
    tools=[get_stock_price], # Injecting the tool here!
    allow_delegation=False,
    llm=ChatOpenAI(temperature=0)
)

task = Task(
    description="What is the price of AAPL?",
    expected_output="The dollar amount.",
    agent=analyst
)
crew = Crew(agents=[analyst], tasks=[task])
print(crew.kickoff())
```
</details>

### Level 3 Boss Level (Cumulative)
**Task:** Automated Marketing Campaign Content Crew.
Create 3 Agents: `Trend Analyzer`, `Copywriter`, and `SEO Specialist`.
Create 3 Sequential Tasks:
1. Find top 2 trends in fitness.
2. Write a blog post based on those trends.
3. Review the blog post and add SEO keywords.
Set `allow_delegation=True` on the SEO Specialist so they can push back on the Copywriter if the text is too short.
<details>
<summary>Hint</summary>
This is purely declarative. Define the 3 agents, the 3 tasks (linked to the agents), and put them in a `Crew(process=Process.sequential)`.
</details>

<details>
<summary>Solution</summary>
```python
from crewai import Agent, Task, Crew, Process
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(temperature=0.7)

trend_agent = Agent(role="Trend Analyzer", goal="Find fitness trends.", backstory="Trend expert.", llm=llm, allow_delegation=False)
copy_agent = Agent(role="Copywriter", goal="Write blogs.", backstory="Pro writer.", llm=llm, allow_delegation=True)
seo_agent = Agent(role="SEO Specialist", goal="Optimize blogs for search engines.", backstory="SEO master.", llm=llm, allow_delegation=True)

t1 = Task(description="Identify 2 current fitness trends.", expected_output="List of 2 trends.", agent=trend_agent)
t2 = Task(description="Write a 100-word blog post on the trends.", expected_output="A blog post draft.", agent=copy_agent)
t3 = Task(description="Review the draft and inject 3 SEO keywords.", expected_output="Final SEO blog post.", agent=seo_agent)

crew = Crew(
    agents=[trend_agent, copy_agent, seo_agent],
    tasks=[t1, t2, t3],
    process=Process.sequential
)

result = crew.kickoff()
print(result)
```
</details>
