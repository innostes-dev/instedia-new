# 2.1 Zoneless Reactivity & Signals

## Phase A: Concept & Application

### 1. Real-World Pain Point (The Why)
For a decade, Angular relied on `Zone.js` to trigger Change Detection. Zone.js worked by monkey-patching every browser API (`setTimeout`, `Promise`, DOM events). Whenever an event happened, Zone.js would tell Angular, "Something might have changed, check the entire component tree!"
In an Ultra-Fast Live Bidding & Stock Auction Ticker, where prices update 60 times a second, checking the entire DOM tree 60 times a second wastes massive amounts of CPU, causing battery drain, dropped frames, and a lagging UI. We need a way to tell Angular exactly *which* piece of data changed, so it only updates *that specific part* of the DOM, without checking everything else.

### 2. Plain English Metaphor (The What)
Imagine a massive 500-room hotel (your App).
**Zone.js** is like a security guard who, whenever a door opens or closes anywhere in the building, must run through all 500 rooms to check if a guest changed the TV channel. (Dirty Checking).
**Signals** are like putting a smart pager on the exact TV that changed. When the guest changes the channel on TV #402, the pager instantly notifies the front desk: "Update room 402's billing." The security guard never has to check the other 499 rooms. (Fine-Grained Reactivity).

### 3. Complete Runnable Code
Here is an Ultra-Fast Live Bidding & Stock Auction Ticker built using fine-grained Signals.

```typescript
import { Component, signal, OnInit, OnDestroy } from '@angular/core';

@Component({
  selector: 'app-auction-ticker',
  standalone: true,
  template: `
    <div class="auction-board">
      <header>
        <h2>Live Auction Ticker</h2>
        <!-- Reading the signal in the template requires calling it like a function: currentPrice() -->
        <div class="main-price" [class.flash-green]="isPriceUp()" [class.flash-red]="!isPriceUp()">
          {{ currentPrice() | currency:'USD' }}
        </div>
      </header>

      <div class="stats-grid">
        <div class="stat-box">
          <label>Highest Bidder</label>
          <div class="value">{{ highestBidder() }}</div>
        </div>
        <div class="stat-box">
          <label>Total Bids</label>
          <div class="value">{{ totalBids() }}</div>
        </div>
      </div>

      <div class="actions">
        <button class="bid-btn" (click)="placeBid(50)">+ $50</button>
        <button class="bid-btn" (click)="placeBid(100)">+ $100</button>
        <button class="bid-btn danger" (click)="resetAuction()">Reset</button>
      </div>
    </div>
  `,
  styles: [`
    .auction-board { max-width: 400px; margin: 2rem auto; font-family: system-ui; background: #0f172a; color: white; padding: 2rem; border-radius: 12px; box-shadow: 0 10px 25px rgba(0,0,0,0.5); }
    header { text-align: center; margin-bottom: 2rem; }
    h2 { margin: 0 0 1rem 0; color: #94a3b8; font-size: 1rem; text-transform: uppercase; letter-spacing: 2px; }
    .main-price { font-size: 3.5rem; font-weight: 800; font-variant-numeric: tabular-nums; transition: color 0.1s ease; }
    .stats-grid { display: grid; grid-template-columns: 1fr 1fr; gap: 1rem; margin-bottom: 2rem; }
    .stat-box { background: #1e293b; padding: 1rem; border-radius: 8px; text-align: center; }
    .stat-box label { display: block; font-size: 0.8rem; color: #64748b; margin-bottom: 0.5rem; }
    .stat-box .value { font-size: 1.25rem; font-weight: bold; }
    .actions { display: grid; grid-template-columns: 1fr 1fr 1fr; gap: 0.5rem; }
    .bid-btn { padding: 0.75rem; border: none; border-radius: 6px; font-weight: bold; cursor: pointer; background: #3b82f6; color: white; transition: background 0.2s; }
    .bid-btn:hover { background: #2563eb; }
    .danger { background: #ef4444; }
    .danger:hover { background: #dc2626; }
    .flash-green { color: #4ade80; }
    .flash-red { color: #f87171; }
  `]
})
export class AuctionTickerComponent implements OnInit, OnDestroy {
  // 1. Define Signals (The Reactive State)
  currentPrice = signal<number>(1000);
  highestBidder = signal<string>('Anonymous');
  totalBids = signal<number>(0);
  isPriceUp = signal<boolean>(true);

  private simInterval: any;

  ngOnInit() {
    // Simulate high-frequency market noise (Network data coming in)
    this.simInterval = setInterval(() => {
      // .update() derives the new value based on the old value
      this.currentPrice.update(price => {
        const volatility = (Math.random() * 10) - 4.5; // Up or down slightly
        this.isPriceUp.set(volatility >= 0); // .set() replaces the value entirely
        return price + volatility;
      });
    }, 150); // Updates ~6 times a second
  }

  ngOnDestroy() {
    clearInterval(this.simInterval);
  }

  placeBid(amount: number) {
    // Update multiple signals
    this.currentPrice.update(price => price + amount);
    this.totalBids.update(bids => bids + 1);
    this.highestBidder.set(`User_${Math.floor(Math.random() * 9000) + 1000}`);
    this.isPriceUp.set(true);
  }

  resetAuction() {
    // Reset signals to initial states
    this.currentPrice.set(1000);
    this.totalBids.set(0);
    this.highestBidder.set('Anonymous');
    this.isPriceUp.set(true);
  }
}
```

### 4. Progressive Step-by-Step Breakdown

**Step 1: Creating a Signal**
*Rationale: Instead of creating a standard class property `currentPrice = 1000;`, we wrap it in a `signal()`. This tells Angular to track this specific piece of data for changes.*
```typescript
import { signal } from '@angular/core';

// Writable signal initialized with 1000
currentPrice = signal<number>(1000);
```

**Step 2: Reading a Signal in the Template**
*Rationale: To access the value of a signal, you must call it like a getter function. By executing `currentPrice()`, Angular's template engine records a dependency. It now knows: "If `currentPrice` changes, I must re-render exactly this text node."*
```html
<div>{{ currentPrice() | currency }}</div>
```

**Step 3: Mutating a Signal (`.set()` vs `.update()`)**
*Rationale: You cannot do `this.currentPrice() = 1200`. You must use the Signal API.
Use `.set(newValue)` when you want to completely overwrite the value.
Use `.update(oldValue => newValue)` when the new value depends on the previous value.*
```typescript
// Overwrite
this.highestBidder.set('Alice');

// Derive from previous
this.totalBids.update(count => count + 1);
```

### 5. ASCII / Architecture Data Flow
```
[User Clicks "Bid $50"]
       |
       v
this.currentPrice.update(...) -> Signal value changes from 1000 -> 1050
       |
       v
[Angular Signal Graph]
Notifies ONLY the specific template node that registered a dependency:
       |
       v
DOM Node: <div class="main-price">{{ 1050 }}</div> (Patched Instantly)
       |
*Rest of the DOM tree is ignored. Zone.js dirty checking bypassed.*
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Forgetting the parentheses when reading a signal in a template (`{{ currentPrice }}`). Angular will render `[Function Signal]`, not the value!
**Pro Tip:** If you have an array or an object in a signal, do not mutate it directly (e.g., `this.users().push(newUser)`). Signals check for identity changes by default. Always create a new reference: `this.users.update(users => [...users, newUser])`.

## Phase B: Engineering Challenges

### Level 1 Warm-Up
**Task:** Convert standard component state to Signals.
You have a component with a counter:
```typescript
count = 0;
increment() { this.count++; }
```
Convert this to use a writable signal.

<details>
<summary>💡 Hint</summary>
Initialize with `signal(0)`. Use `.update()` in the increment method. Update the template to call the signal.
</details>

<details>
<summary>✅ Solution Walkthrough</summary>

```typescript
import { Component, signal } from '@angular/core';

@Component({
  selector: 'app-counter',
  standalone: true,
  template: `
    <button (click)="increment()">Count: {{ count() }}</button>
  `
})
export class CounterComponent {
  count = signal(0); // 1. Create signal

  increment() {
    // 2. Mutate signal
    this.count.update(c => c + 1);
  }
}
```

### Level 2 Real-World
**Task:** Build a `ThemeToggleComponent`. It should hold a signal for `theme` which can be `'light'` or `'dark'`.
1. Display "Current Theme: light" (or dark).
2. Create a button that toggles the theme.
3. Apply a CSS class (`dark-mode` or `light-mode`) to a wrapper div based on the signal's value.

<details>
<summary>💡 Hint</summary>
Use `.update()` to flip the string value. Use `[class.dark-mode]="theme() === 'dark'"` in the template.
</details>

<details>
<summary>✅ Solution Walkthrough</summary>

```typescript
import { Component, signal } from '@angular/core';

@Component({
  selector: 'app-theme-toggle',
  standalone: true,
  template: `
    <div class="wrapper" [class.dark-mode]="theme() === 'dark'" [class.light-mode]="theme() === 'light'">
      <p>Current Theme: {{ theme() }}</p>
      <button (click)="toggle()">Toggle Theme</button>
    </div>
  `,
  styles: [`
    .wrapper { padding: 2rem; transition: background 0.3s, color 0.3s; }
    .light-mode { background: white; color: black; }
    .dark-mode { background: #333; color: white; }
  `]
})
export class ThemeToggleComponent {
  theme = signal<'light' | 'dark'>('light');

  toggle() {
    this.theme.update(current => current === 'light' ? 'dark' : 'light');
  }
}
```

### Level 3 Boss Level (Cumulative)
**Task:** Combine Signals (2.1) and Control Flow (1.2).
Build a `TodoSignalComponent`.
1. Create a signal `todos` holding an array of objects: `{ id: number, text: string, done: boolean }`.
2. Use `@for` to render the list, displaying the text and a checkbox.
3. When the checkbox is clicked, trigger a `toggleDone(id)` method. Inside that method, use `.update()` on the `todos` signal to map over the array and flip the `done` status of the matching ID (remember to return a *new* array).
4. Include a button to add a new hardcoded todo to the list.

<details>
<summary>💡 Hint</summary>
To update an array signal immutably: `this.todos.update(list => list.map(t => t.id === id ? {...t, done: !t.done} : t))`.
</details>

<details>
<summary>✅ Solution Walkthrough</summary>

```typescript
import { Component, signal } from '@angular/core';

interface Todo { id: number; text: string; done: boolean; }

@Component({
  selector: 'app-todo-signal',
  standalone: true,
  template: `
    <div style="padding: 2rem;">
      <h2>Reactive Todo List</h2>
      <button (click)="addTodo()">Add "Learn Signals"</button>

      <ul style="list-style: none; padding: 0; margin-top: 1rem;">
        @for (todo of todos(); track todo.id) {
          <li style="margin-bottom: 0.5rem; display: flex; align-items: center; gap: 0.5rem;">
            <input
              type="checkbox"
              [checked]="todo.done"
              (change)="toggleDone(todo.id)">

            <span [style.text-decoration]="todo.done ? 'line-through' : 'none'">
              {{ todo.text }}
            </span>
          </li>
        } @empty {
          <li>No todos yet!</li>
        }
      </ul>
    </div>
  `
})
export class TodoSignalComponent {
  todos = signal<Todo[]>([
    { id: 1, text: 'Setup project', done: true },
    { id: 2, text: 'Master Control Flow', done: false }
  ]);

  nextId = 3;

  addTodo() {
    this.todos.update(list => [
      ...list,
      { id: this.nextId++, text: 'Learn Signals', done: false }
    ]);
  }

  toggleDone(id: number) {
    this.todos.update(list =>
      list.map(todo =>
        todo.id === id ? { ...todo, done: !todo.done } : todo
      )
    );
  }
}
```
</details>
