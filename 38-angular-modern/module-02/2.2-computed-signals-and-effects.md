# 2.2 Computed Signals and Effects

## Phase A: Concept & Application

### 1. Real-World Pain Point (The Why)
In complex forms like a Dynamic Multi-Currency Converter & Invoice Generator, you have base values (e.g., `basePrice`), but you also have derived values (e.g., `taxAmount`, `totalInUSD`, `totalInEUR`). Previously, developers either calculated these in a getter `get total() { ... }` (which executes on *every* single change detection cycle, destroying performance) or manually recalculated them inside an `ngOnChanges` or multiple `(change)` event handlers, leading to brittle, out-of-sync "stale state" bugs if you forgot to call `updateTotals()` in just one place. Furthermore, executing side-effects (like syncing to localStorage or logging) whenever a specific value changed required messy RxJS subscriptions that could leak memory.

### 2. Plain English Metaphor (The What)
Imagine a spreadsheet.
A **Writable Signal** (`signal()`) is a raw data cell (e.g., Cell A1 = 100, Cell B1 = 0.20).
A **Computed Signal** (`computed()`) is a formula cell (e.g., Cell C1 = A1 * B1). You never manually update Cell C1. It automatically recalculates *only* when A1 or B1 changes, and it caches the result so it doesn't recalculate if you just look at it repeatedly.
An **Effect** (`effect()`) is like a macro script. "Whenever Cell C1 changes, print the document." It performs an outside action (side-effect) in response to a signal changing.

### 3. Complete Runnable Code
Here is a Dynamic Multi-Currency Converter & Invoice Generator using `computed()` and `effect()`.

```typescript
import { Component, signal, computed, effect, untracked } from '@angular/core';

@Component({
  selector: 'app-invoice-generator',
  standalone: true,
  template: `
    <div class="invoice-container">
      <h2>Invoice Generator</h2>

      <div class="input-group">
        <label>Base Price (USD)</label>
        <input type="number" [value]="basePrice()" (input)="updatePrice($event)">
      </div>

      <div class="input-group">
        <label>Tax Rate (%)</label>
        <input type="range" min="0" max="25" [value]="taxRate()" (input)="updateTax($event)">
        <span>{{ taxRate() }}%</span>
      </div>

      <hr>

      <!-- All totals are Computed Signals. Fast and cached! -->
      <div class="totals">
        <div class="line"><span>Subtotal:</span> <span>{{ basePrice() | currency }}</span></div>
        <div class="line"><span>Tax Amount:</span> <span>{{ taxAmount() | currency }}</span></div>
        <div class="line total"><span>Total (USD):</span> <span>{{ totalUSD() | currency }}</span></div>
      </div>

      <div class="currency-converter">
        <h3>Pay in EUR</h3>
        <p>Exchange Rate: 1 USD = 0.92 EUR</p>
        <div class="total-eur">€{{ totalEUR() | number:'1.2-2' }}</div>
      </div>
    </div>
  `,
  styles: [`
    .invoice-container { font-family: sans-serif; max-width: 400px; margin: 2rem auto; padding: 2rem; border: 1px solid #e2e8f0; border-radius: 8px; box-shadow: 0 4px 6px rgba(0,0,0,0.1); }
    .input-group { display: flex; flex-direction: column; margin-bottom: 1rem; }
    .input-group label { font-size: 0.875rem; color: #475569; margin-bottom: 0.5rem; }
    input[type="number"] { padding: 0.5rem; border: 1px solid #cbd5e1; border-radius: 4px; }
    .totals { background: #f8fafc; padding: 1rem; border-radius: 4px; margin-bottom: 1.5rem; }
    .line { display: flex; justify-content: space-between; margin-bottom: 0.5rem; color: #334155; }
    .total { font-weight: bold; font-size: 1.25rem; color: #0f172a; border-top: 2px solid #e2e8f0; padding-top: 0.5rem; margin-top: 0.5rem; }
    .currency-converter { background: #eff6ff; border: 1px solid #bfdbfe; padding: 1rem; border-radius: 4px; text-align: center; }
    .total-eur { font-size: 1.5rem; font-weight: bold; color: #1d4ed8; margin-top: 0.5rem; }
  `]
})
export class InvoiceGeneratorComponent {
  // 1. Writable State
  basePrice = signal<number>(100);
  taxRate = signal<number>(10);
  exchangeRateEUR = 0.92; // Static constant for this example

  // 2. Derived State (Computed Signals)
  taxAmount = computed(() => {
    // Automatically recalculates when basePrice OR taxRate changes
    return this.basePrice() * (this.taxRate() / 100);
  });

  totalUSD = computed(() => {
    // Can compose other computed signals!
    return this.basePrice() + this.taxAmount();
  });

  totalEUR = computed(() => {
    return this.totalUSD() * this.exchangeRateEUR;
  });

  constructor() {
    // 3. Side Effects
    effect((onCleanup) => {
      // This runs once on initialization, and again whenever totalUSD changes.
      const currentTotal = this.totalUSD();
      console.log(`[Sync] Saving new total to local DB: $${currentTotal}`);

      // Example of untracked (read taxRate without triggering this effect if taxRate changes directly)
      const tax = untracked(this.taxRate);
      console.log(`Calculated with tax rate: ${tax}%`);

      // Cleanup logic if the effect runs again before the previous async action finishes
      const syncTimeout = setTimeout(() => console.log('Sync complete.'), 1000);
      onCleanup(() => clearTimeout(syncTimeout));
    });
  }

  // Template event handlers
  updatePrice(event: Event) {
    const val = (event.target as HTMLInputElement).value;
    this.basePrice.set(Number(val));
  }

  updateTax(event: Event) {
    const val = (event.target as HTMLInputElement).value;
    this.taxRate.set(Number(val));
  }
}
```

### 4. Progressive Step-by-Step Breakdown

**Step 1: Defining a `computed()` signal**
*Rationale: We declare `taxAmount` as a `computed`. We pass a function that reads `this.basePrice()` and `this.taxRate()`. Angular automatically registers these two signals as dependencies. If neither changes, `taxAmount()` returns a cached value instantly. It is read-only; you cannot `.set()` a computed signal.*
```typescript
taxAmount = computed(() => this.basePrice() * (this.taxRate() / 100));
```

**Step 2: Defining an `effect()`**
*Rationale: We want to log to the console every time the `totalUSD` changes. We put this in the `constructor()`. The `effect` function executes immediately, sees that we called `this.totalUSD()`, and says "Aha! I must re-run this function anytime `totalUSD` changes."*
```typescript
constructor() {
  effect(() => {
    console.log(`Total changed to: ${this.totalUSD()}`);
  });
}
```

**Step 3: Using `untracked` and `onCleanup`**
*Rationale: Sometimes we want to read a signal inside an effect *without* making it a dependency. We use `untracked(this.taxRate)`. Now, changing `taxRate` will *not* trigger the effect. `onCleanup` is used to cancel pending operations (like a timeout or HTTP request) if the effect is triggered again rapidly.*
```typescript
effect((onCleanup) => {
  const t = this.totalUSD();
  const tax = untracked(this.taxRate); // Reads value, doesn't trigger effect

  const timer = setTimeout(() => log(t), 1000);
  onCleanup(() => clearTimeout(timer)); // Clears old timer if total changes quickly
});
```

### 5. ASCII / Architecture Data Flow
```
[Writable Signals]
basePrice (100) -------+
                       |
taxRate (10) ----+     |
                 |     |
[Computed Graph] v     v
taxAmount() <--- (100 * 0.10) = 10
                 |
                 v
totalUSD() <---- (100 + 10) = 110
                 |
                 v
totalEUR() <---- (110 * 0.92) = 101.20
                 |
[Effect Graph]   v
effect() <------ totalUSD changed! -> console.log("Saving...")
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Using `effect()` to update other signals (e.g., `effect(() => { this.someOtherSignal.set(this.totalUSD() * 2); })`). By default, Angular forbids this and will throw an error `NG0600: Writing to signals is not allowed in a computed or an effect`. This prevents infinite loops.
**Pro Tip:** If state B depends on state A, B should be a `computed()`. Only use `effect()` for *outside interactions* like writing to LocalStorage, logging, updating Chart.js instances, or direct DOM manipulation that Angular doesn't control.

<details>
<summary>✅ Solution Walkthrough</summary>

```typescript
import { Component, signal, effect } from '@angular/core';

@Component({
  selector: 'app-theme-sync',
  standalone: true,
  template: `
    <button (click)="theme.set('dark')">Dark</button>
    <button (click)="theme.set('light')">Light</button>
    <p>Theme: {{ theme() }}</p>
  `
})
export class ThemeSyncComponent {
  // Initialize from storage or default
  theme = signal<string>(localStorage.getItem('themePrefs') || 'light');

  constructor() {
    // Syncs to storage automatically on every change
    effect(() => {
      const currentTheme = this.theme();
      localStorage.setItem('themePrefs', currentTheme);
      console.log('Saved to storage:', currentTheme);
    });
  }
}
```

### Level 3 Boss Level (Cumulative)
**Task:** Build a `FilteredProductList`.
1. Signals: `products` (array of objects with `category`), `searchTerm` (string), and `selectedCategory` (string 'All', 'Electronics', 'Clothing').
2. Computed: `filteredProducts`. It should filter the `products` array based on both the `searchTerm` (case insensitive match) AND the `selectedCategory`.
3. Effect: Write an effect that logs "Search analytics: [searchTerm]" to the console, BUT use `untracked` on `selectedCategory` so it only logs when the search term changes, not when the category changes.
4. UI: Use `@for` (1.2) to render the `filteredProducts`.

<details>
<summary>💡 Hint</summary>
Your computed will look like: `computed(() => this.products().filter(p => p.name.includes(this.searchTerm()) && (this.selectedCategory() === 'All' || p.category === this.selectedCategory())))`.
</details>

<details>
<summary>✅ Solution Walkthrough</summary>

```typescript
import { Component, signal, computed, effect, untracked } from '@angular/core';

interface Product { id: number; name: string; category: string; }

@Component({
  selector: 'app-filtered-products',
  standalone: true,
  template: `
    <div>
      <input type="text" [value]="searchTerm()" (input)="updateSearch($event)" placeholder="Search...">
      <select [value]="selectedCategory()" (change)="updateCategory($event)">
        <option value="All">All</option>
        <option value="Electronics">Electronics</option>
        <option value="Clothing">Clothing</option>
      </select>

      <ul>
        @for (product of filteredProducts(); track product.id) {
          <li>{{ product.name }} ({{ product.category }})</li>
        } @empty {
          <li>No products found.</li>
        }
      </ul>
    </div>
  `
})
export class FilteredProductsComponent {
  products = signal<Product[]>([
    { id: 1, name: 'Laptop', category: 'Electronics' },
    { id: 2, name: 'T-Shirt', category: 'Clothing' },
    { id: 3, name: 'Phone', category: 'Electronics' }
  ]);

  searchTerm = signal('');
  selectedCategory = signal('All');

  // Cached derivation based on two inputs
  filteredProducts = computed(() => {
    const term = this.searchTerm().toLowerCase();
    const category = this.selectedCategory();

    return this.products().filter(p => {
      const matchTerm = p.name.toLowerCase().includes(term);
      const matchCat = category === 'All' || p.category === category;
      return matchTerm && matchCat;
    });
  });

  constructor() {
    effect(() => {
      const term = this.searchTerm();
      // We untrack category so changing dropdown doesn't trigger the analytics log
      const cat = untracked(this.selectedCategory);
      if (term.length > 2) {
        console.log(`[Analytics] User searched for "${term}" in category "${cat}"`);
      }
    });
  }

  updateSearch(e: Event) { this.searchTerm.set((e.target as HTMLInputElement).value); }
  updateCategory(e: Event) { this.selectedCategory.set((e.target as HTMLSelectElement).value); }
}
```
</details>
