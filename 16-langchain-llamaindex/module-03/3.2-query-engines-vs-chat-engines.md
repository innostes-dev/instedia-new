# 3.2 Query Engines vs Chat Engines: Retrieval in Action

## Phase A: Core Concept

### 1. Real-World Pain Point (The Why)
Once you have chunked your documents into a Vector Database, how do you actually use them? If you just want to ask a one-off factual question ("What is the PTO policy?"), you need a system that fetches the right chunks and synthesizes an answer. But if a user wants to ask follow-up questions ("Does that apply to contractors too?"), a one-off query system will fail because it has no memory of the previous question.

### 2. Plain English Metaphor (The What)
A `QueryEngine` is like a **Search Engine with a built-in Summarizer**. You type a query, it finds the top 3 relevant documents, reads them, gives you an answer, and then immediately forgets you exist.
A `ChatEngine` is like a **Librarian sitting at a desk with you**. You ask a question, they fetch a book and answer. You ask a follow-up, they remember the context of the conversation, fetch another book if needed, and continue the dialogue.

### 3. Complete Runnable Code
```python
import os
from llama_index.core import VectorStoreIndex, Document

# (Assuming OPENAI_API_KEY is set in environment)

# 1. Create some dummy documents
docs = [
    Document(text="The company secret password is 'supernova'."),
    Document(text="Employees get 20 days of Paid Time Off (PTO) per year.")
]

# 2. Create the Index (Embeds text and stores in memory)
index = VectorStoreIndex.from_documents(docs)

print("--- QUERY ENGINE (One-off) ---")
# 3. Create a Query Engine
query_engine = index.as_query_engine()
response = query_engine.query("What is the password?")
print("Answer:", response)
# Follow-up will likely fail or ignore context
# print(query_engine.query("Is it case sensitive?"))

print("\n--- CHAT ENGINE (Stateful) ---")
# 4. Create a Chat Engine (Uses CondenseQuestion mode by default to handle memory)
chat_engine = index.as_chat_engine()
response1 = chat_engine.chat("How much PTO do I get?")
print("AI:", response1)

# 5. Follow-up question (The engine remembers!)
response2 = chat_engine.chat("Can I roll it over to next year?")
print("AI:", response2)
```

### 4. Progressive Step-by-Step Breakdown

*   **Step 1: The Index:** `VectorStoreIndex.from_documents` takes your documents, calls an Embedding Model (like OpenAI's `text-embedding-ada-002`) to turn text into numbers (vectors), and stores them in a Vector Database (by default, a simple in-memory dict).
*   **Step 2: `.as_query_engine()`:** This creates a pipeline that takes a string, embeds it, calculates cosine similarity against the database, retrieves the top `k` chunks, and stuffs them into a prompt for the LLM to synthesize an answer.
*   **Step 3: `.as_chat_engine()`:** This creates a more complex pipeline. When you ask a follow-up ("Can I roll it over?"), it first uses the LLM to *condense* the chat history and new question into a standalone query ("Can PTO be rolled over?"). It then runs *that* condensed query through the Vector Database.

### 5. ASCII Data Flow
```text
Query Engine (Stateless):
"What is PTO?" ──► [ Embed ] ──► [ Vector Search ] ──► (Nodes) ──► [ LLM ] ──► Answer

Chat Engine (Stateful):
History: ["How much PTO? -> 20 days"]
New Question: "Can I roll it over?"
       │
       ▼
[ Condense Question LLM ] ──► Generates: "Can PTO be rolled over?"
       │
       ▼
   [ Embed ] ──► [ Vector Search ] ──► (Nodes) ──► [ LLM ] ──► Answer
```

### 6. Noob Trap vs Pro Tip
*   **Noob Trap:** Using a `QueryEngine` in a UI where users expect a ChatGPT-like conversational experience. The bot will constantly misinterpret pronoun references like "it", "he", or "that".
*   **Pro Tip:** You can configure the `QueryEngine` to stream its responses back to the user token-by-token (just like ChatGPT) by using `query_engine = index.as_query_engine(streaming=True)`.

## Phase B: Engineering Challenges

### Level 1 Warm-Up: Inspecting Sources
**Task:** When a Query Engine answers, it uses source nodes. Run a query and print out the text of the chunks it used to generate the answer.
<details>
<summary>Hint</summary>
The returned `response` object has an attribute called `response.source_nodes`. Loop through it and print `node.node.text`.
</details>

**Solution:**
```python
from llama_index.core import VectorStoreIndex, Document

docs = [Document(text="The secret base is located in Antarctica.")]
index = VectorStoreIndex.from_documents(docs)

engine = index.as_query_engine()
response = engine.query("Where is the base?")

for source in response.source_nodes:
    print("Source Text:", source.node.text)
    print("Similarity Score:", source.score)
```

### Level 2 Real-World: Custom Top-K Retrieval
**Task:** By default, LlamaIndex fetches the top 2 most similar nodes. Configure a query engine to fetch the top 5 nodes instead.
<details>
<summary>Hint</summary>
Pass `similarity_top_k=5` as an argument to `index.as_query_engine()`.
</details>

**Solution:**
```python
from llama_index.core import VectorStoreIndex, Document

# Creating 10 dummy docs
docs = [Document(text=f"Fact number {i}") for i in range(10)]
index = VectorStoreIndex.from_documents(docs)

# Configure retriever to grab 5 chunks instead of 2
engine = index.as_query_engine(similarity_top_k=5)
response = engine.query("Give me some facts.")

print(f"Number of sources used: {len(response.source_nodes)}") # Should be 5
```

### Level 3 Boss Level: Corporate Policy Q&A Interactive Assistant
**Task:** Build a ChatEngine using `chat_mode="condense_plus_context"`. Pre-load a system prompt telling it to act as an HR representative.
<details>
<summary>Hint</summary>
Use `index.as_chat_engine(chat_mode="condense_plus_context", system_prompt="You are HR...")`.
</details>

**Solution:**
```python
from llama_index.core import VectorStoreIndex, Document

# 1. Knowledge Base
docs = [
    Document(text="Remote work is allowed up to 3 days a week."),
    Document(text="Hardware stipends are $500 per year for remote workers.")
]
index = VectorStoreIndex.from_documents(docs)

# 2. Advanced Chat Engine Initialization
# condense_plus_context is highly optimized for RAG chat
hr_bot = index.as_chat_engine(
    chat_mode="condense_plus_context",
    system_prompt=(
        "You are a polite Corporate HR Assistant. "
        "Only answer based on the provided context. If you don't know, say so."
    )
)

# 3. Simulate UI
print(hr_bot.chat("Can I work from home?").response)
print(hr_bot.chat("Do I get money for monitors?").response)
```
