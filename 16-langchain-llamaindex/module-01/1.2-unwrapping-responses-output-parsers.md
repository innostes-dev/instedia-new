# 1.2 Unwrapping Responses: Output Parsers

## Phase A: Core Concept

### 1. Real-World Pain Point (The Why)
LLMs output raw, unstructured text strings by default. If you need the AI to return a list of tags, a JSON object representing a product, or a specific enum value to use in your downstream application logic, you can't rely on raw strings. Parsing this string manually with regex or `.split()` is brittle because LLMs might add conversational filler (e.g., "Here is your JSON: ...").

### 2. Plain English Metaphor (The What)
Think of an `OutputParser` as a **Strict Customs Inspector** at a border crossing. The LLM is a traveler trying to bring luggage (data) into your application (the country). The customs inspector hands the traveler a specific declaration form (the format instructions) before they arrive. When the traveler presents their luggage, the inspector rigorously checks if it perfectly matches the declared structure (like a specific JSON schema). If it's messy, it might even force the traveler to go back and pack it correctly.

### 3. Complete Runnable Code
```python
from langchain_core.output_parsers import JsonOutputParser
from langchain_core.prompts import PromptTemplate
from langchain_openai import ChatOpenAI
from pydantic import BaseModel, Field

# 1. Define the desired structure using Pydantic
class Recipe(BaseModel):
    name: str = Field(description="The name of the recipe")
    ingredients: list[str] = Field(description="List of required ingredients")
    prep_time: int = Field(description="Preparation time in minutes")

# 2. Initialize Model and Parser
llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)
parser = JsonOutputParser(pydantic_object=Recipe)

# 3. Create prompt injecting formatting instructions
prompt = PromptTemplate(
    template="Provide a recipe for {dish}.\n{format_instructions}",
    input_variables=["dish"],
    partial_variables={"format_instructions": parser.get_format_instructions()},
)

# 4. Chain and Invoke (Using LCEL preview)
chain = prompt | llm | parser

# 5. Result is a clean Python dictionary matching the schema
result = chain.invoke({"dish": "spaghetti carbonara"})
print(type(result)) # <class 'dict'>
print(result['prep_time'])
```

### 4. Progressive Step-by-Step Breakdown

*   **Step 1: Defining Structure:** We use a Pydantic `BaseModel` to strictly define the schema we want. We specify types and add descriptions to help the LLM understand what each field means.
*   **Step 2: Parser Initialization:** We create a `JsonOutputParser` tied to our Pydantic schema. This parser has a magic method called `.get_format_instructions()` which generates the exact prompt text needed to tell the LLM how to format its output as JSON.
*   **Step 3: Prompt Injection & Execution:** We inject these instructions into our `PromptTemplate`. When the chain runs, the parser takes the raw `AIMessage` string returned by the LLM, strips away any markdown/conversational filler, and parses it cleanly into a Python dictionary.

### 5. ASCII Data Flow
```text
[ Desired Pydantic Schema ] ────────┐
                                    ▼
                          [ Output Parser ]
                                    │ generates instructions
                                    ▼
[ User Prompt ] ───────► [ Prompt Template ]
                                    │
                                    ▼
                             [ LLM ]
                                    │ raw string: "Here is your output: ```json {...} ```"
                                    ▼
                          [ Output Parser ]
                                    │ extracts, validates, parses
                                    ▼
                    [ Structured Python Dictionary/Object ]
```

### 6. Noob Trap vs Pro Tip
*   **Noob Trap:** Using basic `.replace("```json", "")` and `json.loads()` on LLM outputs. This breaks easily when the LLM gets conversational.
*   **Pro Tip:** Use `PydanticOutputParser` combined with LangChain's retry parsers in production. If the LLM returns invalid JSON, the retry parser will automatically feed the error back to the LLM to fix it!

## Phase B: Engineering Challenges

### Level 1 Warm-Up: The Simple String Cleanser
**Task:** Use a `StrOutputParser` to extract just the raw string content from an `AIMessage` object so you don't have to manually call `response.content`.
<details>
<summary>Hint</summary>
Chain `llm | StrOutputParser()`. `StrOutputParser` simply grabs `.content` from the message.
</details>

**Solution:**
```python
from langchain_core.messages import AIMessage
from langchain_core.output_parsers import StrOutputParser

# Simulating an LLM response
mock_response = AIMessage(content="Here is the summary you requested.")

parser = StrOutputParser()
clean_string = parser.invoke(mock_response)
print(clean_string) # "Here is the summary you requested."
```

### Level 2 Real-World: CSV Extractor
**Task:** Use the `CommaSeparatedListOutputParser` to get the LLM to generate a list of 5 SEO keywords for a given topic, returned as a Python list.
<details>
<summary>Hint</summary>
Initialize `CommaSeparatedListOutputParser`, get its format instructions, and inject them into a prompt.
</details>

**Solution:**
```python
from langchain_core.output_parsers import CommaSeparatedListOutputParser
from langchain_core.prompts import PromptTemplate
from langchain_openai import ChatOpenAI

parser = CommaSeparatedListOutputParser()

prompt = PromptTemplate(
    template="Generate 5 SEO keywords for {topic}.\n{format_instructions}",
    input_variables=["topic"],
    partial_variables={"format_instructions": parser.get_format_instructions()}
)

chain = prompt | ChatOpenAI(temperature=0) | parser
keywords = chain.invoke({"topic": "mechanical keyboards"})
print(type(keywords)) # <class 'list'>
print(keywords)
```

### Level 3 Boss Level: Structured Product Review Sentiment Extractor
**Task:** You have raw text reviews of a product. Extract the data into a strict schema: `sentiment` (enum: Positive, Negative, Neutral), `key_features_mentioned` (list of strings), and `score` (int 1-10). Use a JSON output parser.
<details>
<summary>Hint</summary>
Define a Pydantic model with these 3 fields. Use `JsonOutputParser(pydantic_object=...)`. Pass the raw review text to the prompt and enforce the schema.
</details>

**Solution:**
```python
from pydantic import BaseModel, Field
from typing import List, Literal
from langchain_core.output_parsers import JsonOutputParser
from langchain_core.prompts import PromptTemplate
from langchain_openai import ChatOpenAI

# 1. Define strict schema
class ReviewExtraction(BaseModel):
    sentiment: Literal["Positive", "Negative", "Neutral"] = Field(
        description="The overall sentiment of the review"
    )
    key_features_mentioned: List[str] = Field(
        description="List of specific product features mentioned (e.g. battery, screen)"
    )
    score: int = Field(description="Rating from 1 to 10 based on the review tone")

# 2. Setup parser and prompt
parser = JsonOutputParser(pydantic_object=ReviewExtraction)

prompt = PromptTemplate(
    template="Extract the data from this review:\n{review}\n\n{format_instructions}",
    input_variables=["review"],
    partial_variables={"format_instructions": parser.get_format_instructions()}
)

# 3. Chain
llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)
chain = prompt | llm | parser

# 4. Execute
raw_review = "The new smartphone is okay. The battery life is phenomenal, easily lasting two days. However, the screen is too dim in sunlight. I'd give it an average rating."
extracted_data = chain.invoke({"review": raw_review})

print(extracted_data)
# Output might look like:
# {'sentiment': 'Neutral', 'key_features_mentioned': ['battery life', 'screen'], 'score': 5}
```
