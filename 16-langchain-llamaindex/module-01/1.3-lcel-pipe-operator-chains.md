# 1.3 LCEL: The Pipe Operator Magic

## Phase A: Core Concept

### 1. Real-World Pain Point (The Why)
Building AI pipelines traditionally meant writing lots of boilerplate code: invoking a prompt, passing the result to an LLM, getting the response, passing it to a parser, checking for errors, etc. Doing this asynchronously or adding streaming capabilities meant duplicating massive chunks of complex code. Debugging deep chains of functions was a nightmare.

### 2. Plain English Metaphor (The What)
LangChain Expression Language (LCEL) uses the `|` (pipe) operator, much like **Unix command-line pipes**. Imagine an assembly line in a factory. Instead of manually carrying a part from the molding machine (Prompt) to the painting machine (LLM) to the packaging machine (Parser), you set up a continuous conveyor belt (`prompt | model | parser`). Data flows automatically from one station to the next, and LangChain handles the conveyor belt mechanics (streaming, async, parallel execution) for free under the hood.

### 3. Complete Runnable Code
```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

# 1. Define the components (The Factory Machines)
prompt = ChatPromptTemplate.from_template("Tell me a short joke about {topic}")
model = ChatOpenAI(model="gpt-3.5-turbo")
parser = StrOutputParser()

# 2. Chain them together with LCEL (The Conveyor Belt)
chain = prompt | model | parser

# 3. Execute the chain (Start the belt)
# The input dict flows into the prompt, output prompt flows into model,
# raw model message flows into parser, returning the final string.
result = chain.invoke({"topic": "wombats"})

print(result)
```

### 4. Progressive Step-by-Step Breakdown

*   **Step 1: The Components:** Every component in LangChain (Prompts, Models, Parsers, Retrievers) implements the "Runnable" protocol. This means they all share standard methods like `.invoke()`, `.stream()`, and `.batch()`.
*   **Step 2: The Pipe `|`:** When you use `a | b`, you create a new Runnable. The output of `a` is automatically passed as the input to `b`. It abstracts away the intermediate state management.
*   **Step 3: Unified Execution:** Because `chain` is itself a Runnable, calling `chain.invoke()` triggers the whole pipeline. Even better, you can call `chain.stream()` to stream tokens all the way through the parser directly to your user, with zero extra code logic!

### 5. ASCII Data Flow
```text
  Input Dict: {"topic": "wombats"}
         │
         ▼  ( flows into )
 ╭──────────────╮
 │    Prompt    │ formats the string
 ╰───────┬──────╯
         │  String: "Tell me a short joke about wombats"
         ▼
 ╭──────────────╮
 │     LLM      │ generates tokens
 ╰───────┬──────╯
         │  AIMessage: "Why do wombats..."
         ▼
 ╭──────────────╮
 │    Parser    │ extracts content
 ╰───────┬──────╯
         │
         ▼
  Final Output: "Why do wombats..." (String)
```

### 6. Noob Trap vs Pro Tip
*   **Noob Trap:** Using legacy chains like `LLMChain` or writing manual imperative code (`res = llm(prompt.format())`). These lack built-in streaming, async, and tracing support.
*   **Pro Tip:** LCEL supports parallel execution using `RunnableParallel`. You can branch a prompt out to two different LLMs simultaneously and merge their results, dramatically reducing latency.

## Phase B: Engineering Challenges

### Level 1 Warm-Up: The Basic Pipe
**Task:** Recreate the standard `prompt | model | parser` flow to ask for the capital of a `{country}`. Stream the output using `.stream()` instead of `.invoke()`.
<details>
<summary>Hint</summary>
Use `ChatPromptTemplate`, `ChatOpenAI`, and `StrOutputParser`. Iterate over `chain.stream({"country": "France"})` and `print(chunk, end="")`.
</details>

**Solution:**
```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

prompt = ChatPromptTemplate.from_template("What is the capital of {country}? Answer in one word.")
model = ChatOpenAI()
parser = StrOutputParser()

chain = prompt | model | parser

# Streaming output for free!
for chunk in chain.stream({"country": "Japan"}):
    print(chunk, end="", flush=True)
```

### Level 2 Real-World: RunnablePassthrough Context Injection
**Task:** Often you want to pass multiple variables, some computed dynamically. Use `RunnablePassthrough.assign()` to add a `language` variable to your input dictionary before it hits the prompt.
<details>
<summary>Hint</summary>
`chain = (RunnablePassthrough.assign(language=lambda x: "Spanish") | prompt | model | parser)`.
</details>

**Solution:**
```python
from langchain_core.runnables import RunnablePassthrough
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

prompt = ChatPromptTemplate.from_template("Say hello to {name} in {language}.")
model = ChatOpenAI()
parser = StrOutputParser()

# We only input 'name', 'language' is assigned dynamically in the chain
chain = (
    RunnablePassthrough.assign(language=lambda _: "Italian")
    | prompt
    | model
    | parser
)

print(chain.invoke({"name": "Mario"}))
```

### Level 3 Boss Level: 3-Step Content Summarization & Translation Chain
**Task:** Create a chain that takes a long block of `{text}`. First, it summarizes the text. Then, it takes that summary and translates it into `{target_language}`.
<details>
<summary>Hint</summary>
You will need two prompts and one model.
`chain = summary_prompt | model | StrOutputParser() | translation_prompt | model | StrOutputParser()`.
Use dictionary formatting between steps: `... | {"summary": RunnablePassthrough(), "target_language": itemgetter("target_language")} | translation_prompt ...` Wait, easier: just map the output of step 1 to the input of step 2.
</details>

**Solution:**
```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough
from operator import itemgetter

llm = ChatOpenAI(temperature=0)

# Step 1: Summarize
summary_prompt = ChatPromptTemplate.from_template("Summarize this text in 2 sentences:\n{text}")
summary_chain = summary_prompt | llm | StrOutputParser()

# Step 2: Translate
translate_prompt = ChatPromptTemplate.from_template("Translate this text into {target_language}:\n{summary}")
translate_chain = translate_prompt | llm | StrOutputParser()

# Compose them together.
# We take the initial dictionary, run the text through summary_chain,
# and pass the resulting string as 'summary', while keeping 'target_language' from the original input.
full_chain = (
    {"summary": summary_chain, "target_language": itemgetter("target_language")}
    | translate_chain
)

text_to_summarize = "The industrial revolution was a period of major industrialization and innovation during the late 1700s and early 1800s. It began in Great Britain and quickly spread throughout the world. This era saw the mechanization of agriculture and textile manufacturing and a revolution in power, including massive utilization of coal and steam."

result = full_chain.invoke({
    "text": text_to_summarize,
    "target_language": "French"
})

print(result)
```
