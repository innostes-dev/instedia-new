# 1.1 Chat Prompt Templates & Models: Escaping String-Concat Hell

## Phase A: Core Concept

### 1. Real-World Pain Point (The Why)
Manually concatenating strings for prompts (e.g., `f"You are an assistant. Answer this: {user_input}"`) becomes a chaotic mess in production. As your application scales, you need to manage different message roles (System, Human, AI), handle dynamic variables cleanly, and potentially switch between LLM providers (OpenAI, Anthropic, Google) that all expect slightly different API payloads. Raw string manipulation leads to fragile code, injection vulnerabilities, and vendor lock-in.

### 2. Plain English Metaphor (The What)
Think of `ChatPromptTemplate` as a professional set of **Fill-in-the-Blanks Mad-Libs** for robots. Instead of writing a messy letter from scratch every time, you have standardized forms with designated slots for instructions (System) and user input (Human). The unified LLM wrapper (`ChatOpenAI`, `ChatAnthropic`) acts as a universal translator—you hand it the filled-out form, and it seamlessly translates it into the specific API dialect the underlying AI model expects.

### 3. Complete Runnable Code
```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.messages import SystemMessage, HumanMessage

# Initialize the model (Unified Wrapper)
llm = ChatOpenAI(temperature=0.7, model="gpt-4")

# Create a ChatPromptTemplate
prompt_template = ChatPromptTemplate.from_messages([
    ("system", "You are an expert {role} who speaks exactly like a pirate."),
    ("human", "Please explain {topic} in one short sentence.")
])

# Format the prompt with variables
formatted_prompt = prompt_template.invoke({
    "role": "software engineer",
    "topic": "recursion"
})

# Invoke the model
response = llm.invoke(formatted_prompt)
print(response.content)
```

### 4. Progressive Step-by-Step Breakdown

*   **Step 1: Unifying the LLM:** We initialize `ChatOpenAI`. LangChain provides a standard interface (`invoke`, `stream`, `batch`) across all model providers. If we wanted to swap to Anthropic, we'd simply change the import and class to `ChatAnthropic` without touching the rest of our logic.
*   **Step 2: Structuring the Template:** `ChatPromptTemplate.from_messages` cleanly separates the `system` instructions from the `human` query. This maps directly to modern Chat API structures, preventing the model from confusing user data with core instructions.
*   **Step 3: Execution:** We format the template by passing a dictionary of variables to `.invoke()`. It replaces `{role}` and `{topic}` safely. We then pass the resulting formatted messages to our `llm` to get the AI's response.

### 6. Noob Trap vs Pro Tip
*   **Noob Trap:** Hardcoding API payloads using raw dictionaries and `f-strings` to build your conversation history.
*   **Pro Tip:** Use `.partial()` on your templates if certain variables (like the current date) are known early on, leaving the rest (like user input) to be filled out later at runtime.

## Phase B: Engineering Challenges

### Level 1 Warm-Up: The Friendly Translator
**Task:** Create a `ChatPromptTemplate` that translates a phrase from English into a target language provided as a variable.
<details>
<summary>Hint</summary>
Use a system message to set the role as a translator, and a human message to provide the text to translate. Variables should be `{language}` and `{text}`.
</details>

**Solution:**
```python
from langchain_core.prompts import ChatPromptTemplate

template = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful translator. Translate the given text into {language}."),
    ("human", "{text}")
])
formatted = template.invoke({"language": "French", "text": "Hello world!"})
print(formatted.messages)
```

### Level 2 Real-World: Customer Support Router Template
**Task:** Build a template that takes a `user_issue` and `customer_history`. The system prompt should instruct the AI to categorize the issue into "Billing", "Technical", or "General" based on the context.
<details>
<summary>Hint</summary>
Include instructions in the system prompt about the 3 categories. Pass the history and issue as distinct variables in the human message or system message.
</details>

**Solution:**
```python
from langchain_core.prompts import ChatPromptTemplate

router_template = ChatPromptTemplate.from_messages([
    ("system", "You are a customer support router. Categorize the user's issue into exactly one of: Billing, Technical, General. Consider their history: {customer_history}"),
    ("human", "Issue: {user_issue}\nCategory:")
])

prompt = router_template.invoke({
    "customer_history": "Premium user since 2021. Previous issue: password reset.",
    "user_issue": "My app keeps crashing on startup."
})
```

### Level 3 Boss Level: Modular Multi-LLM Prompt Template Engine
**Task:** Build a function that takes a provider name ("openai" or "anthropic") and a user question. It should use the exact same `ChatPromptTemplate` but invoke the corresponding LLM dynamically, demonstrating the power of unified wrappers.
<details>
<summary>Hint</summary>
Create a dictionary mapping strings like `"openai"` to instances of `ChatOpenAI` and `ChatAnthropic`. Define your template once, format it, then look up the chosen LLM from the dict and invoke it.
</details>

**Solution:**
```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_anthropic import ChatAnthropic

def get_answer(provider_name: str, question: str) -> str:
    # 1. Define the unified template once
    template = ChatPromptTemplate.from_messages([
        ("system", "You are a concise expert. Answer in exactly 3 bullet points."),
        ("human", "{question}")
    ])

    # 2. Map of unified models
    # (Assuming API keys are set in environment variables)
    models = {
        "openai": ChatOpenAI(model="gpt-3.5-turbo"),
        "anthropic": ChatAnthropic(model="claude-3-haiku-20240307")
    }

    if provider_name not in models:
        raise ValueError("Unsupported provider")

    llm = models[provider_name]

    # 3. Format and Invoke
    formatted_prompt = template.invoke({"question": question})
    response = llm.invoke(formatted_prompt)

    return response.content

# Example Usage:
# print(get_answer("openai", "How does a CPU work?"))
```
