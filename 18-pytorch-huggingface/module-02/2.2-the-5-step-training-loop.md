# The 5-Step Training Loop

## Phase A: Optimizers and the Loop

### 1. Real-World Pain Point (The Why)
We have a model structure (`nn.Module`), and we know how to get gradients (`autograd`). But manually updating thousands of weights using `w -= lr * w.grad` is tedious and inefficient. Modern AI uses advanced math to update weights (like momentum, adapting learning rates per parameter). You need a standardized, battle-tested engine to handle the actual weight updates during training.

### 2. Plain English Metaphor (The What)
Think of training an AI like navigating a blindfolded hiker down a mountain to reach the lowest valley (minimum loss).
* The **Model** is the hiker.
* The **Loss Function** is an altimeter telling the hiker how high up they are (how bad they are doing).
* **Autograd** is the hiker feeling the slope of the ground under their feet (gradients).
* The **Optimizer** is the brain deciding exactly how big of a step to take and in what direction based on the slope.

### 3. Complete Runnable Code
```python
import torch
import torch.nn as nn
import torch.optim as optim

def complete_training_loop():
    # --- SETUP ---
    # 1. Create Model
    model = nn.Linear(1, 1) # simple y = wx + b model

    # 2. Define Loss Function (Mean Squared Error)
    criterion = nn.MSELoss()

    # 3. Define Optimizer (Stochastic Gradient Descent)
    # We pass model.parameters() so the optimizer knows WHICH weights to update
    optimizer = optim.SGD(model.parameters(), lr=0.01)

    # Fake Data (y = 2x)
    inputs = torch.tensor([[1.0], [2.0], [3.0], [4.0]])
    targets = torch.tensor([[2.0], [4.0], [6.0], [8.0]])

    epochs = 100

    # --- THE TRAINING LOOP ---
    for epoch in range(epochs):

        # STEP 1: Forward Pass (Predict)
        predictions = model(inputs)

        # STEP 2: Compute Loss (Measure Error)
        loss = criterion(predictions, targets)

        # STEP 3: Zero Gradients (Clear old data)
        optimizer.zero_grad()

        # STEP 4: Backward Pass (Compute slope/gradients)
        loss.backward()

        # STEP 5: Optimizer Step (Update weights)
        optimizer.step()

        if (epoch+1) % 20 == 0:
            print(f'Epoch [{epoch+1}/{epochs}], Loss: {loss.item():.4f}')

    # Test the trained model
    print("\nFinal Weight:", model.weight.item())
    print("Final Bias:", model.bias.item())

if __name__ == "__main__":
    complete_training_loop()
```

### 4. Progressive Step-by-Step Breakdown

#### Step 1: The Optimizer
```python
optimizer = optim.SGD(model.parameters(), lr=0.01)
```
We instantiate an optimizer (SGD, Adam, AdamW, etc.). The most crucial part is handing it `model.parameters()`. This gives the optimizer a direct reference to all the weights inside your `nn.Module`.

#### Step 2: The 5-Step Loop
```python
predictions = model(inputs)           # 1. Forward
loss = criterion(predictions, targets)# 2. Loss
optimizer.zero_grad()                 # 3. Zero
loss.backward()                       # 4. Backward
optimizer.step()                      # 5. Step
```
This exact 5-step sequence is the heartbeat of 99% of PyTorch scripts.
1. Guess the answer.
2. See how wrong the guess was.
3. Clear the blackboard from the last math problem.
4. Do the calculus to find the gradients.
5. Move the weights based on the gradients.

#### Step 3: `optimizer.step()`
```python
optimizer.step()
```
This is where the magic happens. The optimizer looks at the `.grad` attribute of every parameter it was given, applies its specific mathematical formula (like momentum), and modifies the actual weights of the model.

### 5. ASCII Data Flow
```text
(Data) -> [ 1. Forward ] -> (Preds)
                              |
(Targets)-----------------> [ 2. Loss ]
                              |
[ 3. Zero Grad ]              V
                              |
[ 5. Step ] <--------- [ 4. Backward ]
(Updates weights)      (Computes grads)
```

### 6. Noob Trap vs Pro Tip
* **Noob Trap:** Putting `optimizer.zero_grad()` *after* `loss.backward()`. If you clear the gradients right after calculating them, `optimizer.step()` will have no gradients to use, and your model will never train.
* **Pro Tip:** In modern PyTorch, you can use `optimizer.zero_grad(set_to_none=True)`. Instead of setting gradients to zero, it completely removes the memory allocation, which is slightly faster and uses less VRAM.

```python
# ... setup ...
val_inputs = torch.tensor([[5.0], [6.0]])
val_targets = torch.tensor([[10.0], [12.0]])

for epoch in range(100):
    model.train() # Set to training mode
    # ... the 5 training steps ...

    if epoch % 10 == 0:
        model.eval() # Set to evaluation mode (affects Dropout/BatchNorm)
        with torch.no_grad(): # Disable autograd
            val_preds = model(val_inputs)
            val_loss = criterion(val_preds, val_targets)
            print(f"Epoch {epoch} | Train Loss: {loss.item():.4f} | Val Loss: {val_loss.item():.4f}")
```

### Level 3: Boss Level
**Challenge:** Implement **Gradient Accumulation**. Sometimes your model is so large that you can only fit a batch size of 2 on your GPU, but you mathematically need a batch size of 8 for stable training. Modify the training loop so that `optimizer.step()` only executes every 4 iterations.
<details>
<summary>Hint</summary>
Do not zero the gradients every loop. Only call `optimizer.step()` and `optimizer.zero_grad()` when `(batch_idx + 1) % 4 == 0`. Be sure to divide your loss by 4 before calling `.backward()` to average the gradients over the accumulated steps!
</details>

<details>
<summary>Solution Walkthrough</summary>
```python
import torch
import torch.nn as nn
import torch.optim as optim

model = nn.Linear(10, 2)
criterion = nn.MSELoss()
optimizer = optim.SGD(model.parameters(), lr=0.01)
accumulation_steps = 4

# Simulate a dataloader yielding 12 small batches
for step in range(12):
    # Fake batch of size 2
    inputs = torch.randn(2, 10)
    targets = torch.randn(2, 2)

    # 1. Forward
    outputs = model(inputs)

    # 2. Loss. Normalize by accumulation steps because
    # .backward() adds gradients by default.
    loss = criterion(outputs, targets)
    loss = loss / accumulation_steps

    # 3. Backward (Gradients accumulate here over 4 loops!)
    loss.backward()

    # 4 & 5. Step and Zero *ONLY* every 4th iteration
    if (step + 1) % accumulation_steps == 0:
        optimizer.step()
        optimizer.zero_grad()
        print(f"Optimizer stepped at step {step+1}!")
```
Gradient Accumulation is a crucial engineering trick. It allows you to simulate training with massive batch sizes (like 1024) even if your consumer GPU can only hold a batch size of 8 at a time.
</details>
