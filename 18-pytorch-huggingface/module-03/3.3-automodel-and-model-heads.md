# AutoModel & Model Heads

## Phase A: The Anatomy of a Transformer

### 1. Real-World Pain Point (The Why)
The `pipeline` is great for quick tests, but it acts like a black box. In real engineering, you need access to the raw mathematical outputs (logits or embeddings) to calculate custom loss functions, attach your own neural network layers, or extract dense representations (embeddings) for vector databases. You need to strip away the pipeline abstraction and interact with the pure PyTorch model.

### 2. Plain English Metaphor (The What)
Think of a Transformer model like a powerful, generic engine.
* The **Base Model** (e.g., `AutoModel`) is just the engine block. You put fuel (tokens) in, and it outputs raw mechanical energy (dense vectors/embeddings).
* The **Model Head** is the attachment you bolt onto the engine to do a specific job.
  * Bolt on a generator? Now it generates text (`AutoModelForCausalLM`).
  * Bolt on a sorting machine? Now it classifies text (`AutoModelForSequenceClassification`).

### 3. Complete Runnable Code
```python
import torch
from transformers import AutoTokenizer, AutoModelForSequenceClassification

def production_text_classifier():
    model_name = "distilbert-base-uncased-finetuned-sst-2-english"

    # 1. Load Tokenizer
    tokenizer = AutoTokenizer.from_pretrained(model_name)

    # 2. Load Model with a Sequence Classification "Head"
    # This automatically downloads the PyTorch weights and wraps it in an nn.Module
    model = AutoModelForSequenceClassification.from_pretrained(model_name)

    text = "Deploying Hugging Face models to production is incredibly satisfying."

    # 3. Tokenize input
    inputs = tokenizer(text, return_tensors="pt")

    # 4. Run the forward pass (Inference)
    # We use torch.no_grad() because we are predicting, not training!
    with torch.no_grad():
        # The model returns an object containing various outputs.
        # We want the raw, unnormalized scores: the 'logits'
        outputs = model(**inputs)
        logits = outputs.logits

    print(f"Raw Logits: {logits}")

    # 5. Convert Logits to Probabilities using Softmax
    probabilities = torch.nn.functional.softmax(logits, dim=-1)
    print(f"Probabilities: {probabilities}")

    # 6. Get the final predicted class
    predicted_class_id = torch.argmax(probabilities, dim=-1).item()

    # Look up the human-readable label from the model's config
    label = model.config.id2label[predicted_class_id]

    print(f"\nText: {text}")
    print(f"Prediction: {label} (Confidence: {probabilities[0][predicted_class_id]:.4f})")

if __name__ == "__main__":
    production_text_classifier()
```

### 4. Progressive Step-by-Step Breakdown

#### Step 1: Loading the specific Architecture
```python
model = AutoModelForSequenceClassification.from_pretrained(model_name)
```
Unlike the `pipeline`, we explicitly choose the architecture. This class takes the base DistilBERT engine and automatically bolts on a linear layer (the "head") designed for classifying the entire sequence into discrete categories.

#### Step 2: Unpacking Inputs
```python
outputs = model(**inputs)
```
`inputs` is a dictionary containing `input_ids` and `attention_mask`. The `**` operator in Python unpacks the dictionary, passing them as named arguments to the model's `forward` method: `model(input_ids=..., attention_mask=...)`.

#### Step 3: Logits to Probabilities
```python
probs = torch.nn.functional.softmax(logits, dim=-1)
```
Neural networks output raw numbers (Logits), like `[ -1.5, 2.3 ]`. These are hard to interpret. The Softmax function squashes these numbers into a probability distribution that always sums to 1.0 (e.g., `[0.02, 0.98]`), meaning "2% chance of class 0, 98% chance of class 1".

### 5. ASCII Data Flow
```text
[ "I am happy" ]
       |
  (Tokenizer)
       |
[ 101, 1045, 2572, 3407, 102 ] (Input IDs)
       |
[ Base Transformer Engine ]    (Produces dense contextual embeddings)
       |
[ Linear Classification Head ] (Compresses embeddings to 2 values)
       |
[ -2.1,  4.5 ]                 (Logits)
       |
   (Softmax)
       |
[ 0.01, 0.99 ]                 (Probabilities: 99% Positive)
```

### 6. Noob Trap vs Pro Tip
* **Noob Trap:** Using `AutoModel` when you want to do classification, or `AutoModelForSequenceClassification` when you want to generate text. The model will load, but the output shape will be entirely wrong for your task, or it will crash.
* **Pro Tip:** If you want to use a model like an embedding engine for a Vector Database (like Pinecone/Chroma), use the base `AutoModel`. It will return the raw hidden states (embeddings) instead of logits.

### Level 2: Real-World
**Challenge:** Extract embeddings. Load the base `bert-base-uncased` model using `AutoModel`. Pass a tokenized sentence through it. Extract the embedding vector for the `[CLS]` token (which is the very first token, at index 0). This specific vector is commonly used to represent the entire meaning of the sentence.
<details>
<summary>Hint</summary>
Use `AutoModel.from_pretrained()`. The output object will have a `.last_hidden_state` attribute of shape `(batch_size, sequence_length, hidden_size)`. Slice it to get the first token's vector.
</details>

<details>
<summary>Solution</summary>
```python
from transformers import AutoTokenizer, AutoModel
import torch

tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")
model = AutoModel.from_pretrained("bert-base-uncased")

inputs = tokenizer("Extract my meaning.", return_tensors="pt")

with torch.no_grad():
    outputs = model(**inputs)

# Shape is (batch_size=1, seq_len, hidden_size=768)
hidden_states = outputs.last_hidden_state

# Get the [CLS] token (batch 0, token 0, all hidden dimensions)
cls_embedding = hidden_states[0, 0, :]

print(f"CLS Embedding Shape: {cls_embedding.shape}") # torch.Size([768])
```
</details>

### Level 3: Boss Level
**Challenge:** Build an LLM Text Generator. Load a small causal language model, specifically `gpt2`. Write a loop that implements greedy decoding:
1. Pass a prompt to the model.
2. Get the logits for the very last token in the sequence.
3. Find the ID of the highest probability next token.
4. Append that ID to your input sequence.
5. Repeat 10 times to generate 10 new words.
*(Note: Do not use the built-in `model.generate()` method for this challenge!)*
<details>
<summary>Hint</summary>
Use `AutoModelForCausalLM.from_pretrained("gpt2")`. In the loop, `outputs.logits` has shape `(batch, seq_len, vocab_size)`. Get the logits for `[-1, :]` (the last token). Use `torch.argmax` to get the next ID, and `torch.cat` to append it to the `input_ids`.
</details>

<details>
<summary>Solution Walkthrough</summary>
```python
from transformers import AutoTokenizer, AutoModelForCausalLM
import torch

tokenizer = AutoTokenizer.from_pretrained("gpt2")
model = AutoModelForCausalLM.from_pretrained("gpt2")

prompt = "The future of artificial intelligence is"
input_ids = tokenizer(prompt, return_tensors="pt")["input_ids"]

print(f"Prompt: {prompt}")

# Generate 10 tokens manually
with torch.no_grad():
    for _ in range(10):
        # 1. Forward pass
        outputs = model(input_ids)

        # 2. Get logits for the LAST generated token
        next_token_logits = outputs.logits[0, -1, :]

        # 3. Greedy decoding: pick the highest probability token
        next_token_id = torch.argmax(next_token_logits)

        # 4. Append to the sequence
        # Reshape to (1, 1) to match input_ids batch dimension
        next_token_id = next_token_id.unsqueeze(0).unsqueeze(0)
        input_ids = torch.cat([input_ids, next_token_id], dim=1)

# Decode the final sequence
final_text = tokenizer.decode(input_ids[0], skip_special_tokens=True)
print(f"Generated: {final_text}")
```
You just wrote the core algorithm that powers ChatGPT! While production systems use optimized KV-caching and advanced sampling (like temperature or top-p), the fundamental loop of predicting the next token and appending it remains exactly the same.
</details>
