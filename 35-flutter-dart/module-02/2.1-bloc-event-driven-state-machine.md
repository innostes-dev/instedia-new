# 2.1 BLoC: Event-Driven State Machine

## Phase A: Core Concept

### 1. Real-World Pain Point (The Why)
As an app grows (like a multi-step food delivery checkout), relying entirely on `setState()` leads to "callback hell." You pass callbacks down through 5 layers of widgets just to update the total price when a user adds extra cheese. The UI becomes tightly coupled with business logic. Testing becomes impossible, and debugging a state change means hunting through dozens of UI files.

### 2. Plain English Metaphor (The What)
Imagine a bank.
- You (the **UI**) don't walk into the vault and grab cash yourself (`setState`).
- Instead, you write out a deposit slip (an **Event**) and hand it to the teller.
- The Teller (the **BLoC** - Business Logic Component) processes the slip, updates the ledger, and hands you a receipt (a **State**).
- You (the **UI**) look at the receipt and update your wallet amount based *only* on that receipt.

The UI only knows how to dispatch Events and draw States. The BLoC holds all the complex business logic (calculating taxes, applying promo codes).

### 3. Complete Runnable Code
Here is a production-grade multi-step checkout state machine using the `flutter_bloc` package.

```dart
import 'package:flutter/material.dart';
import 'package:flutter_bloc/flutter_bloc.dart';

void main() => runApp(const CheckoutApp());

// --- STATES ---
sealed class CheckoutState {}
class CheckoutInitial extends CheckoutState {}
class CheckoutLoading extends CheckoutState {}
class CheckoutSuccess extends CheckoutState {
  final double total;
  CheckoutSuccess(this.total);
}
class CheckoutError extends CheckoutState {
  final String message;
  CheckoutError(this.message);
}

// --- EVENTS ---
sealed class CheckoutEvent {}
class AddItemEvent extends CheckoutEvent {
  final double price;
  AddItemEvent(this.price);
}
class ApplyPromoCodeEvent extends CheckoutEvent {
  final String code;
  ApplyPromoCodeEvent(this.code);
}
class SubmitOrderEvent extends CheckoutEvent {}

// --- BLoC ---
class CheckoutBloc extends Bloc<CheckoutEvent, CheckoutState> {
  double currentTotal = 0.0;
  bool promoApplied = false;

  CheckoutBloc() : super(CheckoutInitial()) {
    on<AddItemEvent>((event, emit) {
      currentTotal += event.price;
      emit(CheckoutSuccess(currentTotal));
    });

    on<ApplyPromoCodeEvent>((event, emit) async {
      emit(CheckoutLoading()); // Show spinner while checking DB
      await Future.delayed(const Duration(seconds: 1)); // Simulate API

      if (event.code == 'DISCOUNT50' && !promoApplied) {
        currentTotal *= 0.5;
        promoApplied = true;
        emit(CheckoutSuccess(currentTotal));
      } else {
        emit(CheckoutError("Invalid or already applied code."));
        emit(CheckoutSuccess(currentTotal)); // Revert to showing total
      }
    });

    on<SubmitOrderEvent>((event, emit) async {
      emit(CheckoutLoading());
      await Future.delayed(const Duration(seconds: 2));
      // Simulate success
      emit(CheckoutInitial()); // Reset for next order
    });
  }
}

// --- UI ---
class CheckoutApp extends StatelessWidget {
  const CheckoutApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: BlocProvider(
        create: (_) => CheckoutBloc(),
        child: const CheckoutScreen(),
      ),
    );
  }
}

class CheckoutScreen extends StatelessWidget {
  const CheckoutScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Cart Checkout')),
      body: BlocConsumer<CheckoutBloc, CheckoutState>(
        listener: (context, state) {
          if (state is CheckoutError) {
            ScaffoldMessenger.of(context).showSnackBar(SnackBar(content: Text(state.message)));
          }
        },
        builder: (context, state) {
          if (state is CheckoutLoading) {
            return const Center(child: CircularProgressIndicator());
          }

          double total = 0;
          if (state is CheckoutSuccess) total = state.total;

          return Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              Text("Total: \$${total.toStringAsFixed(2)}", style: const TextStyle(fontSize: 32)),
              const SizedBox(height: 20),
              ElevatedButton(
                onPressed: () => context.read<CheckoutBloc>().add(AddItemEvent(10.0)),
                child: const Text("Add Burger (\$10)"),
              ),
              ElevatedButton(
                onPressed: () => context.read<CheckoutBloc>().add(ApplyPromoCodeEvent('DISCOUNT50')),
                child: const Text("Apply Promo Code"),
              ),
            ],
          );
        },
      ),
    );
  }
}
```

### 4. Progressive Step-by-Step Breakdown

**Step 1: Define Events and States (The Contract)**
*Rationale: By using `sealed` classes for states and events, we enforce that our UI and BLoC only communicate through strictly typed objects. The UI can't accidentally pass raw data.*
```dart
sealed class CheckoutState {}
sealed class CheckoutEvent {}
```
We define what the UI *can do* (Events: AddItem, ApplyPromo) and what the UI *can look like* (States: Loading, Success, Error).

**Step 2: Map Events to States in the BLoC**
*Rationale: The BLoC registers handlers via the `on<EventType>` syntax. When an event arrives, the BLoC runs business logic and pushes (`emit`) a new state down the stream.*
```dart
on<ApplyPromoCodeEvent>((event, emit) async {
  emit(CheckoutLoading());
  // ... business logic ...
  emit(CheckoutSuccess(currentTotal));
});
```
This is a state machine. It explicitly transitions from `Success` -> `Loading` -> `Success`.

**Step 3: Provide and Consume in the UI**
*Rationale: `BlocProvider` injects the BLoC into the widget tree. `BlocConsumer` rebuilds the UI (`builder`) when state changes AND handles one-off side effects like SnackBars (`listener`).*
```dart
BlocConsumer<CheckoutBloc, CheckoutState>(
  listener: (context, state) { ... show snackbar ... },
  builder: (context, state) { ... return UI ... }
)
```
The UI logic becomes declarative: "If state is Loading, show spinner. If state is Success, show total."

### 5. ASCII / Architecture Data Flow
```text
[ UI (Buttons) ]
       |
       | context.read<Bloc>().add( ApplyPromoCodeEvent )
       v
[ BLoC (Event Stream) ] -> on<ApplyPromoCodeEvent>
       |
       |-- Business Logic (API Calls, DB, Math)
       |
       | emit( CheckoutLoading ) ---> [ UI rebuilds: Spinner ]
       |
       | emit( CheckoutSuccess ) ---> [ UI rebuilds: New Total ]
       v
[ State Stream ]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Putting UI-specific things inside the BLoC state, like `emit(SuccessState(color: Colors.red))`. The BLoC should know *nothing* about Flutter UI concepts like Colors or Widgets. It should only emit data. The UI decides how to render that data.

**Pro Tip:** Use `BlocListener` or the `listener` callback in `BlocConsumer` for navigation (`Navigator.push`), showing dialogs, or SnackBars. If you try to navigate inside the `builder` function, Flutter will crash because `builder` must be a pure function that only returns Widgets.

### Level 1: Warm-Up
**Task:** Create a simple `CounterCubit` (a lighter version of BLoC that uses functions instead of events). It should hold an `int` state. Implement `increment()` and `decrement()` functions. Connect it to a basic UI using `BlocBuilder`.

<details>
<summary>Hint</summary>
A <code>Cubit</code> extends <code>BlocBase</code>. You define it as <code>class CounterCubit extends Cubit<int> { CounterCubit() : super(0); ... }</code> and call <code>emit(state + 1)</code>.
</details>

<details>
<summary>Full Solution</summary>

```dart
import 'package:flutter/material.dart';
import 'package:flutter_bloc/flutter_bloc.dart';

class CounterCubit extends Cubit<int> {
  CounterCubit() : super(0);
  void increment() => emit(state + 1);
  void decrement() => emit(state - 1);
}

void main() => runApp(
  MaterialApp(
    home: BlocProvider(
      create: (_) => CounterCubit(),
      child: const CounterView(),
    ),
  )
);

class CounterView extends StatelessWidget {
  const CounterView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: BlocBuilder<CounterCubit, int>(
          builder: (context, count) => Text('$count', style: const TextStyle(fontSize: 48)),
        ),
      ),
      floatingActionButton: Column(
        mainAxisAlignment: MainAxisAlignment.end,
        children: [
          FloatingActionButton(onPressed: () => context.read<CounterCubit>().increment(), child: const Icon(Icons.add)),
          const SizedBox(height: 8),
          FloatingActionButton(onPressed: () => context.read<CounterCubit>().decrement(), child: const Icon(Icons.remove)),
        ],
      ),
    );
  }
}
```

### Level 2: Real-World
**Task:** Build an Authentication BLoC.
States: `AuthInitial`, `AuthLoading`, `AuthAuthenticated(String token)`, `AuthUnauthenticated(String error)`.
Events: `LoginEvent(String user, String pass)`, `LogoutEvent()`.
In the UI, if authenticated, show a "Welcome" screen. If unauthenticated, show a Login button. If loading, show a spinner. (Simulate login with a Future.delayed).

<details>
<summary>Hint</summary>
Create the sealed classes for Event and State. Register <code>on<LoginEvent></code> in the Bloc, <code>emit(AuthLoading)</code>, wait 1 sec, then check credentials and emit Authenticated or Unauthenticated.
</details>

<details>
<summary>Full Solution</summary>

```dart
// States
sealed class AuthState {}
class AuthInitial extends AuthState {}
class AuthLoading extends AuthState {}
class AuthAuthenticated extends AuthState { final String token; AuthAuthenticated(this.token); }
class AuthUnauthenticated extends AuthState { final String error; AuthUnauthenticated(this.error); }

// Events
sealed class AuthEvent {}
class LoginEvent extends AuthEvent { final String user; final String pass; LoginEvent(this.user, this.pass); }
class LogoutEvent extends AuthEvent {}

// Bloc
class AuthBloc extends Bloc<AuthEvent, AuthState> {
  AuthBloc() : super(AuthInitial()) {
    on<LoginEvent>((event, emit) async {
      emit(AuthLoading());
      await Future.delayed(const Duration(seconds: 1));
      if (event.user == 'admin' && event.pass == '123') {
        emit(AuthAuthenticated('token_xyz'));
      } else {
        emit(AuthUnauthenticated('Invalid credentials'));
      }
    });

    on<LogoutEvent>((event, emit) {
      emit(AuthInitial());
    });
  }
}

// UI
class AuthApp extends StatelessWidget {
  const AuthApp({super.key});
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: BlocProvider(
        create: (_) => AuthBloc(),
        child: Scaffold(
          body: Center(
            child: BlocBuilder<AuthBloc, AuthState>(
              builder: (context, state) {
                if (state is AuthLoading) return const CircularProgressIndicator();
                if (state is AuthAuthenticated) {
                  return Column(
                    mainAxisSize: MainAxisSize.min,
                    children: [
                      Text('Welcome! Token: ${state.token}'),
                      ElevatedButton(onPressed: () => context.read<AuthBloc>().add(LogoutEvent()), child: const Text('Logout'))
                    ]
                  );
                }

                return Column(
                  mainAxisSize: MainAxisSize.min,
                  children: [
                    if (state is AuthUnauthenticated) Text(state.error, style: const TextStyle(color: Colors.red)),
                    ElevatedButton(
                      onPressed: () => context.read<AuthBloc>().add(LoginEvent('admin', '123')),
                      child: const Text('Login')
                    ),
                    ElevatedButton(
                      onPressed: () => context.read<AuthBloc>().add(LoginEvent('admin', 'wrong')),
                      child: const Text('Login (Fail)')
                    )
                  ],
                );
              }
            ),
          )
        )
      )
    );
  }
}
```

### Level 3: Boss Level
**Task:** Implement Debounce Search using Bloc `transformer`.
You have a `SearchBloc` with a `SearchTermChanged(String term)` event.
If a user types quickly, you don't want to hit the API on every single keystroke.
Using the `bloc_concurrency` package or `rxdart` (or just simulating it), modify the `on<SearchTermChanged>` registration so it ignores rapid events and only emits a new state if the user pauses typing for 500ms.

<details>
<summary>Hint</summary>
When registering the event handler: <code>on<SearchTermChanged>(..., transformer: restartable(), or using rxdart's debounceTime)</code>. You can write a custom transformer function using `Stream.transform`.
</details>

<details>
<summary>Full Solution</summary>

```dart
// Note: In a real project, add `rxdart: ^0.27.7` to pubspec.yaml
import 'package:flutter/material.dart';
import 'package:flutter_bloc/flutter_bloc.dart';
import 'package:rxdart/rxdart.dart';

// Event & State
class SearchEvent { final String query; SearchEvent(this.query); }
class SearchState { final String result; SearchState(this.result); }

// Custom Event Transformer for Debouncing
EventTransformer<Event> debounce<Event>(Duration duration) {
  return (events, mapper) => events.debounceTime(duration).switchMap(mapper);
}

class SearchBloc extends Bloc<SearchEvent, SearchState> {
  SearchBloc() : super(SearchState("Start typing...")) {
    on<SearchEvent>(
      (event, emit) async {
        // Simulate API call
        print("API CALL: ${event.query}"); // Only prints once per 500ms pause
        emit(SearchState("Results for: ${event.query}"));
      },
      // Apply the transformer here!
      transformer: debounce(const Duration(milliseconds: 500)),
    );
  }
}

class SearchApp extends StatelessWidget {
  const SearchApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: BlocProvider(
        create: (_) => SearchBloc(),
        child: const SearchScreen(),
      ),
    );
  }
}

class SearchScreen extends StatelessWidget {
  const SearchScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text("Debounced Search")),
      body: Padding(
        padding: const EdgeInsets.all(16.0),
        child: Column(
          children: [
            TextField(
              onChanged: (val) => context.read<SearchBloc>().add(SearchEvent(val)),
              decoration: const InputDecoration(border: OutlineInputBorder(), hintText: 'Search...'),
            ),
            const SizedBox(height: 20),
            BlocBuilder<SearchBloc, SearchState>(
              builder: (context, state) => Text(state.result, style: const TextStyle(fontSize: 24)),
            ),
          ],
        ),
      ),
    );
  }
}
```
