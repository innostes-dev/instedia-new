# Adding Images and Alt Text

## PHASE A: CONCEPT BREAKDOWN

### 1. The Real-World Pain Point / Trigger (The "Why")
Imagine scrolling through Instagram, but the server is down. Instead of a beautiful photo of a sunset, you just see a giant blank white square. Or worse, imagine a blind user relying on a screen reader visiting an e-commerce site to buy a shirt. The screen reader just says "image.jpg" because the developer didn't provide a description. The user has no idea if the shirt is red, striped, or long-sleeved, and immediately leaves the site.

### 2. Plain English Explanation & Physical Metaphor (The "What")
The `<img>` tag is used to embed an image into your webpage. It is a "self-closing" tag (it doesn't have an `</img>` part). The `src` attribute tells the browser where to fetch the image file. The `alt` (alternative text) attribute is a text description of the image used by screen readers and displayed if the image fails to load.
Think of the `<img>` tag as an empty picture frame. The `src` is the set of instructions telling the curator which painting to retrieve from the warehouse. The `alt` text is the plaque next to the frame describing the painting to someone who cannot see it.

### 3. Complete Working Runnable Code
```html
<article class="instagram-post">
  <header>
    <h2>Hiking in Yosemite</h2>
  </header>

  <!-- An accessible, descriptive image embed -->
  <img
    src="assets/yosemite-sunset.jpg"
    alt="A vibrant orange and purple sunset over Half Dome mountain in Yosemite Valley"
  >

  <p>The views from the valley floor are incredible today!</p>
</article>
```

### 4. Progressive Step-by-Step Code Breakdown

**Step 1: The Image Tag and Source**
```html
<img src="assets/yosemite-sunset.jpg">
```
*Why this comes first:* The `<img>` tag reserves the space, and the `src` attribute is mandatory. Without it, the browser doesn't know what file to fetch. Note that this is an empty tag; there is no text content inside it, so it doesn't need a closing tag.

**Step 2: The Alternative Text (Accessibility)**
```html
<img src="..." alt="A vibrant orange and purple sunset over Half Dome mountain">
```
*Why this is required next:* The `alt` text is legally required for accessibility compliance (WCAG) on modern web applications. If the image fails to load, this text appears in its place. Screen readers read this text aloud.

**Step 3: Decorative Images (Empty Alt Text)**
```html
<img src="divider-swirl.png" alt="">
```
*Why this is important:* If an image is purely decorative (like a swoosh graphic or a background pattern) and adds no meaning to the content, you MUST still include the `alt` attribute, but leave it completely empty (`alt=""`). This tells screen readers: "Ignore this image entirely, it's just decoration."

### 5. Behind-the-Scenes / Visual Data Flow
```text
Browser parser encounters <img> tag.
1. Checks `src`. Spawns a background network request to download "yosemite.jpg".
2. Continues rendering the rest of the HTML (doesn't wait for download).
3. If download succeeds: Paints pixels onto the screen.
4. If download fails: Renders the `alt` text string on the screen instead.
```

### 6. Noob Trap vs. Senior Pro Tip
**Noob Trap:** Writing `alt="Image of a sunset"` or `alt="Picture of a sunset"`. Screen readers already announce "Image" before reading the alt text. If you write "Image of...", the user hears "Image, Image of a sunset", which is redundant and annoying.
**Senior Pro Tip:** Write `alt` text as if you are describing the image over the phone to a friend. Be descriptive about the subject, context, and emotion, not the file type.

## PHASE B: PROGRESSIVE 3-LEVEL PRACTICE ARENA

### Level 1: Warm-Up
**Scenario:** A bio picture for a personal portfolio.
**Task:** Embed the image `profile.jpg` and add an appropriate `alt` description for a headshot of "Jane Doe smiling".
**Expected Output:** An `<img>` tag with `src` and `alt`.
<details>
<summary>Hint</summary>
Use `<img src="..." alt="...">`. Do not write "Picture of Jane".
</details>
<details>
<summary>Solution Walkthrough</summary>
```html
<img src="profile.jpg" alt="Jane Doe smiling professionally in a blue suit">
```
</details>

### Level 2: Real-World Scenario
**Scenario:** A blog post with a decorative thematic break image.
**Task:** Embed `flourish.png` but ensure screen readers skip it completely.
<details>
<summary>Hint</summary>
The `alt` attribute must exist, but be empty.
</details>
<details>
<summary>Solution Walkthrough</summary>
```html
<img src="flourish.png" alt="">
```
</details>

### Level 3: Boss Level
**Scenario:** Building an e-commerce product listing (combining Mod 1, 4, 5).
**Task:** Create an `<h2>` for "Nike Air Max". Below it, embed the image `sneaker.jpg` with good alt text. Below that, create a hyperlink to `checkout.html` that says "Buy Now".
<details>
<summary>Hint</summary>
Combine `<h2>`, `<img>`, and `<a>`.
</details>
<details>
<summary>Solution Walkthrough</summary>
```html
<h2>Nike Air Max</h2>
<img src="sneaker.jpg" alt="Red and black Nike Air Max sneaker viewed from the side">
<a href="checkout.html">Buy Now</a>
```
This is a standard, accessible layout for a product card.
</details>
