# Critical Keyword Emphasis

## PHASE A: CONCEPT BREAKDOWN

### 1. The Real-World Pain Point / Trigger (The "Why")
You are reading a critical AWS security alert: "Do not share your secret access key with anyone." If every word is plain text, a tired developer might skim right past it, push the key to GitHub, and cost the company $50,000 in crypto mining bills. You need a way to shout visually AND programmatically so screen readers elevate their pitch.

### 2. Plain English Explanation & Physical Metaphor (The "What")
HTML provides inline tags to change the meaning or importance of specific words within a sentence. `<strong>` indicates critical importance (usually bold), `<em>` adds emphasis/stress (usually italic), `<mark>` highlights text (like a yellow highlighter), and `<sub>`/`<sup>` lower or raise text for math/science.
Think of a paragraph as a spoken sentence. `<em>` is when you change your tone of voice, `<strong>` is when you speak louder, and `<mark>` is pointing a laser pointer at the word.

### 3. Complete Working Runnable Code
```html
<div class="security-banner">
  <h2>Action Required: Security Update</h2>
  <p>
    Your password will expire on <mark>Friday at midnight</mark>.
    You <strong>must</strong> update it immediately.
  </p>
  <p>
    <em>Please note:</em> the new password requires an equation
    like E=mc<sup>2</sup> or H<sub>2</sub>O to be included.
    <small>(Terms and conditions apply).</small>
  </p>
</div>
```

### 4. Progressive Step-by-Step Code Breakdown

**Step 1: Highlighting Text**
```html
Your password will expire on <mark>Friday at midnight</mark>.
```
*Why this comes first:* We need to draw the eye immediately to the deadline. `<mark>` highlights the text, making it stand out as highly relevant context.

**Step 2: Adding Strong Importance**
```html
You <strong>must</strong> update it immediately.
```
*Why this is required next:* The word "must" is critical. If the user misses it, they face consequences. `<strong>` tells the browser (and screen reader) that this is structurally important, not just visually bold.

**Step 3: Subscript and Superscript**
```html
E=mc<sup>2</sup> or H<sub>2</sub>O
```
*Why this follows:* `<sup>` (superscript) pushes the "2" up for exponents, and `<sub>` (subscript) pushes the "2" down for chemical formulas. Without these, it would read "E=mc2", which is mathematically incorrect.

### 5. Behind-the-Scenes / Visual Data Flow
```text
Browser encounters inline tags:
<p> text <strong> text </p>
The <p> is a BLOCK. It takes up the whole width.
The <strong> is INLINE. It flows within the block without breaking to a new line.

Visual output:
Your password will expire on [YELLOW BG: Friday at midnight].
```

### 6. Noob Trap vs. Senior Pro Tip
**Noob Trap:** Using `<b>` (bold) and `<i>` (italic) everywhere. These are legacy presentational tags. They just change the look, not the meaning.
**Senior Pro Tip:** Always use `<strong>` and `<em>`. They provide semantic meaning for SEO and accessibility. Only use `<b>` or `<i>` for visual styling when no semantic meaning is intended (though CSS is better for that).

## PHASE B: PROGRESSIVE 3-LEVEL PRACTICE ARENA

### Level 1: Warm-Up
**Scenario:** A discount banner needs emphasis.
**Task:** Make the word "FREE" strongly important and the words "Limited time" emphasized.
**Starting Code:**
```html
<p>Get a FREE trial today. Limited time offer.</p>
```
**Expected Output:** HTML with `<strong>` and `<em>`.
<details>
<summary>Hint</summary>
Wrap "FREE" in `<strong>` and "Limited time" in `<em>`.
</details>
<details>
<summary>Solution Walkthrough</summary>
```html
<p>Get a <strong>FREE</strong> trial today. <em>Limited time</em> offer.</p>
```
</details>

### Level 2: Real-World Scenario
**Scenario:** A math tutoring site is showing the Pythagorean theorem.
**Task:** Format a^2 + b^2 = c^2 correctly using superscript.
<details>
<summary>Hint</summary>
Use `<sup>` around the number 2s.
</details>
<details>
<summary>Solution Walkthrough</summary>
```html
<p>The theorem is: a<sup>2</sup> + b<sup>2</sup> = c<sup>2</sup></p>
```
</details>

### Level 3: Boss Level
**Scenario:** A complex medical warning (combining 1.1, 1.2, and 1.3).
**Task:** Create a heading "Dosage Warning", a paragraph with the chemical formula for water, a highlighted time restriction, and a strongly important instruction separated by a horizontal rule.
<details>
<summary>Hint</summary>
Combine `<h2>`, `<sub>`, `<mark>`, `<hr>`, and `<strong>`.
</details>
<details>
<summary>Solution Walkthrough</summary>
```html
<h2>Dosage Warning</h2>
<p>
  Take with a full glass of H<sub>2</sub>O.<br>
  Do not consume after <mark>8:00 PM</mark>.
</p>
<hr>
<p>Failure to follow instructions <strong>will</strong> cause side effects.</p>
```
</details>
