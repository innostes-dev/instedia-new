# Internal Page Jumps (Fragment Identifiers)

## PHASE A: CONCEPT BREAKDOWN

### 1. The Real-World Pain Point / Trigger (The "Why")
You are reading Stripe's API Reference documentation. It's a single HTML page that is 50,000 pixels tall. You want to read about "Refunds". Without a jump link, you have to scroll endlessly, straining your eyes to find the exact heading. If someone asks you for the link to the Refunds section, you can only give them the link to the top of the entire document and say, "Scroll down for 5 minutes."

### 2. Plain English Explanation & Physical Metaphor (The "What")
You can assign a unique `id` attribute to any HTML element. You can then use an anchor tag with an `href` pointing to that `#id` (called a fragment). When clicked, the browser instantly scrolls the page so that specific element is at the top of the screen.
Think of the `id` as a physical bookmark tucked into page 300 of a book. The `href="#bookmark"` is a magic button on the cover that instantly flips the book open to exactly page 300.

### 3. Complete Working Runnable Code
```html
<!-- The Table of Contents (The Magic Buttons) -->
<nav>
  <h2>API Documentation</h2>
  <ul>
    <li><a href="#authentication">1. Authentication</a></li>
    <li><a href="#pagination">2. Pagination</a></li>
    <li><a href="#refunds">3. Refunds</a></li>
  </ul>
</nav>

<!-- Lots of content causing scrolling... -->
<div style="height: 1000px;"></div>

<!-- The Target Destinations (The Bookmarks) -->
<h2 id="authentication">Authentication</h2>
<p>Use your secret API key to authenticate.</p>

<div style="height: 1000px;"></div>

<h2 id="pagination">Pagination</h2>
<p>Our API uses cursor-based pagination.</p>

<div style="height: 1000px;"></div>

<h2 id="refunds">Refunds</h2>
<p>Refunds can take 5-10 business days to process.</p>
```

### 4. Progressive Step-by-Step Code Breakdown

**Step 1: Setting the Target `id`**
```html
<h2 id="refunds">Refunds</h2>
```
*Why this comes first:* An `id` is a unique identifier. You cannot have two elements on the same page with `id="refunds"`. This creates the precise anchor point on the page.

**Step 2: Linking to the Target**
```html
<a href="#refunds">Go to Refunds</a>
```
*Why this is required next:* The hash symbol (`#`) inside the `href` instructs the browser: "Do not look for a new file. Look inside the current file for an element with this exact ID."

**Step 3: External Linking to a Fragment**
```html
<!-- Example of a link from a different page -->
<a href="https://api.stripe.com/docs#refunds">View Refunds</a>
```
*Why this is powerful:* You can combine absolute URLs with fragment identifiers. The browser will load the new page and *then* immediately scroll to the `#refunds` ID.

### 5. Behind-the-Scenes / Visual Data Flow
```text
URL Bar changes from:  yoursite.com/docs.html
To:                    yoursite.com/docs.html#refunds

Browser Engine:
1. Detects URL hash change.
2. Scans DOM for matching ID.
3. Calculates Y-axis position of that element.
4. Executes native scroll jump to that Y coordinate.
```

### 6. Noob Trap vs. Senior Pro Tip
**Noob Trap:** Using JavaScript (like `window.scrollTo`) to build table-of-contents navigation. It breaks native browser back-button behavior and fails if JS is disabled.
**Senior Pro Tip:** Use "Skip Links" for accessibility. Screen reader users hate listening to a 20-link navigation menu on every single page load. Place a link at the very top of your `<body>` that says `<a href="#main-content">Skip to Main Content</a>`. This is a mandatory WCAG accessibility requirement for modern apps.

## PHASE B: PROGRESSIVE 3-LEVEL PRACTICE ARENA

### Level 1: Warm-Up
**Scenario:** You have a footer at the bottom of a long page.
**Task:** Give the footer an ID and create a "Jump to bottom" link.
**Starting Code:**
```html
<a href="">Jump to bottom</a>
<!-- Long content -->
<footer>Copyright 2024</footer>
```
<details>
<summary>Hint</summary>
Add `id="bottom"` to the footer, and set the href to `#bottom`.
</details>
<details>
<summary>Solution Walkthrough</summary>
```html
<a href="#bottom">Jump to bottom</a>
<!-- Long content -->
<footer id="bottom">Copyright 2024</footer>
```
</details>

### Level 2: Real-World Scenario
**Scenario:** A Wikipedia article's table of contents.
**Task:** Create a link labeled "History" that jumps to an `<h2>` labeled "History of Rome".
<details>
<summary>Hint</summary>
You need both the `<a>` with a `#hash` and the `<h2>` with an `id`.
</details>
<details>
<summary>Solution Walkthrough</summary>
```html
<a href="#history">History</a>
<!-- Space -->
<h2 id="history">History of Rome</h2>
```
</details>

### Level 3: Boss Level
**Scenario:** Implementing the "Skip Link" pattern for accessibility.
**Task:** Create a link at the top that says "Skip to Content". Then create a main `<h1>` for the article titled "Breaking News". Ensure the link targets the heading correctly.
<details>
<summary>Hint</summary>
The link `href` must strictly match the heading's `id`.
</details>
<details>
<summary>Solution Walkthrough</summary>
```html
<a href="#main-article">Skip to Content</a>

<!-- Navigation menu would go here -->
<ul>
  <li>Home</li>
  <li>About</li>
</ul>

<h1 id="main-article">Breaking News</h1>
<p>Today's top story...</p>
```
Screen reader users will tab to the skip link, press enter, and instantly bypass the navigation menu, landing exactly on the `<h1>`.
</details>
