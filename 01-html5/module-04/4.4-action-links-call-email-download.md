# Action Links: Call, Email, Download

## PHASE A: CONCEPT BREAKDOWN

### 1. The Real-World Pain Point / Trigger (The "Why")
A user on a mobile phone searches for a local pizza restaurant. They find the website and see the phone number listed as plain text `<p>555-0199</p>`. They have to awkwardly try to highlight the text, copy it, switch to their phone app, and paste it. Half the time, they accidentally copy a space, the paste fails, and they give up and order from a competitor.

### 2. Plain English Explanation & Physical Metaphor (The "What")
HTML anchor tags aren't just for loading web pages. By changing the protocol in the `href` attribute (from `https:` to `mailto:` or `tel:`), you can trigger native applications on the user's operating system (like opening Apple Mail or launching the Android phone dialer). You can also use the `download` attribute to force a file to save to the hard drive instead of opening in the browser.
Think of these like specialized hotlines. Clicking a regular link opens a door to another room. Clicking a `tel:` link picks up the red emergency phone on the desk and dials directly.

### 3. Complete Working Runnable Code
```html
<div class="contact-card">
  <h2>Contact Yelp Support</h2>

  <p>
    <strong>Phone:</strong>
    <a href="tel:+18005550199">1-800-555-0199</a>
  </p>

  <p>
    <strong>Email:</strong>
    <a href="mailto:support@yelp.com?subject=Account%20Issue&body=Hello,%20I%20need%20help.">
      Email Support
    </a>
  </p>

  <p>
    <strong>Offline Resources:</strong>
    <a href="assets/yelp-menu-guide.pdf" download="Yelp_Guide_2024.pdf">
      Download the Menu Guide (PDF)
    </a>
  </p>
</div>
```

### 4. Progressive Step-by-Step Code Breakdown

**Step 1: The Telephone Link**
```html
<a href="tel:+18005550199">1-800-555-0199</a>
```
*Why this works:* The `tel:` protocol tells the operating system to open the default dialing app. Always use the international format (starting with `+` and the country code) in the `href` to ensure it works for users dialing from abroad.

**Step 2: The Mailto Link with Parameters**
```html
<a href="mailto:support@yelp.com?subject=Account%20Issue">Email Support</a>
```
*Why this is powerful:* The `mailto:` protocol opens the default email client (Outlook, Apple Mail, Gmail). You can append `?subject=` and `&body=` to pre-fill the email for the user. Note that spaces must be URL-encoded as `%20`.

**Step 3: The Download Attribute**
```html
<a href="assets/guide.pdf" download="Yelp_Guide_2024.pdf">Download</a>
```
*Why this is required:* Normally, if a browser can read a PDF or an image, clicking a link to it will open it directly in the browser tab. Adding the `download` attribute forces the browser to bypass displaying it and immediately prompt the user to save it to their hard drive. The value inside `download=""` allows you to rename the file on the user's computer.

### 5. Behind-the-Scenes / Visual Data Flow
```text
User clicks tel: link ---> Browser checks OS Registry for default "tel" handler
                      ---> OS launches Phone Dialer app
                      ---> OS passes "+18005550199" to Dialer

User clicks download link ---> Browser requests PDF from server
                          ---> Server sends PDF data
                          ---> Browser intercepts rendering engine, routes to File System
                          ---> Prompts "Save As" dialogue
```

### 6. Noob Trap vs. Senior Pro Tip
**Noob Trap:** Using `mailto:` on modern landing pages for lead generation. Spambots scrape web pages for `mailto:` links and will instantly flood that inbox with thousands of junk emails.
**Senior Pro Tip:** For B2C (Business to Consumer) contact pages, always use a `<form>` (Module 7) instead of `mailto:` to prevent spam. Only use `mailto:` for internal company directories behind a login, or when required by a specific design spec. However, `tel:` is incredibly crucial for mobile SEO and conversions.

## PHASE B: PROGRESSIVE 3-LEVEL PRACTICE ARENA

### Level 1: Warm-Up
**Scenario:** You need a clickable phone number for a local plumber.
**Task:** Create a link that calls `555-1234`.
**Starting Code:**
```html
<p>Call us today at 555-1234</p>
```
<details>
<summary>Hint</summary>
Wrap the number in an `<a>` tag with the `tel:` protocol.
</details>
<details>
<summary>Solution Walkthrough</summary>
```html
<p>Call us today at <a href="tel:5551234">555-1234</a></p>
```
</details>

### Level 2: Real-World Scenario
**Scenario:** A tech conference provides a digital ticket.
**Task:** Create a link to `ticket.png` that forces a download and renames the file to `My_Ticket.png`.
<details>
<summary>Hint</summary>
Use the `download` attribute with a value.
</details>
<details>
<summary>Solution Walkthrough</summary>
```html
<a href="ticket.png" download="My_Ticket.png">Download Ticket</a>
```
</details>

### Level 3: Boss Level
**Scenario:** Building an employee directory card.
**Task:** Create a heading with an employee's name. Below it, an unordered list. Item 1: A `mailto:` link to `john@company.com` pre-filled with the subject "Meeting". Item 2: A `tel:` link to their mobile.
<details>
<summary>Hint</summary>
Combine `<h2>`, `<ul>`, `<li>`, and `<a>` with specialized protocols and URL parameters.
</details>
<details>
<summary>Solution Walkthrough</summary>
```html
<h2>John Doe</h2>
<ul>
  <li><a href="mailto:john@company.com?subject=Meeting">Email John</a></li>
  <li><a href="tel:+1234567890">Call Mobile</a></li>
</ul>
```
This is a standard pattern for mobile-friendly contact cards.
</details>
