# Two-Dimensional Grids

## PHASE A: CONCEPT BREAKDOWN

### 1. The Real-World Pain Point / Trigger (The "Why")
You need to display a user's GitHub Git Commit History Log, comparing Branch Name, Date, and Author across 50 rows. If you use unordered lists (`<ul>`) inside standard paragraphs, the text won't align. The "Author" name on row 1 might start 30 pixels further to the right than the "Author" name on row 2, creating a jagged, unreadable mess of data. You need rigid, interlocking cells.

### 2. Plain English Explanation & Physical Metaphor (The "What")
The `<table>` tag creates a structured, two-dimensional grid of rows and columns. Inside the table, you define Table Rows (`<tr>`). Inside the rows, you define Table Data cells (`<td>`). For the top row headers, you use Table Header cells (`<th>`).
Think of a `<table>` as a physical Excel spreadsheet. `<tr>` tells the printer to move to the next horizontal line, and `<td>` tells it to fill in the individual rectangular boxes on that line.

### 3. Complete Working Runnable Code
```html
<section class="commit-log">
  <h2>Recent Commits</h2>

  <table border="1"> <!-- Border added temporarily just for visual learning -->

    <!-- The Header Row -->
    <tr>
      <th>Branch</th>
      <th>Date</th>
      <th>Author</th>
    </tr>

    <!-- Data Row 1 -->
    <tr>
      <td>main</td>
      <td>Oct 12</td>
      <td>Jane Doe</td>
    </tr>

    <!-- Data Row 2 -->
    <tr>
      <td>feature-login</td>
      <td>Oct 13</td>
      <td>John Smith</td>
    </tr>

  </table>
</section>
```

### 4. Progressive Step-by-Step Code Breakdown

**Step 1: The Table and Row Initialization**
```html
<table>
  <tr>
```
*Why this comes first:* `<table>` sets the boundaries of the grid. `<tr>` (Table Row) must be declared before you can place any data. You cannot put a column inside a table directly; you must build the table row by row, horizontal slice by horizontal slice.

**Step 2: The Header Cells**
```html
    <th>Branch</th>
    <th>Date</th>
    <th>Author</th>
  </tr>
```
*Why this is required next:* `<th>` (Table Header) is used for the column titles. Browsers automatically bold the text and center it. More importantly, screen readers announce these headers to blind users so they know what column they are navigating through.

**Step 3: The Data Cells**
```html
  <tr>
    <td>main</td>
    <td>Oct 12</td>
    <td>Jane Doe</td>
  </tr>
```
*Why this follows:* `<td>` (Table Data) populates the actual grid. **Critical rule:** The number of `<td>` elements in a row should perfectly match the number of `<th>` elements in the header row, otherwise the grid will collapse or display empty spaces.

### 5. Behind-the-Scenes / Visual Data Flow
```text
DOM Construction Rule: HTML Tables are built Horizontally, NOT Vertically.

Row 1 [ TR ]: (TH)Branch | (TH)Date   | (TH)Author
Row 2 [ TR ]: (TD)main   | (TD)Oct 12 | (TD)Jane Doe
```

### 6. Noob Trap vs. Senior Pro Tip
**Noob Trap:** Using tables to design the entire layout of a webpage (e.g., putting the navigation menu in the left column and the main content in the right column). This was how websites were built in 2002. It destroys accessibility and makes mobile responsiveness nearly impossible.
**Senior Pro Tip:** Use `<table>` strictly for **tabular data** (spreadsheets, logs, timetables, financial matrices). Use CSS Flexbox and Grid for page layout.

## PHASE B: PROGRESSIVE 3-LEVEL PRACTICE ARENA

### Level 1: Warm-Up
**Scenario:** A tiny 2x2 grid of fruit prices.
**Task:** Create a table with one row of headers ("Fruit", "Price") and one row of data ("Apple", "$1").
**Expected Output:** A `<table>` containing two `<tr>` elements, populated with `<th>` and `<td>`.
<details>
<summary>Hint</summary>
Row 1 gets `<th>`. Row 2 gets `<td>`.
</details>
<details>
<summary>Solution Walkthrough</summary>
```html
<table>
  <tr>
    <th>Fruit</th>
    <th>Price</th>
  </tr>
  <tr>
    <td>Apple</td>
    <td>$1</td>
  </tr>
</table>
```
</details>

### Level 2: Real-World Scenario
**Scenario:** Displaying business hours.
**Task:** Create a table. The first column is "Day" and the second is "Hours". Add rows for "Monday" (9am-5pm) and "Tuesday" (Closed).
<details>
<summary>Hint</summary>
You need 1 header row and 2 data rows. Ensure you have 2 columns per row.
</details>
<details>
<summary>Solution Walkthrough</summary>
```html
<table>
  <tr>
    <th>Day</th>
    <th>Hours</th>
  </tr>
  <tr>
    <td>Monday</td>
    <td>9am-5pm</td>
  </tr>
  <tr>
    <td>Tuesday</td>
    <td>Closed</td>
  </tr>
</table>
```
</details>

### Level 3: Boss Level
**Scenario:** An employee directory with nested links (combining Mod 1, 4, 6).
**Task:** Create a table with headers for "Name", "Role", and "Action". Add one data row for "Alice" and "Manager". In the "Action" column for Alice, add a `mailto:` hyperlink to `alice@company.com` with the text "Email Alice".
<details>
<summary>Hint</summary>
You can place any HTML element (like an `<a>` tag) inside a `<td>`.
</details>
<details>
<summary>Solution Walkthrough</summary>
```html
<table>
  <tr>
    <th>Name</th>
    <th>Role</th>
    <th>Action</th>
  </tr>
  <tr>
    <td>Alice</td>
    <td>Manager</td>
    <td><a href="mailto:alice@company.com">Email Alice</a></td>
  </tr>
</table>
```
This is how modern web dashboards render actionable data grids.
</details>
