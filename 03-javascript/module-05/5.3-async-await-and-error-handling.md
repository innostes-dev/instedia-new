# 5.3 Async/Await and Error Handling

## Phase A: Core Concept

### 1. Real-World Pain Point (The Why)
While `.then()` chains are better than nested callbacks, they still force you to write functions inside functions. The code drifts to the right, variables get trapped in `.then()` scopes, and it's hard to read top-to-bottom. We want async code to *look* like synchronous code.

### 2. Plain English Metaphor (The What)
- **`await`** is a **pause button** on a TV remote. When the engine hits `await`, it literally pauses the execution of that specific function until the Promise finishes. (The rest of the app outside the function keeps running).
- **`async`** is a warning label on the function that says: "Warning: This function contains pause buttons."
- **`try/catch`** is the safety net that catches any rejected promises that happen while paused.

### 3. Complete Runnable Code
```javascript
// Example: Stripe Payment Gateway Checkout Transaction

// A helper function simulating a database (returns a Promise)
function chargeCard(amount) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (amount > 100) reject("Insufficient funds.");
      else resolve({ receiptId: "TXN-999" });
    }, 1000);
  });
}

// 1. Mark the function as 'async'
async function checkout() {
  console.log("1. Checkout started.");

  // 2. Wrap risky 'await' calls in a try/catch block
  try {
    // 3. The 'await' pauses this function until chargeCard finishes!
    const result = await chargeCard(50);

    // 4. This line ONLY runs if chargeCard resolves successfully.
    console.log(`2. Success! Receipt: ${result.receiptId}`);

  } catch (error) {
    // 5. This block runs instantly if chargeCard REJECTS.
    console.log(`2. Failed: ${error}`);
  } finally {
    // 6. Finally ALWAYS runs, success or fail. Great for hiding spinners!
    console.log("3. Checkout process completed (UI Spinner hidden).");
  }
}

checkout();
console.log("0. This runs immediately! The UI isn't blocked.");
```

### 4. Progressive Step-by-Step Breakdown
**Step 1: The `async` Keyword**
You cannot use `await` unless the function is labeled `async`. Calling an `async` function automatically returns a Promise!
**Step 2: The `await` Keyword**
`const result = await chargeCard(50);` unpacks the Promise. It waits for the `resolve()` value, then assigns it directly to `result`. No `.then(result => ...)` needed!
**Step 3: `try / catch`**
Because we aren't using `.catch()`, a rejected promise will crash the app. We wrap the `await` inside a `try {}` block. If it rejects, JS teleports directly to the `catch (error) {}` block.
**Step 4: `finally`**
The `finally` block is optional but powerful. It runs regardless of success or failure. It's the standard place to write `spinner.hide()` or close database connections.

### 5. ASCII Data Flow
```text
checkout() Called
       |
[ try block starts ]
       |
await chargeCard(50) -----> PAUSE! Wait 1 second...
                                    |
                              [ RESOLVES ]
                                    |
                            (Unpauses)
                            result = { receiptId }
                                    |
[ finally block runs ]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Forgetting the `try/catch` block. If an `await` rejects and there is no `try/catch`, it results in an "Unhandled Promise Rejection" which will completely crash modern Node.js servers.
**Pro Tip:** Don't overuse `await`. If you need to fetch User A and User B, doing `await getUser(A)` followed by `await getUser(B)` takes 2 seconds (1s + 1s). They run sequentially. Use `Promise.all()` (covered in 5.5) to run them in parallel!

## Phase B: Engineering Challenges

### Level 1: Warm-Up
**Task:** Convert a `.then()` to `async/await`.
```javascript
function getRole() { return Promise.resolve("Admin"); }
// Convert this:
// getRole().then(role => console.log(role));
```
Write an `async function checkRole()` that `await`s the result and logs it.
<details>
<summary>Hint</summary>
`const role = await getRole(); console.log(role);`
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
function getRole() { return Promise.resolve("Admin"); }

async function checkRole() {
  const role = await getRole();
  console.log(role);
}

checkRole();
```
The code now reads top-to-bottom like synchronous code.
</details>

### Level 2: Real-World
**Task:** Write an `async function login(password)`.
Inside, create a `try/catch`.
In the `try`:
1. If password is strictly equal to `"123"`, throw a new Error: `throw new Error("Weak password")`.
2. Else, log "Login success".
In the `catch`: Log the error message (`error.message`).
<details>
<summary>Hint</summary>
You can manually `throw` errors inside a `try` block, and the `catch` will intercept them instantly!
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
async function login(password) {
  try {
    if (password === "123") {
      throw new Error("Weak password");
    }
    console.log("Login success");
  } catch (error) {
    console.log(`Failed: ${error.message}`);
  }
}

login("123"); // Failed: Weak password
```
`try/catch` catches *both* synchronous errors (like `throw`) and asynchronous Promise rejections!
</details>

### Level 3: Boss Level
**Task:** (Cumulative) Scope, Async, and Object parsing.
Assume `function fetchUser(id)` returns a Promise that resolves to `{ data: { user: { name: "Bob" } } }` for ID 1, and rejects with `"404"` for ID 2.
1. Write an `async function getUserName(id)`.
2. In the `try` block, `await fetchUser(id)`.
3. Use optional chaining (`?.`) to extract the name. If missing, default to "Guest" using `??`.
4. Log the name.
5. In the `catch` block, log "Error: [err]".
6. In a `finally` block, log "Fetch attempt finished".
<details>
<summary>Hint</summary>
`const res = await fetchUser(id); const name = res.data?.user?.name ?? "Guest";`
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
// Mock API function
function fetchUser(id) {
  return id === 1
    ? Promise.resolve({ data: { user: { name: "Bob" } } })
    : Promise.reject("404 Not Found");
}

async function getUserName(id) {
  try {
    // Wait for the data
    const response = await fetchUser(id);

    // Safely parse deeply nested data
    const name = response.data?.user?.name ?? "Guest";
    console.log(`Welcome, ${name}!`);

  } catch (error) {
    console.error(`Error: ${error}`);
  } finally {
    console.log("Fetch attempt finished.");
  }
}

getUserName(1); // Welcome, Bob! -> Fetch attempt finished.
// getUserName(2); // Error: 404... -> Fetch attempt finished.
```
This is the gold standard for fetching and parsing data in modern JavaScript frameworks (React, Vue, Node).
</details>
