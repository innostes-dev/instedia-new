# 5.5 Parallel Execution with Promise.all

## Phase A: Core Concept

### 1. Real-World Pain Point (The Why)
Your dashboard needs to fetch: User Profile (1 sec), Recent Orders (2 sec), and Notifications (1 sec).
If you write `await getProfile(); await getOrders(); await getNotifs();`, it takes 1 + 2 + 1 = **4 seconds** total. They run sequentially. This is a massive performance bottleneck. You want them to all start fetching at the exact same time!

### 2. Plain English Metaphor (The What)
`Promise.all()` is a **manager hiring a team**.
Instead of hiring one worker, waiting for them to finish, and then hiring the next (sequential), the manager hires 3 workers at once (parallel) and tells them to all go do their tasks. The manager then waits until the *slowest* worker is done, and collects all their results in a tidy array. The total time taken is only as long as the slowest task (2 seconds).

### 3. Complete Runnable Code
```javascript
// Example: Fast Dashboard Data Aggregator

// Mock API functions that take time
const fetchProfile = () => new Promise(res => setTimeout(() => res({ name: "Alice" }), 1000));
const fetchOrders  = () => new Promise(res => setTimeout(() => res([ {id: 1} ]), 2000)); // Slowest!
const fetchNotifs  = () => new Promise(res => setTimeout(() => res(["Alert!"]), 500));

async function loadDashboard() {
  console.time("Dashboard Load Time"); // Starts a performance timer

  try {
    // We pass an ARRAY of Promises into Promise.all()
    // It returns a single Promise that resolves to an ARRAY of results.
    // Order is preserved! index 0 is profile, index 1 is orders, etc.

    const [profile, orders, notifs] = await Promise.all([
      fetchProfile(),
      fetchOrders(),
      fetchNotifs()
    ]);

    console.log("Profile:", profile.name);
    console.log("Orders:", orders.length);
    console.log("Notifications:", notifs[0]);

  } catch (error) {
    // If ANY single promise rejects, the ENTIRE Promise.all fails instantly!
    console.error("Dashboard failed to load:", error);
  }

  console.timeEnd("Dashboard Load Time"); // Will log ~2000ms, not 3500ms!
}

loadDashboard();
```

### 4. Progressive Step-by-Step Breakdown
**Step 1: The Array of Promises**
We call the functions `fetchProfile()` to *start* the promises, and put those pending promises into an array: `[ promise1, promise2, promise3 ]`.
**Step 2: `Promise.all()`**
We `await Promise.all(...)`. The engine fires them off simultaneously. It waits exactly 2000ms (the time of the slowest promise, `fetchOrders`).
**Step 3: Array Destructuring**
`Promise.all` returns an array of results. We use `const [profile, orders, notifs] =` to instantly unpack that array into nicely named variables, based on their index position.
**Step 4: The Catch**
`Promise.all` is "All or Nothing" (Fail-Fast). If *one* promise rejects, it skips to the `catch` block immediately, ignoring any successful promises.

### 5. ASCII Data Flow
```text
Promise.all( [ P1, P2, P3 ] )
               |   |   |
( 500ms)       |   |   +--> Done (Notifs)
(1000ms)       +--> Done (Profile)
(2000ms)           |
                   v
               Done (Orders)
                   |
     RETURNS [ profileData, orderData, notifData ]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Using `Promise.all` when you don't actually care if one fails. If a non-critical notification fetch fails, you don't want the whole dashboard to crash!
**Pro Tip:** Use `Promise.allSettled()` instead of `Promise.all()` for independent tasks. It waits for all to finish, and returns an array showing which ones succeeded and which ones failed, without throwing an error!

## Phase B: Engineering Challenges

### Level 1: Warm-Up
**Task:** Create two promises: `p1 = Promise.resolve("Apple")` and `p2 = Promise.resolve("Banana")`. Use `Promise.all` to await them both, and log the resulting array.
<details>
<summary>Hint</summary>
`const results = await Promise.all([p1, p2]); console.log(results);`
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
async function run() {
  const p1 = Promise.resolve("Apple");
  const p2 = Promise.resolve("Banana");

  const results = await Promise.all([p1, p2]);
  console.log(results); // ["Apple", "Banana"]
}
run();
```
Combines multiple asynchronous sources into a single synchronous array.
</details>

### Level 2: Real-World
**Task:** You need to fetch data for User 1 and User 2 at the same time.
Write an async function. Create an array of two fetch Promises: `fetch("https://jsonplaceholder.typicode.com/users/1")` and `fetch(".../users/2")`.
Await them with `Promise.all`.
(Bonus: The result is an array of `Response` objects. Map over them and call `.json()` on each to get the data!).
<details>
<summary>Hint</summary>
`const [res1, res2] = await Promise.all([fetch(url1), fetch(url2)]);`
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
async function getTwoUsers() {
  try {
    const urls = [
      "https://jsonplaceholder.typicode.com/users/1",
      "https://jsonplaceholder.typicode.com/users/2"
    ];

    // 1. Fetch in parallel
    const [res1, res2] = await Promise.all([ fetch(urls[0]), fetch(urls[1]) ]);

    // 2. Parse JSON in parallel! (.json() returns promises too!)
    const [user1, user2] = await Promise.all([ res1.json(), res2.json() ]);

    console.log(user1.name, "&", user2.name);
  } catch (err) {
    console.log("Error:", err);
  }
}
// getTwoUsers();
```
This is drastically faster than awaiting `res1`, then awaiting `res2`.
</details>

### Level 3: Boss Level
**Task:** (Cumulative) Dynamic Parallel Data Fetching.
You have an array of IDs: `const ids = [1, 2, 3]`.
You want to fetch all three users from `https://jsonplaceholder.typicode.com/users/[id]`.
1. Use `.map()` on the `ids` array. For each `id`, return the `fetch(...)` Promise! (You now have an array of pending Promises).
2. Pass that mapped array directly into `Promise.all()`.
3. Loop over the resulting responses, checking `.ok`.
4. Use another `Promise.all` mapped over `.json()` to parse them.
<details>
<summary>Hint</summary>
`const fetchPromises = ids.map(id => fetch(url + id));`
`const responses = await Promise.all(fetchPromises);`
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
async function getManyUsers(ids) {
  const baseUrl = "https://jsonplaceholder.typicode.com/users/";

  try {
    // 1. Map IDs to an array of FETCH PROMISES
    const fetchPromises = ids.map(id => fetch(baseUrl + id));

    // 2. Await all fetches in parallel
    const responses = await Promise.all(fetchPromises);

    // 3. Validate
    responses.forEach(res => {
      if (!res.ok) throw new Error("A request failed");
    });

    // 4. Map Responses to JSON PROMISES and await them in parallel
    const jsonPromises = responses.map(res => res.json());
    const users = await Promise.all(jsonPromises);

    // Final Array of Data!
    const names = users.map(u => u.name);
    console.log("Fetched names:", names);

  } catch (err) {
    console.error("Batch fetch failed:", err);
  }
}

// getManyUsers([1, 2, 3]);
```
This is the pinnacle of asynchronous JavaScript. Taking a dynamic array of IDs, fanning out N network requests in parallel, gathering them, parsing them in parallel, and formatting the results immutably.
</details>
