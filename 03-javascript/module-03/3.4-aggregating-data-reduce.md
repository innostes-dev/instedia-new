# 3.4 Array.reduce() - The Aggregator

## Phase A: Core Concept

### 1. Real-World Pain Point (The Why)
You have an array of cart items: `[ {price: 10}, {price: 20} ]`. `.map()` gives you a new array. `.filter()` gives you a subset array. But what if you want a SINGLE value, like the total sum of the cart? You could use a `for` loop with a global `let total = 0`, but functional programming demands a pure method to squash an array down into one value.

### 2. Plain English Metaphor (The What)
`Array.reduce()` is a **snowball rolling down a hill**.
It starts as a small core (the starting value). As it rolls over every item in the array, it packs that item's data into the snowball (the accumulator). When it reaches the bottom, you have one giant snowball (the final total).

### 3. Complete Runnable Code
```javascript
// Example: Cart Grand Total & Tax Summary Aggregator
const cart = [
  { item: "Book", price: 20 },
  { item: "Pen", price: 5 },
  { item: "Bag", price: 50 }
];

// Reduce takes TWO arguments:
// 1. A callback function (accumulator, currentItem) => {}
// 2. A starting value (e.g., 0)

const grandTotal = cart.reduce((accumulator, currentItem) => {
  // Read the current item's price
  const itemPrice = currentItem.price;

  // Add it to the snowball (accumulator)
  const newSnowballSize = accumulator + itemPrice;

  // You MUST return the new accumulator,
  // which is passed to the next cycle!
  return newSnowballSize;

}, 0); // <-- This 0 is the starting value of the snowball!

console.log(`Total: $${grandTotal}`); // Total: $75

// Pro Pattern: The One-Liner
const quickTotal = cart.reduce((acc, item) => acc + item.price, 0);
```

### 4. Progressive Step-by-Step Breakdown
**Step 1: The Arguments**
`.reduce()` takes a callback, AND a crucial second argument: the initial value `0`. This is what `accumulator` equals on the very first loop.
**Step 2: The Callback Logic**
On Loop 1, `acc = 0`, `item = {price: 20}`. We return `0 + 20` (20).
On Loop 2, `acc = 20`, `item = {price: 5}`. We return `20 + 5` (25).
On Loop 3, `acc = 25`, `item = {price: 50}`. We return `25 + 50` (75).
**Step 3: The Final Return**
Whatever is returned on the very last loop (75) is assigned to the `grandTotal` variable.

### 5. ASCII Data Flow
```text
[ {price:20}, {price:5}, {price:50} ]
      |
(Loop 1) acc = 0    + 20 -> RETURNS 20
                            |
(Loop 2) acc = 20   + 5  -> RETURNS 25
                            |
(Loop 3) acc = 25   + 50 -> RETURNS 75
                            |
                     [ Final Result: 75 ]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Forgetting the initial value (the `, 0` at the end). If you forget it, `.reduce()` uses the *entire first object* in the array as the starting snowball. You end up trying to do `{price: 20} + 5`, resulting in chaotic string concatenation bugs like `"[object Object]5"`.
**Pro Tip:** `.reduce()` isn't just for math. The starting value can be an empty Object `{}`, allowing you to squash an Array of data into a single formatted Object Map!

## Phase B: Engineering Challenges

### Level 1: Warm-Up
**Task:** `const numbers = [10, 20, 30]`. Use `.reduce()` to calculate the sum. Use the one-liner syntax. Don't forget your starting value!
<details>

`numbers.reduce((acc, curr) => acc + curr, 0);`
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
const numbers = [10, 20, 30];
const sum = numbers.reduce((acc, curr) => acc + curr, 0);

console.log(sum); // 60
```
Standard accumulation pattern.
</details>

### Level 2: Real-World
**Task:** Tally up votes. `const votes = ["yes", "no", "yes", "yes"]`. You want to find out how many "yes" votes there are. Use `.reduce()` with a starting value of `0`. Inside the callback, if the item is "yes", return `acc + 1`. Otherwise, return `acc`.
<details>
<summary>Hint</summary>
`return item === "yes" ? acc + 1 : acc;` or use an `if / else`.
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
const votes = ["yes", "no", "yes", "yes"];

const yesCount = votes.reduce((acc, vote) => {
  if (vote === "yes") {
    return acc + 1; // Add to tally
  } else {
    return acc;     // Keep tally the same
  }
}, 0);

console.log(yesCount); // 3
```
Reduce is perfect for tallying and counting specific subsets of data without maintaining external variables.
</details>

### Level 3: Boss Level
**Task:** (Cumulative) Combine map, filter, and reduce!
`const orders = [ { product: "apple", price: "2", status: "paid" }, { product: "banana", price: "3", status: "pending" }, { product: "cherry", price: "5", status: "paid" } ];`
Task: Calculate the total revenue of **paid** orders.
1. `.filter()` for "paid" status.
2. `.map()` to cast the string prices to Numbers.
3. `.reduce()` to sum those numbers up.
Log the total.
<details>
<summary>Hint</summary>
`orders.filter(...).map(...).reduce(..., 0)`
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
const orders = [
  { product: "apple", price: "2", status: "paid" },
  { product: "banana", price: "3", status: "pending" },
  { product: "cherry", price: "5", status: "paid" }
];

const totalRevenue = orders
  .filter(order => order.status === "paid")
  .map(order => Number(order.price))
  .reduce((acc, price) => acc + price, 0);

console.log(`Total Revenue: $${totalRevenue}`); // 2 + 5 = 7
```
This chain is the holy grail of JavaScript data processing. Filter the noise, Format the data, Squash it into a result. It reads beautifully top-to-bottom.
</details>
