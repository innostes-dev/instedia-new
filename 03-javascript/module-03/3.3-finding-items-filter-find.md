# 3.3 Array.filter() & find() - The Investigators

## Phase A: Core Concept

### 1. Real-World Pain Point (The Why)
You have a list of 10,000 Amazon products. A user clicks the "In-Stock Only" checkbox. If you loop through manually and `splice()` items out of the array, you mutate the original data—so when they uncheck the box, the data is gone forever! You need a way to create a subset array based on rules.

### 2. Plain English Metaphor (The What)
- **`Array.filter()`** is a **bouncer with a guest list**. You give the bouncer a rule ("must be over 18"). It evaluates every person in line. If the rule returns `true`, they go into the *new* VIP room (new array). If `false`, they are ignored.
- **`Array.find()`** is a **sniper**. It searches for the *first* person that matches the rule, grabs them, and immediately stops looking.

### 3. Complete Runnable Code
```javascript
// Example: Amazon In-Stock Filter & Product Lookup
const products = [
  { id: 101, name: "Mouse", inStock: true, price: 25 },
  { id: 102, name: "Keyboard", inStock: false, price: 100 },
  { id: 103, name: "Monitor", inStock: true, price: 300 }
];

// --- 1. FILTER: Give me ALL items that match ---
// Rule: Must return a Boolean (true/false)
const availableProducts = products.filter((item) => {
  // If inStock is true, keep it. Else, discard it.
  return item.inStock === true;
});

console.log("Available:", availableProducts);
// Returns Array of 2 objects: [ {Mouse}, {Monitor} ]


// --- 2. FIND: Give me the FIRST item that matches ---
// Rule: ID must strictly equal 102
const specificKeyboard = products.find((item) => item.id === 102);

console.log("Found Item:", specificKeyboard);
// Returns SINGLE Object: { id: 102, name: "Keyboard", ... }


// --- Pro Pattern: Implicit Return One-Liners ---
const expensiveItems = products.filter(p => p.price >= 100);
```

### 4. Progressive Step-by-Step Breakdown
**Step 1: The Callback Rule**
Both `.filter()` and `.find()` take a callback function, just like `.map()`. However, instead of returning transformed data, the callback MUST return `true` or `false` (or a truthy/falsy value).
**Step 2: How Filter works**
`.filter()` iterates through the whole list. Every time it gets `true`, it pushes that item into a new array. It always returns an Array (even if empty `[]`).
**Step 3: How Find works**
`.find()` iterates until it hits the first `true`, then immediately returns that specific *item itself* (an Object, String, Number). If nothing matches, it returns `undefined`.

### 5. ASCII Data Flow
```text
[ {Mouse, stock:true}, {Key, stock:false}, {Mon, stock:true} ]
           |                   |                   |
.filter( i => i.stock )        |                   |
           |                   |                   |
     RETURN true          RETURN false        RETURN true
      (KEEP!)             (DISCARD!)          (KEEP!)
           \                   |                   /
            v                  |                  v
     [ {Mouse, stock:true},    x     {Mon, stock:true} ]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Using `.filter()` when you only need one specific item (like looking up by ID). `.filter` will scan the entire array even after finding it, and it returns an Array `[ {item} ]` which forces you to do `result[0]`. Use `.find()` instead!
**Pro Tip:** You can chain these methods immutably! `products.filter(p => p.inStock).map(p => p.price)` filters the list, then immediately maps the results into a list of prices.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
**Task:** `const ages = [12, 18, 25, 8, 30]`. Use `.filter()` to create an array called `adults` containing only numbers 18 and over. Use a one-liner.
<details>
<summary>Hint</summary>
`ages.filter(age => age >= 18);`
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
const ages = [12, 18, 25, 8, 30];
const adults = ages.filter(age => age >= 18);

console.log(adults); // [18, 25, 30]
```
Returns a new array based on the boolean condition.
</details>

### Level 2: Real-World
**Task:** You are authenticating a user.
`const users = [ { username: "admin", pin: 1234 }, { username: "guest", pin: 0000 } ];`
Use `.find()` to locate the user where the `username` is "admin" AND the `pin` is 1234. If found, log "Access Granted". If `.find()` returns undefined, log "Access Denied".
<details>
<summary>Hint</summary>
`const loggedIn = users.find(u => u.username === "admin" && u.pin === 1234);` Check if `loggedIn` is truthy!
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
const users = [
  { username: "admin", pin: 1234 },
  { username: "guest", pin: 0000 }
];

const validUser = users.find(u => u.username === "admin" && u.pin === 1234);

if (validUser) {
  console.log("Access Granted");
} else {
  console.log("Access Denied");
}
```
`.find()` correctly identifies the object, and standard truthiness logic handles the branching.
</details>

### Level 3: Boss Level
**Task:** (Cumulative) Chaining methods and type coercion.
Data: `const orders = [ { id: 1, amount: "50", status: "delivered" }, { id: 2, amount: "150", status: "pending" }, { id: 3, amount: "200", status: "delivered" } ];`
Task:
1. Use `.filter()` to keep only "delivered" orders.
2. Chain `.map()` directly onto the result to extract just the `amount` of those orders, and cast them to actual Numbers.
3. The final result should be an array of numbers: `[50, 200]`.
<details>
<summary>Hint</summary>
`orders.filter(o => ...).map(o => Number(...))`
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
const orders = [
  { id: 1, amount: "50", status: "delivered" },
  { id: 2, amount: "150", status: "pending" },
  { id: 3, amount: "200", status: "delivered" }
];

// Chain them together!
const deliveredTotals = orders
  .filter(order => order.status === "delivered")
  .map(order => Number(order.amount));

console.log(deliveredTotals); // [50, 200]
```
This is a staple pattern in React, Vue, and Node.js. Filter down to the exact data subset you want, then Map it into the precise shape your UI or database needs.
</details>
