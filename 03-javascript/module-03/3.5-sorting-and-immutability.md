# 3.5 Sorting and Immutability (slice vs splice)

## Phase A: Core Concept

### 1. Real-World Pain Point (The Why)
You have a leaderboard: `[50, 10, 100]`. You run `.sort()`. Suddenly it looks like `[10, 100, 50]`. Wait, 100 comes before 50? Yes, because default sorting converts everything to text and sorts alphabetically ("1" comes before "5"). Worse, `.sort()` mutates the original array! The original chronological data is destroyed.

### 2. Plain English Metaphor (The What)
- **`Array.sort()`** is a **referee**. By default, it's a terrible referee that judges everything alphabetically. You have to give it a "Comparator Function" to explain how to compare numbers.
- **`Array.slice()` vs `.splice()`**: `.splice()` is a **scalpel** that cuts pieces out of the original array (mutation). `.slice()` is a **scanner** that makes a copy of a section without harming the original.

### 3. Complete Runnable Code
```javascript
// Example: Leaderboard Scoreboard & Price Sorter
const scores = [50, 10, 100, 30];

// 1. The Default Disaster
// scores.sort(); -> Mutates! Becomes [10, 100, 30, 50]

// 2. The Safe, Pro Pattern
// Step A: Use .slice() with no arguments to create a perfect COPY
const safeScoresCopy = scores.slice();

// Step B: Sort the copy using a Comparator Function
// (a, b) represents two numbers being compared.
// If a - b is negative, 'a' goes first (Ascending).
// If b - a is negative, 'b' goes first (Descending).

safeScoresCopy.sort((a, b) => {
  return a - b; // Ascending Order (lowest to highest)
});

console.log("Original untouched:", scores); // [50, 10, 100, 30]
console.log("Sorted copy:", safeScoresCopy); // [10, 30, 50, 100]

// Modern ES2023 Array.toSorted() (If supported)
// const modernSort = scores.toSorted((a,b) => a - b);
```

### 4. Progressive Step-by-Step Breakdown
**Step 1: The Shallow Copy**
Calling `.slice()` with no arguments returns a brand new array containing the exact same items. We do this to protect `scores` from mutation.
**Step 2: The Comparator Function**
`.sort((a, b) => a - b)` takes two items. If `a = 50` and `b = 10`, `a - b` is `40` (Positive). A positive result tells the engine to swap them, moving `10` before `50`.
**Step 3: Descending Order**
To sort highest-to-lowest, just flip the math: `.sort((a, b) => b - a)`.

### 5. ASCII Data Flow
```text
[ Original: [50, 10, 100, 30] ]
          |
       .slice() Creates Copy
          |
          v
[ Copy: [50, 10, 100, 30] ]
          |
.sort( a - b ) -> Is (50 - 10) > 0? SWAP!
          |
          v
[ Sorted: [10, 30, 50, 100] ]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Using `.splice(index, 1)` to remove an item from an array in React or Redux state. `.splice()` mutates! Instead, use `.filter()` to create a new array without the item: `arr.filter(item => item.id !== removeId)`.
**Pro Tip:** If sorting objects, access the property inside the math: `users.sort((a, b) => a.age - b.age)`. Also, familiarize yourself with `toSorted()`, `toSpliced()`, and `toReversed()` which are modern, immutable versions of the classic methods!

## Phase B: Engineering Challenges

### Level 1: Warm-Up
**Task:** `const prices = [99, 5, 20]`. Sort them in **descending** order (highest to lowest). Make sure to create a copy using `.slice()` first!
<details>
<summary>Hint</summary>
`const copy = prices.slice(); copy.sort((a, b) => b - a);`
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
const prices = [99, 5, 20];
const sortedDesc = prices.slice().sort((a, b) => b - a);

console.log(sortedDesc); // [99, 20, 5]
```
Chaining `.slice().sort()` is the classic way to immutably sort an array.
</details>

### Level 2: Real-World
**Task:** You have a list of user objects: `const players = [{name: "Al", score: 20}, {name: "Bo", score: 100}, {name: "Cy", score: 50}]`. Create a safe sorted copy that puts the highest scorer first.
<details>
<summary>Hint</summary>
In the comparator, do the math on the `score` properties: `b.score - a.score`.
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
const players = [
  {name: "Al", score: 20},
  {name: "Bo", score: 100},
  {name: "Cy", score: 50}
];

const leaderboard = players.slice().sort((a, b) => {
  return b.score - a.score;
});

console.log(leaderboard);
// Bo (100), Cy (50), Al (20)
```
Sorting objects requires accessing the specific numeric property you want to evaluate.
</details>

### Level 3: Boss Level
**Task:** (Cumulative) The Complete Pipeline.
`const rawData = [ {id: 1, price: "40", type: "book"}, {id: 2, price: "10", type: "game"}, {id: 3, price: "100", type: "book"} ];`
1. Filter for type "book".
2. Map to convert `price` strings to Numbers.
3. Sort the resulting array from lowest to highest price. (Since map and filter already create new arrays, you don't actually need `.slice()` here!).
4. Log the result.
<details>
<summary>Hint</summary>
Chain it all: `.filter(b).map(b).sort((a,b) => a.price - b.price)`.
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
const rawData = [
  {id: 1, price: "40", type: "book"},
  {id: 2, price: "10", type: "game"},
  {id: 3, price: "100", type: "book"}
];

const processedBooks = rawData
  .filter(item => item.type === "book")
  .map(item => {
    // Return a new object with the price casted to a Number
    return { id: item.id, price: Number(item.price), type: item.type };
  })
  .sort((a, b) => a.price - b.price); // Lowest to highest

console.log(processedBooks);
// [ {id: 1, price: 40...}, {id: 3, price: 100...} ]
```
This is the ultimate array manipulation workflow. We sanitize, format, and organize raw data purely and immutably.
</details>
