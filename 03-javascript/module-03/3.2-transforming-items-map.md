# 3.2 Array.map() - The Transformer

## Phase A: Core Concept

### 1. Real-World Pain Point (The Why)
You have an array of prices `[10, 20, 30]`. You need to create an array of formatted strings for the UI: `["$10.00", "$20.00", "$30.00"]`. If you use a `for` loop, you have to create an empty array, push items into it manually, and manage all the state. It's verbose and repetitive.

### 2. Plain English Metaphor (The What)
`Array.map()` is an **assembly line machine**.
You put a box of raw materials (an array) onto the conveyor belt. The machine processes every single item exactly the same way, and spits out a *brand new box* of finished products at the end. The original box of raw materials is completely untouched.

### 3. Complete Runnable Code
```javascript
// Example: E-Commerce Formatted Price List
const rawPrices = [15, 42.5, 99];

// The map() function takes a "callback function" as an argument.
// Think of it as the instruction manual for the assembly line machine.

const formattedPrices = rawPrices.map((price) => {
  // This logic runs once for EVERY item in the array
  const addedTax = price * 1.08;
  const asString = `$${addedTax.toFixed(2)}`;

  // Whatever you RETURN is placed into the new array
  return asString;
});

console.log("Original:", rawPrices); // [15, 42.5, 99] (Untouched!)
console.log("Formatted:", formattedPrices); // ["$16.20", "$45.90", "$106.92"]

// Pro Pattern: Implicit Return (One-Liner)
// If you remove the { } and the `return` keyword, arrow functions return automatically.
const quickDoubles = rawPrices.map(p => p * 2);
console.log("Doubled:", quickDoubles); // [30, 85, 198]
```

### 4. Progressive Step-by-Step Breakdown
**Step 1: The Method Call**
We call `.map()` directly on `rawPrices`. We must store the result in a new variable (`formattedPrices`) because `map` returns a brand new array.
**Step 2: The Callback Function**
`map` expects an arrow function: `(price) => { ... }`. It passes the current item into this function (first `15`, then `42.5`, etc.).
**Step 3: The Return Statement**
The single most important rule of `.map()`: **You MUST return a value.** Whatever value is returned becomes the item in the new array at that exact position.

### 5. ASCII Data Flow
```text
[ rawPrices: [ 15, 42.5, 99 ] ]
               |    |    |
   .map( p => `$${(p * 1.08).toFixed(2)}` )
               |    |    |
    RETURN: "$16" "$45" "$106"
               |    |    |
               v    v    v
[ formattedPrices: ["$16.20", "$45.90", "$106.92"] ]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Using `.map()` but forgetting the `return` keyword inside the `{}` block. If you do this, `map` creates an array full of `[undefined, undefined, undefined]`. Also, using `.map()` just to loop and do `console.log()`—use `.forEach()` or `for...of` if you aren't returning a new array!
**Pro Tip:** Master the implicit return: `arr.map(x => x.id)`. It makes extracting specific data from a massive list of objects beautifully succinct.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
**Task:** `const numbers = [1, 2, 3, 4]`. Use `.map()` with a one-line implicit return to multiply every number by 10. Store it in `tens` and log it.
<details>
<summary>Hint</summary>
`numbers.map(n => n * 10);`
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
const numbers = [1, 2, 3, 4];
const tens = numbers.map(n => n * 10);

console.log(tens); // [10, 20, 30, 40]
```
Clean, functional, and immutable.
</details>

### Level 2: Real-World
**Task:** You have a list of user names: `const users = ["alice", "bob", "charlie"]`. Use `.map()` to capitalize them and wrap them in an HTML list item tag. Return a string like `<li>Alice</li>`. Remember string methods like `toUpperCase()`, `slice(1)`, and template literals!
<details>
<summary>Hint</summary>
Inside the map block, capitalize it: `const cap = user[0].toUpperCase() + user.slice(1);`. Then return `<li>${cap}</li>`.
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
const users = ["alice", "bob", "charlie"];

const listItems = users.map((user) => {
  const capitalized = user[0].toUpperCase() + user.slice(1);
  return `<li>${capitalized}</li>`;
});

console.log(listItems);
// ["<li>Alice</li>", "<li>Bob</li>", "<li>Charlie</li>"]
```
This is the exact pattern React uses to render lists of UI components!
</details>

### Level 3: Boss Level
**Task:** (Cumulative) Map an array of objects while handling missing data.
`const rawUsers = [ { id: 1, bio: { name: "sam" } }, { id: 2, bio: null }, { id: 3, bio: { name: "alex" } } ];`
Create a new array called `displayNames`. Map over `rawUsers`.
1. Safely extract the name using optional chaining (`?.`).
2. Use nullish coalescing (`??`) to default to "Guest" if the bio or name is missing.
3. Return the string formatted as `"[ID: 1] Name: Sam"`. Capitalize the name manually or dynamically.
<details>
<summary>Hint</summary>
`const name = user.bio?.name ?? "guest";` Then format and return it.
</details>
<details>
<summary>Solution Walkthrough</summary>

```javascript
const rawUsers = [
  { id: 1, bio: { name: "sam" } },
  { id: 2, bio: null },
  { id: 3, bio: { name: "alex" } }
];

const displayNames = rawUsers.map((user) => {
  // 1 & 2: Safe extraction
  const rawName = user.bio?.name ?? "guest";

  // Capitalize
  const capName = rawName[0].toUpperCase() + rawName.slice(1);

  // 3: Return formatted template literal
  return `[ID: ${user.id}] Name: ${capName}`;
});

console.log(displayNames);
/*
  [
    "[ID: 1] Name: Sam",
    "[ID: 2] Name: Guest",
    "[ID: 3] Name: Alex"
  ]
*/
```
This combines safe data parsing with immutable transformation, a critical skill for processing messy API data.
</details>
