# CSS Custom Properties

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
Hardcoding `#1da1f2` in 50 different places means that if marketing changes the brand color, you have to do a risky Find & Replace across the whole codebase.

### 2. Plain English Metaphor (The What)
CSS Variables are like saving a contact in your phone. You just call 'Mom', and the phone knows what number to dial. If Mom changes her number, you only update it in one place.

### 3. Complete Runnable Code
```html
<div class="card">Hello Theme</div>
<style>
  :root {
    --bg-color: white;
    --text-color: black;
  }

  [data-theme="dark"] {
    --bg-color: black;
    --text-color: white;
  }

  body { background: var(--bg-color); }
  .card { color: var(--text-color); }
</style>
<script>
  // Simple JS to toggle theme
  document.documentElement.setAttribute('data-theme', 'dark');
</script>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Define global variables in the `:root` pseudo-class using the `--` prefix.

**Step 2:** Consume the variables in your styles using the `var(--name)` function.

**Step 3:** To create themes, override the variable definitions under a specific class or data attribute.

### 5. ASCII Data Flow
```text
[ :root ] -> --primary: blue
                 |
[ .button ] -> var(--primary) -> Button is blue

[ .theme-dark ] -> --primary: purple
                 |
[ .button ] -> var(--primary) -> Button is purple
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Using Sass/SCSS variables (`$color`) for theming. SCSS compiles to static CSS, so you can't change it on the fly in the browser.
**Pro Tip:** CSS variables cascade. You can redefine `--btn-color` on a specific parent div, and only buttons inside that div will change color.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Define a custom property for a primary brand color and apply it to an h1.
<details>
<summary>Hint</summary>
Use :root and var().
</details>
<details>
<summary>Solution</summary>

```css
:root { --brand: #ff0000; }
h1 { color: var(--brand); }
```
</details>

### Level 2: Real-World (Complete Dark/Light Theme Switcher)
Create a dark mode theme that swaps background and text colors.
<details>
<summary>Hint</summary>
Override variables in a dark class.
</details>
<details>
<summary>Solution</summary>

```css
:root { --bg: #fff; --txt: #000; }
.dark { --bg: #000; --txt: #fff; }
body { background: var(--bg); color: var(--txt); }
```
</details>

### Level 3: Boss Level (Cumulative)
Build a button component with a local override for its hover state color.
<details>
<summary>Hint</summary>
Define a local variable on the button class.
</details>
<details>
<summary>Solution</summary>

```css
.btn { --btn-bg: blue; background: var(--btn-bg); }
.btn:hover { --btn-bg: darkblue; }
```
</details>
