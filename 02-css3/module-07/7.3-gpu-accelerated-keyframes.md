# GPU Accelerated Keyframes

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
Animating `width`, `height`, `top`, or `margin` causes the browser to recalculate the entire page layout 60 times a second, making your fans spin and the animation stutter.

### 2. Plain English Metaphor (The What)
Animating layout properties is like rebuilding a house to move it 10 feet. Animating GPU properties (`transform`, `opacity`) is like putting the house on a flatbed truck and driving it 10 feet.

### 3. Complete Runnable Code
```html
<div class="heart">❤️</div>
<style>
  .heart:active {
    animation: pop 0.3s ease-out;
  }

  @keyframes pop {
    0% { transform: scale(1); }
    50% { transform: scale(1.5); }
    100% { transform: scale(1); }
  }
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Create an `@keyframes` rule giving the animation a name (`pop`).

**Step 2:** Define the steps using percentages (0%, 50%, 100%).

**Step 3:** Apply the animation to an element using the `animation` property, exclusively animating `transform` and `opacity`.

### 5. ASCII Data Flow
```text
0%   [ ❤️ Size 1 ]
         |
50%  [ ❤️ Size 1.5 ] <-- (GPU handles scaling)
         |
100% [ ❤️ Size 1 ]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Animating `width` or `left` to move an element.
**Pro Tip:** Strictly limit animations to `transform` (translate, scale, rotate) and `opacity`. The browser sends these to the GPU, guaranteeing a buttery smooth 60fps.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Create a pulsing animation loop.
<details>
<summary>Hint</summary>
Use keyframes with scale and opacity, infinite.
</details>
<details>
<summary>Solution</summary>

```css
@keyframes pulse { 0% { transform: scale(1); opacity: 1; } 50% { transform: scale(1.1); opacity: 0.8; } 100% { transform: scale(1); opacity: 1; } }
.item { animation: pulse 2s infinite; }
```
</details>

### Level 2: Real-World (Twitter Heart Like Animation)
Build a Twitter-style heart pop animation on click.
<details>
<summary>Hint</summary>
Use scale up then back to normal.
</details>
<details>
<summary>Solution</summary>

```css
@keyframes pop { 50% { transform: scale(1.3); } }
.heart:active { animation: pop 0.2s ease; }
```
</details>

### Level 3: Boss Level (Cumulative)
Create a seamless scrolling marquee (like a stock ticker) using pure CSS.
<details>
<summary>Hint</summary>
TranslateX from 0 to -100%.
</details>
<details>
<summary>Solution</summary>

```css
@keyframes scroll { 100% { transform: translateX(-100%); } }
.ticker { animation: scroll 10s linear infinite; }
```
</details>
