# Transitions & Timing

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
Buttons instantly snap to a new color when hovered, making the UI feel harsh, cheap, and robotic.

### 2. Plain English Metaphor (The What)
A transition is hiring a chauffeur. Instead of teleporting from home to work, the chauffeur drives you there smoothly over a set amount of time.

### 3. Complete Runnable Code
```html
<button class="btn">Hover Me</button>
<style>
  .btn {
    background: blue;
    transform: translateY(0);
    /* property duration timing-function */
    transition: background 0.3s ease, transform 0.2s cubic-bezier(0.175, 0.885, 0.32, 1.275);
  }
  .btn:hover {
    background: darkblue;
    transform: translateY(-5px);
  }
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Define the base state (e.g., `background: blue`).

**Step 2:** Add a `transition` property specifying *what* to animate, *how long*, and the *easing*.

**Step 3:** Define the target state on a pseudo-class (e.g., `:hover`). The browser calculates the frames in between.

### 5. ASCII Data Flow
```text
[ Base State ]
      |
 (transition: 0.3s) --> Browser interpolates frames smoothly
      |
[ :hover State ]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Using `transition: all 0.3s`. This forces the browser to animate things you didn't intend, destroying performance.
**Pro Tip:** Use custom `cubic-bezier` timing functions to create bounce, spring, and physical feeling animations instead of standard `ease`.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Make a link smoothly change color on hover over half a second.
<details>
<summary>Hint</summary>
Transition the color property.
</details>
<details>
<summary>Solution</summary>

```css
a { transition: color 0.5s ease; }
a:hover { color: red; }
```
</details>

### Level 2: Real-World (Smooth Button Ripple & Elevation)
Create a button that lifts up and gains a shadow smoothly.
<details>
<summary>Hint</summary>
Transition transform and box-shadow.
</details>
<details>
<summary>Solution</summary>

```css
.btn { transition: transform 0.2s, box-shadow 0.2s; }
.btn:hover { transform: translateY(-4px); box-shadow: 0 4px 8px rgba(0,0,0,0.2); }
```
</details>

### Level 3: Boss Level (Cumulative)
Implement an off-canvas menu that slides in with a spring effect.
<details>
<summary>Hint</summary>
Use transform and a cubic-bezier.
</details>
<details>
<summary>Solution</summary>

```css
.menu { transform: translateX(100%); transition: transform 0.4s cubic-bezier(0.175, 0.885, 0.32, 1.275); }
.menu.open { transform: translateX(0); }
```
</details>
