# Relational Styling (:has)

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
You want a parent card to turn green when a checkbox inside it is checked. Historically, this required writing JavaScript event listeners.

### 2. Plain English Metaphor (The What)
The `:has()` selector is a parent looking inside their child's backpack. If they see an 'A+' grade (checked box), the parent smiles (turns green).

### 3. Complete Runnable Code
```html
<label class="card">
  <input type="checkbox" class="check" />
  Select Plan
</label>
<style>
  .card {
    border: 2px solid gray;
    padding: 20px;
  }

  /* If the card contains a checked input, style the card! */
  .card:has(.check:checked) {
    border-color: green;
    background: lightgreen;
  }
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Create the HTML structure with a parent (`.card`) containing a stateful element (checkbox).

**Step 2:** Write a selector targeting the parent.

**Step 3:** Add the `:has(.check:checked)` pseudo-class to apply styles to the parent ONLY if the internal condition is met.

### 5. ASCII Data Flow
```text
[ Card ]
  |-- [ Checkbox ] (Unchecked) -> Card is Gray

[ Card ]
  |-- [ Checkbox ] (Checked!) -> Trigger :has() -> Card becomes Green
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Thinking `:has()` only styles the child. It styles the element *before* the colon.
**Pro Tip:** `:has()` is completely revolutionizing CSS. You can build entire interactive components (accordions, tabs, form validation UI) with zero JavaScript.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Style a section only if it contains an h1.
<details>
<summary>Hint</summary>
Use :has().
</details>
<details>
<summary>Solution</summary>

```css
section:has(h1) { background: yellow; }
```
</details>

### Level 2: Real-World (Zero-JS Interactive Form Card Selector)
Create a card that gets a blue border when the user focuses on an input inside it.
<details>
<summary>Hint</summary>
Use :has(:focus).
</details>
<details>
<summary>Solution</summary>

```css
.card:has(input:focus) { border: 2px solid blue; }
```
</details>

### Level 3: Boss Level (Cumulative)
Build a zero-JS interactive pricing tier selector where the whole column highlights if chosen.
<details>
<summary>Hint</summary>
Parent column has an input:checked.
</details>
<details>
<summary>Solution</summary>

```css
.column { opacity: 0.5; }
.column:has(input:checked) { opacity: 1; transform: scale(1.05); }
```
</details>
