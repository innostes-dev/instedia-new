# Grid Containers & fr Units

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
Flexbox is great for 1D rows, but creating a 2D matrix (like a video gallery) requires complex wrapping math and breaks easily.

### 2. Plain English Metaphor (The What)
Grid is a spreadsheet. You define the columns and rows of the spreadsheet, and the items just plop into the cells. `fr` is 'fraction of leftover space'.

### 3. Complete Runnable Code
```html
<div class="grid">
  <div class="vid">1</div>
  <div class="vid">2</div>
  <div class="vid">3</div>
</div>
<style>
  .grid {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 16px;
  }
  .vid { background: gray; height: 100px; }
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Set `display: grid` to turn the container into a grid system.

**Step 2:** Define columns with `grid-template-columns: 1fr 1fr 1fr`. This creates 3 equal columns.

**Step 3:** Add `gap` for perfect spacing between all grid cells.

### 5. ASCII Data Flow
```text
[ 1fr ]   [ 1fr ]   [ 1fr ]
+-------+ +-------+ +-------+
| Vid 1 | | Vid 2 | | Vid 3 |
+-------+ +-------+ +-------+
| Vid 4 | | Vid 5 | | Vid 6 |
+-------+ +-------+ +-------+
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Using `%` for grid columns instead of `fr`. `%` ignores `gap` and will cause overflows.
**Pro Tip:** Use `repeat(3, 1fr)` instead of writing `1fr 1fr 1fr` to keep your CSS clean and scalable.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Create a basic 2-column grid.
<details>
<summary>Hint</summary>
Use grid-template-columns.
</details>
<details>
<summary>Solution</summary>

```css
.grid { display: grid; grid-template-columns: 1fr 1fr; }
```
</details>

### Level 2: Real-World (YouTube Video Showcase Matrix)
Build a YouTube-style 4-column video matrix with 20px gaps.
<details>
<summary>Hint</summary>
Use repeat and gap.
</details>
<details>
<summary>Solution</summary>

```css
.grid { display: grid; grid-template-columns: repeat(4, 1fr); gap: 20px; }
```
</details>

### Level 3: Boss Level (Cumulative)
Create a layout with a 250px sidebar and a fluid main content area.
<details>
<summary>Hint</summary>
Mix px and fr units.
</details>
<details>
<summary>Solution</summary>

```css
.layout { display: grid; grid-template-columns: 250px 1fr; }
```
</details>
