# Asymmetric Editorial Spans

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
You want one 'featured' news article to be huge (spanning 2 columns and 2 rows), while others are small, but the HTML order restricts you.

### 2. Plain English Metaphor (The What)
Grid spanning is like merging cells in Excel. You can tell one item to stretch across multiple lines, regardless of its HTML order.

### 3. Complete Runnable Code
```html
<div class="news-grid">
  <div class="hero">Big Story</div>
  <div class="side">Small 1</div>
  <div class="side">Small 2</div>
</div>
<style>
  .news-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
  }
  .hero {
    grid-column: span 2;
    grid-row: span 2;
    background: darkblue; color: white;
  }
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Create a standard multi-column grid (e.g., 3 columns).

**Step 2:** Select the featured child element (`.hero`).

**Step 3:** Apply `grid-column: span 2` to make it twice as wide, and `grid-row: span 2` for height.

### 5. ASCII Data Flow
```text
[   HERO (span 2)   ] [ Small 1 ]
[   HERO (span 2)   ] [ Small 2 ]
[ Small 3 ] [ Small 4 ] [ Small 5 ]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Trying to use Flexbox to build complex, asymmetric masonry layouts. It requires splitting HTML into columns.
**Pro Tip:** For even more control, look up `grid-template-areas` to draw an ASCII map of your layout in CSS.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Make an item span 2 columns.
<details>
<summary>Hint</summary>
Use grid-column.
</details>
<details>
<summary>Solution</summary>

```css
.item { grid-column: span 2; }
```
</details>

### Level 2: Real-World (NYT Front-Page Hero Layout)
Create a featured article that spans all 3 columns of a grid.
<details>
<summary>Hint</summary>
Use 1 / -1.
</details>
<details>
<summary>Solution</summary>

```css
.hero { grid-column: 1 / -1; }
```
</details>

### Level 3: Boss Level (Cumulative)
Build an editorial layout where the first item takes a 2x2 space, and next items flow around it.
<details>
<summary>Hint</summary>
Use both column and row spans.
</details>
<details>
<summary>Solution</summary>

```css
.feat { grid-column: span 2; grid-row: span 2; }
```
</details>
