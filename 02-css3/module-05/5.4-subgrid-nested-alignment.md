# Subgrid & Nested Alignment

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
You have a grid of pricing cards. Inside each card is a Title, Price, and Features list. If one features list is longer, the 'Buy' buttons on the cards misalign.

### 2. Plain English Metaphor (The What)
Subgrid allows children to inherit the grid tracks of their grandparent. It punches a hole through the container so inner elements align globally.

### 3. Complete Runnable Code
```html
<div class="pricing">
  <div class="card">
    <h3>Pro</h3>
    <ul><li>A</li><li>B</li></ul>
    <button>Buy</button>
  </div>
  <div class="card">
    <h3>Enterprise</h3>
    <ul><li>A</li><li>B</li><li>C</li><li>D</li></ul>
    <button>Buy</button>
  </div>
</div>
<style>
  .pricing {
    display: grid;
    grid-template-columns: 1fr 1fr;
    /* Define rows for the children to inherit */
    grid-template-rows: auto 1fr auto;
  }
  .card {
    display: grid;
    grid-template-rows: subgrid; /* Inherit rows */
    grid-row: span 3; /* Stretch across the 3 parent rows */
  }
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Define a parent grid with explicit rows (e.g., `auto 1fr auto`).

**Step 2:** Make the child cards `display: grid` and tell them to span those rows.

**Step 3:** Use `grid-template-rows: subgrid` on the cards so their internal elements align with the parent's grid lines.

### 5. ASCII Data Flow
```text
[ Parent Grid Rows ]
Line 1: ---------------------
[ Pro Title ]  [ Ent Title ]
Line 2: ---------------------
[ Feature ]    [ Feature ]
[ Feature ]    [ Feature ]
               [ Feature ]
Line 3: ---------------------
[ Buy Btn ]    [ Buy Btn ]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Trying to fix button alignment by setting fixed heights on the feature lists, which breaks when text wraps.
**Pro Tip:** Subgrid is the ultimate solution for aligning elements across different nested components.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Allow a child grid to inherit its parent's columns.
<details>
<summary>Hint</summary>
Use subgrid on columns.
</details>
<details>
<summary>Solution</summary>

```css
.child { display: grid; grid-template-columns: subgrid; }
```
</details>

### Level 2: Real-World (Shopify Pricing Tier Comparison Cards)
Align the buttons of three pricing cards horizontally, regardless of content height above them.
<details>
<summary>Hint</summary>
Parent defines rows, children use subgrid and span.
</details>
<details>
<summary>Solution</summary>

```css
.parent { display: grid; grid-template-rows: auto 1fr auto; }
.card { display: grid; grid-template-rows: subgrid; grid-row: span 3; }
```
</details>

### Level 3: Boss Level (Cumulative)
Build a complex form where labels in different fieldsets perfectly align.
<details>
<summary>Hint</summary>
Use subgrid on the fieldsets.
</details>
<details>
<summary>Solution</summary>

```css
.form { display: grid; grid-template-columns: 150px 1fr; }
.fieldset { display: grid; grid-template-columns: subgrid; grid-column: span 2; }
```
</details>
