# Display Flex & Axes

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
Putting divs side-by-side used to require complex floats and clearfixes, resulting in fragile layouts.

### 2. Plain English Metaphor (The What)
Flexbox is like a string of beads. You define the string (the container) and direction (the axis), and the beads (children) just line up perfectly.

### 3. Complete Runnable Code
```html
<div class="row">
  <div class="movie">1</div>
  <div class="movie">2</div>
  <div class="movie">3</div>
</div>
<style>
  .row {
    display: flex;
    flex-direction: row; /* Main Axis */
  }
  .movie { width: 100px; height: 150px; background: red; margin: 4px; }
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Target the parent container (`.row`).

**Step 2:** Set `display: flex;`. Immediately, children become flex items and sit side-by-side.

**Step 3:** Set `flex-direction: row;` to explicitly state the Main Axis is horizontal.

### 5. ASCII Data Flow
```text
[Container (display: flex)]
--> MAIN AXIS (flex-direction: row) -->
+-------+ +-------+ +-------+
| Item 1| | Item 2| | Item 3|
+-------+ +-------+ +-------+
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Applying flex properties to the children instead of the parent container.
**Pro Tip:** Remember the Main Axis. Everything in Flexbox (alignment, gaps, wrapping) orbits around which way the Main Axis points.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Make three paragraphs sit side-by-side.
<details>
<summary>Hint</summary>
Put them in a container and use `display: flex`.
</details>
<details>
<summary>Solution</summary>

```css
.container { display: flex; }
```
</details>

### Level 2: Real-World (Netflix Horizontal Movie Thumbnail Row)
Create a vertical list of horizontal rows (like a feed).
<details>
<summary>Hint</summary>
Use flex-direction.
</details>
<details>
<summary>Solution</summary>

```css
.feed { display: flex; flex-direction: column; }
.feed-item { display: flex; flex-direction: row; }
```
</details>

### Level 3: Boss Level (Cumulative)
Build a Netflix-style horizontal row that scrolls if it overflows.
<details>
<summary>Hint</summary>
Use flex and overflow-x.
</details>
<details>
<summary>Solution</summary>

```css
.row { display: flex; flex-direction: row; overflow-x: auto; gap: 8px; }
```
</details>
