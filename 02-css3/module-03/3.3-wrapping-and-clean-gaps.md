# Wrapping & Clean Gaps

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
Items shrink to microscopic sizes when too many are added, or relying on margins creates awkward edge-spacing issues.

### 2. Plain English Metaphor (The What)
Wrapping is a word processor going to the next line. `gap` is the built-in social distancing rule between the items.

### 3. Complete Runnable Code
```html
<div class="tags">
  <div class="tag">#css</div>
  <div class="tag">#flexbox</div>
  <div class="tag">#webdev</div>
</div>
<style>
  .tags {
    display: flex;
    flex-wrap: wrap;
    gap: 12px;
  }
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Set `display: flex` on the container.

**Step 2:** Add `flex-wrap: wrap` so children move to a new row instead of squishing.

**Step 3:** Use `gap: 12px` to add exact spacing *between* items, without adding margins to the outside edges.

### 5. ASCII Data Flow
```text
[#css] (12px) [#flexbox] (12px) [#webdev]
(12px gap here when wrapping)
[#more] (12px) [#tags]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Using negative margins on the container to offset margins on the children.
**Pro Tip:** Always use `gap`. It replaced the complex margin hacks entirely.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Allow flex items to wrap to a new line.
<details>
<summary>Hint</summary>
Use flex-wrap.
</details>
<details>
<summary>Solution</summary>

```css
.container { display: flex; flex-wrap: wrap; }
```
</details>

### Level 2: Real-World (Instagram Tag Pill Selector)
Create an Instagram-style tag list with consistent spacing.
<details>
<summary>Hint</summary>
Combine flex-wrap and gap.
</details>
<details>
<summary>Solution</summary>

```css
.tags { display: flex; flex-wrap: wrap; gap: 8px; }
```
</details>

### Level 3: Boss Level (Cumulative)
Create a gallery of photos that wraps, with different gaps for rows vs columns.
<details>
<summary>Hint</summary>
Gap can take two values.
</details>
<details>
<summary>Solution</summary>

```css
.gallery { display: flex; flex-wrap: wrap; gap: 16px 8px; /* row column */ }
```
</details>
