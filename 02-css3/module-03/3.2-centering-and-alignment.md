# Centering & Alignment

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
Centering a box vertically and horizontally used to be the hardest joke in web development.

### 2. Plain English Metaphor (The What)
Justify handles movement ALONG the main axis (train moving on tracks). Align handles movement ACROSS the cross axis (train jumping tracks).

### 3. Complete Runnable Code
```html
<div class="screen">
  <div class="modal">Login</div>
</div>
<style>
  .screen {
    display: flex;
    justify-content: center; /* Main Axis */
    align-items: center;     /* Cross Axis */
    height: 100vh;
  }
  .modal { width: 300px; height: 200px; background: white; }
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Make the parent full height (`height: 100vh`) so there is space to center within.

**Step 2:** Use `justify-content: center` to center horizontally (Main Axis).

**Step 3:** Use `align-items: center` to center vertically (Cross Axis).

### 5. ASCII Data Flow
```text
      (align-items)
           ^
           |
(justify) <+> (justify)
           |
           v
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Using margins and calc() to perfectly center something. It breaks when content changes size.
**Pro Tip:** The 3 lines to perfectly center anything: `display: flex; justify-content: center; align-items: center;`.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Center text horizontally inside a flex container.
<details>
<summary>Hint</summary>
Use justify-content.
</details>
<details>
<summary>Solution</summary>

```css
.container { display: flex; justify-content: center; }
```
</details>

### Level 2: Real-World (Centered Login Modal Dialog Box)
Align items to the right, but vertically centered.
<details>
<summary>Hint</summary>
Justify flex-end, align center.
</details>
<details>
<summary>Solution</summary>

```css
.container { display: flex; justify-content: flex-end; align-items: center; }
```
</details>

### Level 3: Boss Level (Cumulative)
Space three items evenly across a navbar, perfectly centered vertically.
<details>
<summary>Hint</summary>
Space-between.
</details>
<details>
<summary>Solution</summary>

```css
.navbar { display: flex; justify-content: space-between; align-items: center; }
```
</details>
