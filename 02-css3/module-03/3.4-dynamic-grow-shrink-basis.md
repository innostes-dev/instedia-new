# Dynamic Grow, Shrink, Basis

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
You have an icon, a text input, and a send button. You want the input to take up all remaining space, but `width: 100%` breaks it.

### 2. Plain English Metaphor (The What)
Flex-basis is the starting salary. Flex-grow is the bonus multiplier if the company makes extra money. Flex-shrink is the pay cut multiplier if the company loses money.

### 3. Complete Runnable Code
```html
<div class="input-bar">
  <button class="attach">+</button>
  <input class="text-field" type="text" />
  <button class="send">Send</button>
</div>
<style>
  .input-bar { display: flex; gap: 8px; }
  .attach, .send { flex: 0 0 auto; } /* Don't grow, don't shrink */
  .text-field { flex: 1 1 auto; }    /* Grow to fill space */
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Container uses `display: flex`.

**Step 2:** Buttons use `flex: 0 0 auto` (grow: 0, shrink: 0, basis: auto) so they stay their natural size.

**Step 3:** Input uses `flex: 1 1 auto` so it grows to absorb all leftover space in the container.

### 5. ASCII Data Flow
```text
[+] <----- (flex-grow: 1) stretches this -----> [Send]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Writing `width: 100%` on a flex item, causing overflow.
**Pro Tip:** Use the shorthand `flex: 1` (which means `flex: 1 1 0%`) for items you want to take up remaining space.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Make a flex item take up all remaining space.
<details>
<summary>Hint</summary>
Use flex-grow.
</details>
<details>
<summary>Solution</summary>

```css
.item { flex-grow: 1; }
```
</details>

### Level 2: Real-World (Slack Chat Message Input Bar)
Build a Slack input bar where the input stretches but buttons stay fixed.
<details>
<summary>Hint</summary>
Use flex: 1 on input.
</details>
<details>
<summary>Solution</summary>

```css
.input { flex: 1; }
.btn { flex-shrink: 0; }
```
</details>

### Level 3: Boss Level (Cumulative)
Create a split layout where the left side is exactly 250px and the right side fills the rest.
<details>
<summary>Hint</summary>
Use flex-basis on left, flex-grow on right.
</details>
<details>
<summary>Solution</summary>

```css
.sidebar { flex: 0 0 250px; }
.main { flex: 1; }
```
</details>
