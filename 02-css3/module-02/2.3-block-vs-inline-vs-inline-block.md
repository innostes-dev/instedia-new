# Block, Inline, and Inline-Block

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
You try to give a simple `<span>` a width and height to make it a pill button, but it completely ignores you.

### 2. Plain English Metaphor (The What)
Block is a greedy couch taking up the whole wall. Inline is a single word in a sentence. Inline-block is a couch you can put in the middle of a sentence.

### 3. Complete Runnable Code
```html
<nav>
  <a href="#" class="pill">Home</a>
  <span class="badge">3</span>
</nav>
<style>
  .pill {
    display: inline-block;
    padding: 8px 16px;
    background: #eee;
    border-radius: 20px;
  }
  .badge {
    display: inline-block;
    width: 24px;
    height: 24px;
    background: red;
    color: white;
    text-align: center;
    border-radius: 50%;
  }
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Use `<a>` and `<span>`, which are `inline` by default (ignoring width/height).

**Step 2:** Change them to `display: inline-block`.

**Step 3:** Apply padding, width, height, and backgrounds safely while staying on the same line.

### 5. ASCII Data Flow
```text
[Block]
--------------------
[Inline] [Inline] [Inline]
--------------------
[Inline-Block (Has Dimensions)] [Inline-Block]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Using `float: left` just to get blocks side-by-side.
**Pro Tip:** Modern CSS rarely needs `inline-block` for layouts; use Flexbox instead. But `inline-block` is still great for icons and badges in text.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Make an anchor tag respect width and height.
<details>
<summary>Hint</summary>
Change its display property.
</details>
<details>
<summary>Solution</summary>

```css
a { display: inline-block; width: 100px; height: 50px; }
```
</details>

### Level 2: Real-World (Navbar Pill Buttons & Badges)
Build a notification badge that sits next to text.
<details>
<summary>Hint</summary>
Use inline-block and border-radius.
</details>
<details>
<summary>Solution</summary>

```css
.badge { display: inline-block; width: 20px; height: 20px; border-radius: 50%; background: red; }
```
</details>

### Level 3: Boss Level (Cumulative)
Create a list of pill buttons that wrap nicely without breaking layout.
<details>
<summary>Hint</summary>
Flexbox is better, but inline-block works if you manage whitespace.
</details>
<details>
<summary>Solution</summary>

```css
.pill { display: inline-block; margin: 4px; padding: 8px 16px; border-radius: 999px; }
```
</details>
