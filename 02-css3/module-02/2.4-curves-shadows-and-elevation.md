# Curves, Shadows, and Elevation

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
UI feels flat and indistinguishable. Users can't tell what is clickable or what is layered on top of what.

### 2. Plain English Metaphor (The What)
Shadows and curves are like lighting in a room. They tell our brain how close an object is to us and make edges feel friendly.

### 3. Complete Runnable Code
```html
<div class="property-card">
  <h3>Cozy Cabin</h3>
</div>
<style>
  .property-card {
    width: 300px;
    padding: 20px;
    border-radius: 16px;
    background: white;
    box-shadow: 0 10px 15px -3px rgba(0,0,0,0.1),
                0 4px 6px -2px rgba(0,0,0,0.05);
  }
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Apply `border-radius` to soften the corners of the card.

**Step 2:** Add a primary `box-shadow` for the main drop shadow.

**Step 3:** Add a secondary, tighter `box-shadow` (comma-separated) to create a realistic, layered ambient shadow.

### 5. ASCII Data Flow
```text
[Flat Div] ---> (+ border-radius) ---> [Rounded Div]
           ---> (+ box-shadow)    ---> [Floating Card]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Using pure black `#000000` for shadows. It looks muddy and artificial.
**Pro Tip:** Layer multiple subtle shadows to create realistic, physical depth.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Make a square div a perfect circle.
<details>
<summary>Hint</summary>
Use border-radius at 50%.
</details>
<details>
<summary>Solution</summary>

```css
div { width: 100px; height: 100px; border-radius: 50%; }
```
</details>

### Level 2: Real-World (Airbnb Elevated Property Card)
Create an Airbnb-style property card with a soft, modern shadow.
<details>
<summary>Hint</summary>
Use low opacity black and a large blur radius.
</details>
<details>
<summary>Solution</summary>

```css
.card { border-radius: 12px; box-shadow: 0 8px 24px rgba(0,0,0,0.08); }
```
</details>

### Level 3: Boss Level (Cumulative)
Create an interactive card that elevates on hover.
<details>
<summary>Hint</summary>
Transition the transform and box-shadow.
</details>
<details>
<summary>Solution</summary>

```css
.card { transition: transform 0.2s, box-shadow 0.2s; }
.card:hover { transform: translateY(-4px); box-shadow: 0 12px 32px rgba(0,0,0,0.12); }
```
</details>
