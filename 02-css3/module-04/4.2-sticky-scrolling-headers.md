# Sticky Scrolling Headers

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
You want a menu to scroll normally, but 'stick' to the top of the screen when it hits the edge so the user doesn't lose it.

### 2. Plain English Metaphor (The What)
Sticky is like a post-it note on a conveyor belt. It moves with the belt until it hits a wall, then it just slides along the wall.

### 3. Complete Runnable Code
```html
<header>Main Nav</header>
<div class="sub-nav">Categories</div>
<main>Lots of content...</main>
<style>
  .sub-nav {
    position: sticky;
    top: 0; /* The threshold */
    background: white;
    z-index: 10;
  }
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Set `position: sticky` on the element you want to pin.

**Step 2:** Set a threshold, like `top: 0`, which tells it *when* to stick.

**Step 3:** Ensure no parent element has `overflow: hidden`, or sticky will break.

### 5. ASCII Data Flow
```text
(Scrolling Down)
[Main Nav]  <-- scrolls out of view
[Sub Nav]   <-- scrolls until it hits top: 0
================ (Top of Screen)
[Sub Nav]   <-- STICKS HERE
[Content]   <-- slides under Sub Nav
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Putting `overflow: hidden` on the `body` or a wrapper div, which silently disables sticky behavior.
**Pro Tip:** Sticky elements only stick *within their parent container*. If the parent is the same height as the sticky element, it won't stick.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Make a header stick to the top of the page.
<details>
<summary>Hint</summary>
Use sticky and top: 0.
</details>
<details>
<summary>Solution</summary>

```css
header { position: sticky; top: 0; }
```
</details>

### Level 2: Real-World (Amazon Category Sub-Navbar Pinned on Scroll)
Create a sticky sub-navbar that stops 50px from the top (under a fixed main nav).
<details>
<summary>Hint</summary>
Set top to 50px.
</details>
<details>
<summary>Solution</summary>

```css
.sub-nav { position: sticky; top: 50px; }
```
</details>

### Level 3: Boss Level (Cumulative)
Build an alphabetized contact list where the letter headers stick as you scroll past them.
<details>
<summary>Hint</summary>
Put sticky on the headers inside the list container.
</details>
<details>
<summary>Solution</summary>

```css
.letter-header { position: sticky; top: 0; background: #eee; }
```
</details>
