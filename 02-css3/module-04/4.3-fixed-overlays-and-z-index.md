# Fixed Overlays & Z-Index

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
You need a chat widget that stays in the bottom corner no matter where the user scrolls, floating above everything else.

### 2. Plain English Metaphor (The What)
Fixed positioning locks an element to the camera lens itself. Z-index decides which sticker is placed on top if two stickers overlap on the lens.

### 3. Complete Runnable Code
```html
<div class="chat-widget">💬 Help</div>
<style>
  .chat-widget {
    position: fixed;
    bottom: 20px;
    right: 20px;
    z-index: 9999;
    background: blue; color: white;
    border-radius: 50px; padding: 16px;
  }
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Use `position: fixed` to anchor the element to the viewport (the screen).

**Step 2:** Position it using `bottom` and `right`.

**Step 3:** Assign a high `z-index` so it stays above page content.

### 5. ASCII Data Flow
```text
[ Camera Lens / Viewport ]
    (Locked: bottom 20, right 20)
       [ Chat Widget (z-index: 9999) ]
-----------------------------------------
[ Scrolling Webpage (z-index: 1) ]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Thinking `z-index: 9999999` will always beat `z-index: 10`. Stacking contexts matter! A child of a `z-index: 1` parent can never beat a `z-index: 10` element.
**Pro Tip:** Manage your z-indexes using CSS variables (e.g., `--z-modal: 1000`) so you don't end up in an arms race of nines.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Make a navigation bar fixed to the top of the screen.
<details>
<summary>Hint</summary>
Use fixed and top: 0.
</details>
<details>
<summary>Solution</summary>

```css
nav { position: fixed; top: 0; width: 100%; }
```
</details>

### Level 2: Real-World (Full-Screen Intercom Support Chat Drawer)
Create a bottom-right chat button that stays above all content.
<details>
<summary>Hint</summary>
Fixed, bottom/right, z-index.
</details>
<details>
<summary>Solution</summary>

```css
.chat { position: fixed; bottom: 20px; right: 20px; z-index: 100; }
```
</details>

### Level 3: Boss Level (Cumulative)
Create a full-screen modal overlay.
<details>
<summary>Hint</summary>
Use fixed, top/left/right/bottom 0.
</details>
<details>
<summary>Solution</summary>

```css
.overlay { position: fixed; inset: 0; background: rgba(0,0,0,0.5); z-index: 999; }
```
</details>
