# Unstyled HTML & Selectors

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
Browsers render plain HTML differently, making the web look like a 1990s academic paper. We need to add visual identity to our raw structure.

### 2. Plain English Metaphor (The What)
Think of HTML as the bare frame of a house, and CSS as the paint, wallpaper, and interior design.

### 3. Complete Runnable Code
```html
<!DOCTYPE html>
<html>
<head>
  <style>
    /* CSS goes here */
    body { font-family: sans-serif; color: #333; }
    h1 { color: #000; }
    .author { color: #666; }
  </style>
</head>
<body>
  <h1>The Future of Design</h1>
  <p class="author">By Jane Doe</p>
</body>
</html>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** First, we link our CSS to the HTML document (here using an internal `<style>` tag).

**Step 2:** We target the `body` to set a base font and text color.

**Step 3:** We use an element selector (`h1`) and a class selector (`.author`) to customize specific pieces of text.

### 5. ASCII Data Flow
```text
[HTML Structure] ---> [CSS Selectors] ---> [Visual Output]
  <body>                 body { ... }         Styled background
    <h1>                   h1 { ... }         Bold heading
    <p class="author">     .author { ... }    Gray text
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Writing all styles inline using the `style` attribute (e.g., `<h1 style='color:red'>`).
**Pro Tip:** Using external stylesheets and targeting elements via classes for reusability.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Style a basic paragraph to be blue.
<details>
<summary>Hint</summary>
Use the `p` selector.
</details>
<details>
<summary>Solution</summary>

```css
p { color: blue; }
```
</details>

### Level 2: Real-World (Medium Minimal Story Header)
Create a Medium-style story header with a large, bold title.
<details>
<summary>Hint</summary>
Use font-size and font-weight on a class.
</details>
<details>
<summary>Solution</summary>

```css
.story-title { font-size: 3rem; font-weight: bold; }
```
</details>

### Level 3: Boss Level (Cumulative)
Combine multiple selectors to style a full header section.
<details>
<summary>Hint</summary>
Use commas for multiple selectors or chain them.
</details>
<details>
<summary>Solution</summary>

```css
.header h1, .header p { text-align: center; }
```
</details>
