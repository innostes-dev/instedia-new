# Text Overflow & Truncation

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
Long user-generated content (like song titles) breaks UI layouts by wrapping unexpectedly or pushing elements out of bounds.

### 2. Plain English Metaphor (The What)
Truncation is like a picture frame: if the painting is too wide, we hide the edges and add a tiny '...' sticky note to show there's more.

### 3. Complete Runnable Code
```html
<div class="track-title">
  This is a very long track title that will not fit in the box
</div>
<style>
  .track-title {
    width: 200px;
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
  }
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Constrain the width of the container so we have a definite boundary.

**Step 2:** Prevent the text from wrapping to the next line using `white-space: nowrap`.

**Step 3:** Hide the overflow and use `text-overflow: ellipsis` to add the '...'.

### 5. ASCII Data Flow
```text
[Text String] --> [Container Width Hit] --> [No Wrap] --> [Cut Off] --> [Add ...]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Forgetting that `text-overflow` requires `overflow: hidden` and `white-space: nowrap` to actually work.
**Pro Tip:** Using multi-line truncation (line-clamp) for paragraphs instead of single-line truncation.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Prevent text from wrapping inside a div.
<details>
<summary>Hint</summary>
Use `white-space`.
</details>
<details>
<summary>Solution</summary>

```css
div { white-space: nowrap; }
```
</details>

### Level 2: Real-World (Spotify Long Track Title Truncation)
Implement a Spotify-style track title that truncates with an ellipsis when too long.
<details>
<summary>Hint</summary>
Combine white-space, overflow, and text-overflow.
</details>
<details>
<summary>Solution</summary>

```css
.title { white-space: nowrap; overflow: hidden; text-overflow: ellipsis; width: 150px; }
```
</details>

### Level 3: Boss Level (Cumulative)
Create a multi-line truncated description (like a podcast summary).
<details>
<summary>Hint</summary>
Look into `-webkit-line-clamp`.
</details>
<details>
<summary>Solution</summary>

```css
.desc { display: -webkit-box; -webkit-line-clamp: 3; -webkit-box-orient: vertical; overflow: hidden; }
```
</details>
