# Web Fonts & Typography

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
System fonts are boring and inconsistent across operating systems. We want a unified, beautiful typographic experience.

### 2. Plain English Metaphor (The What)
Web fonts are like sending a custom typewriter along with your document so the reader sees exactly the letters you intended.

### 3. Complete Runnable Code
```html
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap" rel="stylesheet">
<style>
  body {
    font-family: 'Inter', sans-serif;
    line-height: 1.6;
    letter-spacing: -0.02em;
  }
</style>
<div class="card">Beautiful Typography</div>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Import the web font via Google Fonts or `@font-face`.

**Step 2:** Apply the font using `font-family`, providing a generic fallback (`sans-serif`).

**Step 3:** Adjust `line-height` for readability and `letter-spacing` for a polished look.

### 5. ASCII Data Flow
```text
[Browser requests HTML] --> [Finds <link> to Font] --> [Downloads Font]
                                                     --> [Applies Font to Text]
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Loading 10 different font weights you don't use, tanking page load speed.
**Pro Tip:** Using variable fonts or only loading the exact weights you need, and always providing web-safe fallbacks.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Set the font of the body to Arial with a fallback to sans-serif.
<details>
<summary>Hint</summary>
Use the `font-family` property.
</details>
<details>
<summary>Solution</summary>

```css
body { font-family: 'Arial', sans-serif; }
```
</details>

### Level 2: Real-World (Apple Clean Typography Card)
Create an Apple-style typography layout using a custom sans-serif font, adjusted line-height, and tight letter spacing.
<details>
<summary>Hint</summary>
Use negative letter-spacing for large text.
</details>
<details>
<summary>Solution</summary>

```css
h1 { font-family: -apple-system, sans-serif; font-weight: 600; letter-spacing: -0.05em; line-height: 1.1; }
```
</details>

### Level 3: Boss Level (Cumulative)
Build a cohesive typography system with headings and body text that scale harmoniously.
<details>
<summary>Hint</summary>
Use rems and consistent line heights.
</details>
<details>
<summary>Solution</summary>

```css
body { font-family: 'Inter', sans-serif; line-height: 1.5; }
h1 { font-size: 2.5rem; line-height: 1.2; }
```
</details>
