# Mobile-First Media Queries

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
Designing for desktop first, then writing hundreds of overrides to squish it onto mobile, leading to broken, bloated CSS.

### 2. Plain English Metaphor (The What)
Mobile-first is building a small foundation, then adding extensions as you get more land. Desktop-first is building a mansion, then trying to cram it into a tiny lot with a bulldozer.

### 3. Complete Runnable Code
```html
<nav class="navbar">
  <div class="logo">App</div>
  <ul class="links">
    <li>Home</li>
    <li>Pricing</li>
  </ul>
</nav>
<style>
  /* MOBILE FIRST (Default) */
  .navbar { display: flex; flex-direction: column; }

  /* ENHANCE FOR LARGER SCREENS */
  @media (min-width: 768px) {
    .navbar { flex-direction: row; justify-content: space-between; }
  }
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Write base styles optimized for the smallest possible screen (mobile).

**Step 2:** Add a `@media (min-width: 768px)` block to trigger when the screen reaches tablet size.

**Step 3:** Inside the query, *override or add* styles needed for the larger screen (like switching column to row).

### 5. ASCII Data Flow
```text
[ Base CSS (Mobile) ] -> App is usable
       |
       +--> [ @media (min-width: 768px) ] -> App expands for Tablet
                 |
                 +--> [ @media (min-width: 1024px) ] -> App expands for Desktop
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Using `@media (max-width)` to hide desktop elements on mobile. This forces mobile users to download desktop CSS.
**Pro Tip:** Stick strictly to `min-width`. Your code will be much cleaner and performant.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Change a box from red to blue on screens wider than 500px.
<details>
<summary>Hint</summary>
Use min-width.
</details>
<details>
<summary>Solution</summary>

```css
.box { background: red; }
@media (min-width: 500px) { .box { background: blue; } }
```
</details>

### Level 2: Real-World (Responsive Landing Page Navigation)
Convert a mobile vertical menu into a horizontal desktop menu.
<details>
<summary>Hint</summary>
Base is column, media query makes it row.
</details>
<details>
<summary>Solution</summary>

```css
.menu { display: flex; flex-direction: column; }
@media (min-width: 768px) { .menu { flex-direction: row; } }
```
</details>

### Level 3: Boss Level (Cumulative)
Create a 1-column mobile grid that becomes 3-column on desktop.
<details>
<summary>Hint</summary>
Use grid-template-columns in the media query.
</details>
<details>
<summary>Solution</summary>

```css
.grid { display: grid; grid-template-columns: 1fr; }
@media (min-width: 1024px) { .grid { grid-template-columns: repeat(3, 1fr); } }
```
</details>
