# Container Queries

## Phase A: The Core Concept

### 1. Real-World Pain Point (The Why)
You build a nice card component that works well in a 3-column grid. But when you put that exact same card in a narrow sidebar, it breaks, because media queries only care about the *screen* size, not the *parent* size.

### 2. Plain English Metaphor (The What)
A media query is looking out the window to check the weather. A container query is looking at the size of your suitcase to see what you can pack.

### 3. Complete Runnable Code
```html
<div class="sidebar">
  <div class="card">
    <div class="card-content">Info</div>
  </div>
</div>
<style>
  .sidebar {
    container-type: inline-size;
    container-name: sidebar;
  }
  .card { display: flex; flex-direction: row; }

  /* If the parent container is smaller than 400px */
  @container sidebar (max-width: 400px) {
    .card { flex-direction: column; }
  }
</style>
```

### 4. Progressive Step-by-Step Breakdown
**Step 1:** Define the parent as a container using `container-type: inline-size`.

**Step 2:** Write a `@container` query instead of a `@media` query.

**Step 3:** The child component will now respond to its actual physical space on the page, not the viewport size.

### 5. ASCII Data Flow
```text
[ Sidebar (300px wide) ]  <-- Container
  |-- [ Card ] triggers @container (max-width: 400px)
  |-- Card becomes Vertical (column)

[ Main Content (800px wide) ] <-- Container
  |-- [ Same Card ] does NOT trigger
  |-- Card stays Horizontal (row)
```

### 6. Noob Trap vs Pro Tip
**Noob Trap:** Using container queries for everything. Use media queries for macro page layouts, and container queries for micro component layouts.
**Pro Tip:** Container queries allow true component-driven design. A component can finally own its responsive logic completely.

## Phase B: Engineering Challenges

### Level 1: Warm-Up
Declare a div as a container for queries.
<details>
<summary>Hint</summary>
Use container-type.
</details>
<details>
<summary>Solution</summary>

```css
.wrapper { container-type: inline-size; }
```
</details>

### Level 2: Real-World (Reusable Widget Adapting to Sidebar)
Change a card's background if its container is wider than 500px.
<details>
<summary>Hint</summary>
Use @container.
</details>
<details>
<summary>Solution</summary>

```css
@container (min-width: 500px) { .card { background: blue; } }
```
</details>

### Level 3: Boss Level (Cumulative)
Build a reusable bio-widget that switches layout based on the size of the slot it's placed in.
<details>
<summary>Hint</summary>
Combine container definition and query.
</details>
<details>
<summary>Solution</summary>

```css
.slot { container-type: inline-size; }
@container (max-width: 300px) { .bio { display: block; } }
```
</details>
