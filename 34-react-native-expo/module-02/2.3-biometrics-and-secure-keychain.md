# 2.3 Biometrics & Secure Storage: FaceID and Keychain

## Phase A: Concept & Implementation

### 1. Real-World Pain Point (The Why)
Many developers build a mobile login screen, get a JWT (JSON Web Token) from their backend, and casually save it using `AsyncStorage.setItem('token', jwt)`. This is a massive security vulnerability. `AsyncStorage` writes data in plain, unencrypted text to the device's local file system. A malicious actor with physical access to the device, or malware exploiting a rooted/jailbroken phone, can easily extract this token and hijack the user's account. For banking, healthcare, or any app handling PII (Personally Identifiable Information), this is unacceptable.

### 2. Plain English Metaphor (The What)
`AsyncStorage` is like writing your house key down on a sticky note and leaving it on your car dashboard. Anyone who looks through the window can copy it. Expo SecureStore, backed by iOS Keychain and Android Keystore, is like putting that key inside a titanium vault bolted to the floor of the bank. Only the bank's security system (the OS) can open it. To make retrieving the key convenient but secure, we use Expo LocalAuthentication (Biometrics). This acts as a highly trained security guard who checks your face or fingerprint before unlocking the titanium vault.

### 3. Complete Runnable Code
*Example: Bank-Grade Mobile Login with Biometric FaceID*

**Setup requirements:** `expo-secure-store` and `expo-local-authentication`.

```tsx
import React, { useState, useEffect } from 'react';
import { View, Text, StyleSheet, TouchableOpacity, Alert } from 'react-native';
import * as SecureStore from 'expo-secure-store';
import * as LocalAuthentication from 'expo-local-authentication';
import { Ionicons } from '@expo/vector-icons';

const TOKEN_KEY = 'user_secure_jwt';

const BiometricAuthScreen = () => {
  const [isAuthenticated, setIsAuthenticated] = useState(false);
  const [hasBiometrics, setHasBiometrics] = useState(false);
  const [secureData, setSecureData] = useState<string | null>(null);

  useEffect(() => {
    checkBiometricAvailability();
  }, []);

  const checkBiometricAvailability = async () => {
    // 1. Check if the device has hardware support (e.g., FaceID scanner exists)
    const compatible = await LocalAuthentication.hasHardwareAsync();
    // 2. Check if the user has actually enrolled their face/fingerprint in OS settings
    const enrolled = await LocalAuthentication.isEnrolledAsync();

    setHasBiometrics(compatible && enrolled);
  };

  const handleLogin = async () => {
    try {
      if (!hasBiometrics) {
        Alert.alert('Error', 'Biometrics not set up on this device. Please use password.');
        return;
      }

      // Prompt the OS native biometric modal
      const authResult = await LocalAuthentication.authenticateAsync({
        promptMessage: 'Authenticate to access Secure Banking',
        fallbackLabel: 'Use PIN', // Button shown if face isn't recognized
        cancelLabel: 'Cancel',
        disableDeviceFallback: false, // Allows OS passcode if biometrics fail
      });

      if (authResult.success) {
        setIsAuthenticated(true);
        // After verifying identity, securely retrieve the token
        await retrieveSecureData();
      } else {
        Alert.alert('Authentication Failed', 'Could not verify identity.');
      }
    } catch (error) {
      console.error('Auth error:', error);
    }
  };

  const simulateInitialSetup = async () => {
    // Simulating a first-time login where we get a token from an API
    const fakeApiToken = 'jwt_eyJhbGciOiJIUzI1Ni...';

    // Save token to hardware-encrypted Keystore/Keychain
    // requireAuthentication: true means iOS will natively prompt FaceID
    // even just to READ this value later.
    await SecureStore.setItemAsync(TOKEN_KEY, fakeApiToken, {
      keychainAccessible: SecureStore.WHEN_UNLOCKED_THIS_DEVICE_ONLY,
    });

    Alert.alert('Success', 'Token encrypted and saved to Keychain.');
  };

  const retrieveSecureData = async () => {
    const token = await SecureStore.getItemAsync(TOKEN_KEY);
    setSecureData(token);
  };

  const handleLogout = () => {
    setIsAuthenticated(false);
    setSecureData(null);
  };

  return (
    <View style={styles.container}>
      <Ionicons name="lock-closed" size={64} color="#3B82F6" style={styles.icon} />
      <Text style={styles.title}>Secure Banking App</Text>

      {!isAuthenticated ? (
        <View style={styles.authContainer}>
          <TouchableOpacity style={styles.setupButton} onPress={simulateInitialSetup}>
            <Text style={styles.buttonText}>1. Simulate First Login (Save Token)</Text>
          </TouchableOpacity>

          <TouchableOpacity
            style={[styles.authButton, !hasBiometrics && styles.disabledButton]}
            onPress={handleLogin}
            disabled={!hasBiometrics}
          >
            <Ionicons name="finger-print" size={24} color="white" style={{ marginRight: 8 }} />
            <Text style={styles.buttonText}>2. Login with Biometrics</Text>
          </TouchableOpacity>
        </View>
      ) : (
        <View style={styles.dashboard}>
          <Text style={styles.successText}>Authentication Successful!</Text>
          <Text style={styles.dataText}>Decrypted Token: {secureData?.substring(0, 15)}...</Text>
          <TouchableOpacity style={styles.logoutButton} onPress={handleLogout}>
            <Text style={styles.buttonText}>Lock App</Text>
          </TouchableOpacity>
        </View>
      )}
    </View>
  );
};

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center', backgroundColor: '#F3F4F6', padding: 20 },
  icon: { marginBottom: 20 },
  title: { fontSize: 24, fontWeight: '800', marginBottom: 40, color: '#1F2937' },
  authContainer: { width: '100%', alignItems: 'center' },
  setupButton: { backgroundColor: '#6B7280', padding: 16, borderRadius: 12, width: '100%', marginBottom: 16 },
  authButton: { backgroundColor: '#3B82F6', padding: 16, borderRadius: 12, width: '100%', flexDirection: 'row', justifyContent: 'center', alignItems: 'center' },
  disabledButton: { backgroundColor: '#9CA3AF' },
  buttonText: { color: 'white', fontWeight: '700', fontSize: 16, textAlign: 'center' },
  dashboard: { alignItems: 'center', width: '100%' },
  successText: { fontSize: 20, color: '#10B981', fontWeight: 'bold', marginBottom: 12 },
  dataText: { fontSize: 14, color: '#4B5563', marginBottom: 24, fontFamily: 'monospace' },
  logoutButton: { backgroundColor: '#EF4444', padding: 16, borderRadius: 12, width: '100%' },
});

export default BiometricAuthScreen;
```

### 4. Progressive Step-by-Step Breakdown

**Step 1: Evaluating Device Capabilities**
Why this precedes the next: We cannot prompt for FaceID if the device is an older model without the hardware, or if the user simply hasn't set it up.
```tsx
const compatible = await LocalAuthentication.hasHardwareAsync();
const enrolled = await LocalAuthentication.isEnrolledAsync();
```
*Rationale:* Mobile development requires defensive programming against hardware variance. If these return false, we must elegantly fallback to a traditional username/password or PIN screen rather than crashing.

**Step 2: Securing the Data in the Hardware Enclave**
Why this precedes the next: Before we can verify identity to read a token, the token must be securely stored during the initial login.
```tsx
await SecureStore.setItemAsync(TOKEN_KEY, fakeApiToken, {
  keychainAccessible: SecureStore.WHEN_UNLOCKED_THIS_DEVICE_ONLY,
});
```
*Rationale:* `WHEN_UNLOCKED_THIS_DEVICE_ONLY` is a crucial iOS security configuration. It ensures the token is only accessible when the phone is unlocked, and prevents the token from being backed up to iCloud and restored onto a *different* device, thwarting cloning attacks.

**Step 3: Prompting Native OS Authentication**
Why this precedes the next: We must ask the OS to verify the human before we attempt to pull the token out of the vault.
```tsx
const authResult = await LocalAuthentication.authenticateAsync({
  promptMessage: 'Authenticate to access Secure Banking',
});
if (authResult.success) { /* retrieve data */ }
```
*Rationale:* React Native never actually sees your fingerprint or facial data. The OS handles the scan natively and simply returns a boolean (`success: true/false`) to the JS thread.

### 5. ASCII / Architecture Data Flow
```text
[ First Time Login ]
1. React Native (API Call) --> Receives JWT
2. SecureStore.setItem()   --> Sends JWT to OS
3. OS Hardware Enclave     --> Encrypts JWT using device-specific master key. Stored in Keystore/Keychain.

[ Subsequent Login (Biometrics) ]
1. User taps "Login"
2. LocalAuth.authenticate() --> JS calls Native OS
3. OS FaceID/TouchID UI     --> Scans user (Hardware layer)
4. OS returns Boolean       --> { success: true }
5. React Native             --> Calls SecureStore.getItem()
6. OS Hardware Enclave      --> Decrypts JWT and returns it to JS
7. React Native             --> Attaches JWT to HTTP headers for API requests
```

### 6. Noob Trap vs Pro Tip
* **Noob Trap:** Using `SecureStore` for everything, including large JSON objects or arrays of app settings. `SecureStore` has a size limit (often around 2048 bytes on Android) and is significantly slower than standard storage due to encryption overhead.
* **Pro Tip:** Only store strictly sensitive material (OAuth tokens, encryption keys, PIN hashes) in `SecureStore`. For large amounts of non-sensitive data, use `AsyncStorage` or SQLite.

### Level 2: Real-World
**Challenge:** SecureStore keys can persist even if the user uninstalls and reinstalls the app, leading to weird state bugs on fresh installs. Implement a check on app boot that clears the SecureStore if it's a completely fresh install.
<details>
<summary>Hint</summary>
Use standard `AsyncStorage` to set a flag like `has_run_before = true`. If this flag is missing, it means the app was reinstalled. If it's missing, delete the `TOKEN_KEY` from `SecureStore`.
</details>

<details>
<summary>Solution Walkthrough</summary>
```tsx
import AsyncStorage from '@react-native-async-storage/async-storage';
import * as SecureStore from 'expo-secure-store';

const checkFirstRun = async () => {
  const hasRun = await AsyncStorage.getItem('has_run_before');
  if (!hasRun) {
    // App was freshly installed. Clear any lingering Keychain data.
    await SecureStore.deleteItemAsync(TOKEN_KEY);
    await AsyncStorage.setItem('has_run_before', 'true');
  }
};
```
This is a standard pattern for managing Keychain persistence lifecycles.
</details>

### Level 3: Boss Level
**Challenge:** Build an "AppLock" feature. If the app goes into the background for more than 60 seconds (e.g., user switches to Messages and comes back), automatically wipe the React state and force the user to re-authenticate with FaceID.
<details>
<summary>Hint</summary>
You need the `AppState` API from React Native. Track when `AppState` changes to `'background'` and save a timestamp. When it changes to `'active'`, check the time difference. If `> 60000ms`, call `setIsAuthenticated(false)` and trigger the FaceID prompt.
</details>

<details>
<summary>Solution Walkthrough</summary>
This combines App Lifecycle state with Biometric Security to create true banking-grade session management.

```tsx
import { AppState } from 'react-native';
import { useRef, useEffect } from 'react';

const BiometricAppLock = () => {
  const appState = useRef(AppState.currentState);
  const backgroundTime = useRef<number | null>(null);

  useEffect(() => {
    const subscription = AppState.addEventListener('change', nextAppState => {
      if (appState.current.match(/active/) && nextAppState === 'background') {
        // App went to background, record time
        backgroundTime.current = Date.now();
      }

      if (appState.current.match(/inactive|background/) && nextAppState === 'active') {
        // App returned to active
        if (backgroundTime.current) {
          const timeAway = Date.now() - backgroundTime.current;
          if (timeAway > 60000) { // 60 seconds
            // Force re-authentication
            setIsAuthenticated(false);
            handleLogin(); // Triggers biometric prompt
          }
        }
      }
      appState.current = nextAppState;
    });

    return () => subscription.remove();
  }, []);
}
```
</details>
